# /cafe — gov 글 → 카페 글 파일 → 임시등록 (2026-09-29 확정)

사장님이 하는 말은 이것뿐이다: **"작성한 글 푸시하고 카페 글 작성해서 저장"**. 나머지는 이 순서대로 알아서 한다.

## 순서

1. **푸시** — 그날 쓴 gov 글(커밋 안 된 것 포함)을 커밋·푸시한다. pre-push 가 막으면 고쳐서 통과시킨다(`--no-verify` 금지). 사장님이 이 말을 했으면 푸시 승인으로 본다(CLAUDE.md 절대 규칙 3).
   Cloudflare 빌드가 끝나 글 주소가 열리는지 확인한다(카페 글 링크가 404이면 안 된다).
2. **대상 찾기** — 오늘 새로 쓰거나 고친 gov 글 전부. `scripts/cafe/.state.json` 의 `drafted` 에 없는 slug 가 대상이다.
   (허브·스포크는 스포크마다 한 편. 스포크 카페 글에는 허브 링크도 넣는다)
3. **카페 글 파일 작성** — 글마다 `scripts/cafe/{slug}.md` (스포크는 `geps-…` 처럼 스포크 slug).
   - 형식 정본: `scripts/cafe/post.mjs` 머리 주석. 첫 줄 `제목:` · `인용구:`(gov 타이틀) · 서론 · `링크: 글자 | gov 주소` · `■` 소제목 · … · 정리 한 줄 · `※` 기준일 · 맨 아래 `링크:` · `태그:` 5개(공백 없는 검색어).
   - 사실·숫자는 **gov 글(data/policies/*.ts, app/policy/**/content/**)에 있는 것만**. 새로 만들지 않는다. 표는 "- 항목: 값" 줄로.
   - 해요체. 전문 용어는 풀어 쓴다(승계·개시연령·원천징수처럼 풀이 없는 말 금지). 문장이 어색하면 독립 검수(Agent)로 한 번 더 읽힌다.
   - **제목**: 짧게(대개 35~45자) + 눌러 볼 이유(날짜·조건·금액·손해) + 네이버 자동완성어(Playwright 로 `ac.search.naver.com` 조회, 추측 금지). gov 타이틀과 같게 쓰지 않는다.
   - **서론 마지막 문장은 링크를 읽어 주지 않는다**("○○ 버튼을 눌러" 금지). 링크는 `링크:` 줄이 담당한다.
   - 정부 이미지(정책브리핑 등)는 저작권 때문에 넣지 않는다 — 사장님이 임시등록 글에서 넣는다.
4. **임시등록** — `node scripts/cafe/post.mjs --all` 을 돌린다(로그인 대기 때문에 오래 걸리면 백그라운드로 돌려 로그 파일로 진행을 본다).
   사장님께 "열린 창에서 네이버 로그인(로그인 상태 유지 체크)" 을 부탁한다. 로그인이 남아 있으면 그냥 진행된다.
   게시판은 기본 '금융 경제'. 다른 게시판은 `--board=정부지원금`.
5. **보고** — 임시등록된 편 수와 제목 목록, 못 올린 편(진단 `scripts/cafe/debug.json`)을 말한다.

## 하지 말 것

- 공개 등록(`--publish`) — 자동 승인 검사가 막는다. 우회하지 않는다. 사장님이 눌러야 한다.
- 이미 올린 글 중복 등록(`.state.json` 이 기억한다, 다시 하려면 `--again`).
- 하루 등록 3편 상한·간격 2분(사장님이 등록할 때 지켜지도록 안내만).
- 내 셸 명령 줄에 `post.mjs` 를 넣은 채 프로세스를 이름으로 죽이기(셸이 같이 죽는다). 창을 끌 땐 chrome 중 `remote-debugging-port=9333` 인자만 골라서 끈다.

## 화면이 바뀌어 막힐 때

`scripts/cafe/debug.json`·`debug.png` 를 보고 `post.mjs` 의 선택자를 고친다. 창은 디버그 포트 9333 으로 뜨므로 `chromium.connectOverCDP('http://127.0.0.1:9333')` 로 붙어 화면을 확인할 수 있다.
