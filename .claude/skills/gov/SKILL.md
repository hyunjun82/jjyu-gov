# /gov {키워드} — scripts/write.ts 가 4단계를 실행한다

단계 실행은 **전부 `scripts/write.ts` 가 한다.** 내가 순서를 정하지 않는다.
2026-08-23 이전에는 이 자리에 에이전트 4개(gov-title·outline·fact·verify)가 있었다.
에이전트는 나한테 하는 부탁이라 지켰는지 아무도 못 봤고, 안 지킨 걸 잡으려고
게이트를 계속 붙였다(도구 커밋 203건). 그래서 실행 파일 하나로 바꿨다.

사람이 서는 자리는 **두 곳뿐**이다 — 타이틀 번호 고르기, 구성표 승인.
(푸시 승인은 별개다. 자동 푸시 금지 — CLAUDE.md 절대규칙 3.)

## 어디까지 왔는지부터 묻는다

```bash
npx tsx scripts/write.ts "{키워드}"
```

출력 맨 아래 "지금 칠 것" 한 줄이 다음 명령이다. **그 줄을 그대로 실행한다.**
상태는 `scripts/output/state-{slug}.json` 에 있어서 세션이 끊겨도 이어진다.

---

## 1단계 — 타이틀 (사람 개입 ①)

```bash
npx tsx scripts/write.ts "{키워드}" --1
```

자음 ㄱ~ㅎ 확장으로 실검색어를 모으고, 그 **조각으로만** 후보를 조립해 번호로 뿌린다.
후보마다 어느 검색어에서 왔는지, KB 패턴 ①~⑨ 중 무엇인지가 같이 찍힌다.

- 후보를 **채팅에 그대로 올리고 멈춘다.** 내가 고르지 않는다.
- 내가 문장을 새로 지어 끼워넣지 않는다 — 지으면 실검색어가 아니게 된다.
- 사장님이 번호를 주시면:

```bash
npx tsx scripts/write.ts "{키워드}" --pick {번호}
```

구성표·팩트시트·초안 뼈대가 생기고, **소제목은 실검색어로 이미 채워져 있다.**

## 2단계 — 구성표 (사람 개입 ②)

내가 채우는 것은 `outline-{slug}.md` 의 **hero 서론 + 버튼 라벨·목적지**뿐이다.
문구는 `.claude/rules/action-copy.md` 6단계 흐름(공감→대안→금액→단서→넘기기→기간)을 따른다.

```bash
npx tsx scripts/write.ts "{키워드}" --2        # 빈칸·비질문형 소제목 점검
```

통과하면 **구성표 전문을 채팅에 올리고 멈춘다.** 승인 없이 본문으로 넘어가지 않는다.
사장님이 "승인" 하시면:

```bash
npx tsx scripts/write.ts "{키워드}" --approve  # stage2-{slug}.json 도장 → pre-push 가 본다
```

## 3단계 — 사실

```bash
npx tsx scripts/write.ts "{키워드}" --3
```

구성표·팩트시트에 적힌 URL 을 **전부** 열어 `scripts/output/sources/` 에 저장하고
`source-{slug}.txt` 로 합친다.

- **1500자 미만 경고가 뜨면 그 출처는 못 받은 것이다.** 아코디언·JS 로딩이다.
  Playwright MCP 로 직접 열어 `browser_take_screenshot` + 텍스트를 확보한다.
  (2026-08-23 손보협회 FAQ 를 907자만 읽고 "근거 없다"고 오판했다.)
- 봇 차단이면 폴백 순서: Claude in Chrome → law.go.kr/easylaw → korea.kr 보도자료 PDF
- 수치는 2개 이상 출처 교차 + 계산 정합성 검산. 못 채운 항목은 팩트시트
  "확보하지 못한 것"에 사유와 함께 적고 **본문에 쓰지 않는다.**

그 다음 본문을 쓴다. 스포크면 뼈대를 손으로 만들지 않는다:

```bash
npx tsx scripts/new-spoke.ts --spec scripts/output/spec-{slug}.json
```

## 4단계 — 대조

```bash
npx tsx scripts/write.ts "{키워드}" --4
```

추출본 ↔ 완성글 양방향 대조 + 배선·타입 게이트. 통과하면 커밋한다.
**글이 없으면 여기서 막힌다** — 안 쓴 글에 찍히는 초록불이 제일 위험해서다.

푸시는 사장님 승인 뒤에만. 배치로 10~30편 모아 한 번에 올린다.

## 하지 말 것

- 단계 건너뛰고 본문부터 쓰기 — 훅이 저장을 막고 pre-push 가 push 를 막는다
- 결과가 이상하다고 **새 검사기·새 에이전트 만들기.** 원인은 대개 지시문의 그 줄이다.
  고칠 곳은 이 파일이거나 `scripts/write.ts` 안의 규칙이지, 새 파일이 아니다.
- 추정·예시 수치, 블로그·언론을 1차 출처로 인용, 정부 슬로건·로고, 자동 푸시
