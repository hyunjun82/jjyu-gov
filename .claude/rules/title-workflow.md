# 타이틀·소제목 — 사장님이 준 것은 글자 그대로 (2026-09-19 확정, 09-23 보완)

1. 허브·스포크 확장은 사장님이 spec 으로 준다 (`scripts/specs/{주제}.md`). 한 편짜리를 맡기면 내가 네이버 자동완성 + 행동 키워드로 짓는다.
2. **글자 하나 바꾸지 않는다.** 후킹·패턴·캡처·실검색어 조립·판정 — 전부 없다 (2026-09-19 삭제).
3. **바꾸자고 제안하지 않는다.** 어색해 보여도 그대로 쓴다. 문제가 있으면 보고서 메모에 한 줄 적고 그대로 쓴다.
4. 소제목 = qa 카드 4개 (spec 순서 그대로), FAQ 2개 — `scripts/gov/check-article.mjs` 가 개수까지 막는다.
5. 버튼: 상단 = 타이틀의 행동어, 카드 = 행동이 있는 소제목 바로 아래(cardLayout 'act-first'). 목적지는 수집 단계에서 실제로 열린 주소만.
