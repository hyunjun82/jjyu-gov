## 작업 중 알게 된 구조 (다음 세션에서 반복 삽질 방지)

1. **스포크 버튼은 `act.url`·`act.label`을 쓰지 않는다.** 목적지는 항상 허브(`/policy/{id}/`),
   라벨은 그 카드 질문 문장에서 `lib/cta.ts`의 `hubCta()`가 자동 생성한다.
   → 스포크에서 버튼 문구를 바꾸려면 **질문 문장을 고쳐야 한다.** `act`에는 `cue`만 쓴다.
2. 같은 페이지에서 라벨이 겹치면 `HUB_CTA_FALLBACKS`로 대체된다 —
   질문 3개가 전부 "금액" 계열이면 엉뚱한 라벨("신청방법 바로가기")이 붙으니 질문 어휘를 분산시킬 것.
3. `SpokeQAItem`에 `act` 타입이 없어서 TS 오류가 났었다 → 2026-07-31 추가 완료.
4. 게이트(`check-cue-value.ts` 등)는 `git diff origin/main...HEAD` 기준이라
   **커밋 전 파일은 검사되지 않는다.** 작업 중 확인하려면 파일을 직접 검사할 것.
5. `verify-quality.ts` Q12는 `/(?<![가-힣])약\s*\d/` — "약 8일분" 같은 표현이 걸린다.
