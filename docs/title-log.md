# 타이틀 캡처 확인 기록 (title-log)

> **왜 이 파일이 있나 (2026-08-10)**
> "타이틀 뽑기 전에 reference/titles 캡처를 연다"는 규칙이 수차례 지적에도 계속 어겨졌다.
> 원인은 규칙이 행동이라 게이트가 검사할 수 없었기 때문이다 — 캡처 파일이 "있는지"는
> 검사했지만 "봤는지"는 흔적이 없었다.
> 그래서 흔적을 강제한다: 신규·수정 타이틀은 이 파일에 아래 형식의 항목이 없으면
> 저장 훅(`scripts/hooks/require-title-log.mjs`)이 이 기록 없이는 저장을 막는다. **옮겨적지 못하면 안 연 것이다.**

## 항목 형식 (이대로 안 쓰면 게이트가 못 읽는다)

```
## <글 파일명(확장자 제외) 또는 slug>
- 캡처: <reference/titles/ 파일명> — "<캡처에서 본 KB 타이틀 한 줄 그대로>"
- 패턴: <①~⑨ 중 하나> — <왜 이 구조를 골랐나 한 문장>
- 타이틀: <확정 타이틀>
```

- 캡처 줄의 따옴표 안은 **캡처 화면에 실제로 보이는 타이틀**을 옮겨적는다. 기억으로 쓰지 않는다.
- 패턴 번호는 `docs/title-corpus-kb.md` ①~⑨.
- 한 글에 여러 후보를 냈으면 확정된 것만 적는다.
