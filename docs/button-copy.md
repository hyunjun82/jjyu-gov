# 버튼·문구 정본

## 흐름 (구조만 고정, 문장은 매번 다르게)

```
1 공감            요즘 은행권 대출 쉽지 않습니다
2 대안이 왜 어려운가  2금융·3금융 알아보자니 이자가 배보다 배꼽이라 선뜻 못 하시죠
3 그래서 이게 있다   광진구는 1.5%로 최대 1억까지 지원하는데요
4 다만 다 되는 건 아니다  아쉽게도 전 업종이 아니라 해당 업종만 지원됩니다
5 그럼 확인부터 하셔야겠죠  그럼 먼저 내 업종이 되는지부터 확인하셔야겠죠
  → [대출 지원 업종부터 확인하기]      ← 버튼 1: 대상 확인
6 기간           8월 12일까지라 열흘 정도 남았습니다
  → [융자 신청 바로가기]               ← 버튼 2: 신청
```

버튼은 2~3개. 카드마다 하나씩 짜내면 "확인하기" 도배가 된다(A축이 상한 5개로 차단).
4번(다 되는 건 아니다)이 확인 버튼을 누르게 만드는 지점이고,
5번 한 줄이 버튼으로 넘기는 다리다. 이게 없으면 설명하다 버튼이 튀어나온다(O축이 차단).
  "그럼 먼저 내가 대상자인지 확인부터 하셔야겠죠"
  "먼저 대상자인지, 신청은 가능한지 파악이 중요하겠죠"
버튼 문구는 앞 문장에서 나온다 — 서류 얘기를 안 했으면 "서류 챙기러 가기"는 와닿지 않는다.

## 예시 셋 (흐름은 같고 시작은 다 다르다)

- 광진구 융자 — 대안이 없다는 데서 시작
- 시흥 전세이자 — "1년 치 모아보면 적은 돈이 아닙니다" 금액 체감에서 시작
- 에너지바우처 — "대상자여도 신청 안 하면 한 푼도 안 나옵니다" 몰라서 못 받는 데서 시작

## 문체

말하듯 잇는다. 단정형으로 뚝뚝 끊으면 공고문이 된다.
  X  1억까지 지원합니다. 8월 12일에 닫힙니다.
  O  최대 1억까지 지원하는데요. 8월 12일까지라 열흘 정도 남았습니다.

맺음은 매번 다르게(N축이 도배 차단).
  서류부터 맞춰보고 가시는 게 좋습니다 / 좋은 결과 있으셨으면 좋겠습니다
  지나면 다음 해까지 기다려야 합니다 / 대상 확인되셨으면 바로 넣어두세요

맺음을 "…하시길 바랍니다"로 고정하면 사이트 전체가 같은 문장으로 끝나
AI가 찍어낸 티가 난다(N축이 차단). 상황에 맞게 매번 바꾼다.

  서류는 미리 챙겨두세요        (준비가 필요한 건)
  8월 12일이면 접수가 닫힙니다   (마감이 임박한 건)
  이번엔 구가 냅니다            (돈이 핵심인 건)
  대상인데 신청 안 하면 한 푼도 안 들어옵니다  (몰라서 놓치는 건)
  남은 경기는 월·화 저녁에만 열립니다          (일정이 핵심인 건)

## 버튼

`[무엇을] + [즉시] + [목적 행위]` — 6~14자, 기관명 금지.
지원금 글에서 사용자가 원하는 건 정보가 아니라 돈이다.

| X | O |
|---|---|
| 지원 내용 확인하기 | 지원금 즉시 신청하기 |
| 신청 자격 살펴보기 | 내 자격 맞춰보기 |
| 접수 방법 알아보기 | 우리 동 센터 찾기 |
| 케스파컵 대진표·일정 조회하기 | 케스파컵 시청 바로가기 |

카드마다 동사를 다르게. 읽는 동사(확인·보기·살펴·훑어)가 절반 넘으면 차단.

## 마감

X 이번엔 8월 7일 오후 6시가 끝입니다
O 8월 7일 오후 6시까지이니 미리 신청하시길 바랍니다
