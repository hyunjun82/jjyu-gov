# 버튼·문구 정본

글의 목적은 정보 전달이 아니라 버튼 클릭이다. 아래 예시를 보고 그대로 따라 쓴다.

---

## 1. 정본 — 워터밤 부산 (이 글 하나만 보면 된다)

**후킹**
> 작년에 표 놓치고 영상으로만 보신 분들 계실 겁니다. 부산은 8월 8일 하루뿐이고,
> 온라인에서 매진되면 현장에서는 아예 팔지 않습니다.
> 지금 라인업이 나왔으니 이번엔 예매 성공하시길 바랍니다.

**버튼 (7개, 전부 다른 행동)**

| 카드 | 버튼 | 어디로 |
|---|---|---|
| 언제·어디 | 워터밤 부산 즉시 예매하기 | 예매처 |
| 라인업 | 내가 볼 무대 라인업에서 찾기 | 라인업 페이지 |
| 교통 | 부산 셔틀버스 예약하기 | 셔틀 예약 |
| 예매처 | 예매처 비교하기 | 예매처 목록 |
| 입장 | 입장 가능한 신분증 확인하기 | 안내 |
| 팔찌 | QR 즉시 발급받기 | 발급 화면 |
| 준비물 | 물총·방수팩 고르기 | 상품 페이지 |

**왜 이게 정본인가**
- 후킹이 "작년에 놓친 나"로 시작한다. 행사 설명이 아니다.
- 버튼 7개가 예매·찾기·예약·비교·확인·발급·고르기로 전부 다르다.
- 사용자가 하고 싶은 일(표 사기, 자리 잡기, 팔찌 받기)이 그대로 버튼이다.

## 2. 나쁜 예 (우리가 실제로 저지른 것)

| 글 | 버튼들 | 문제 |
|---|---|---|
| 케스파컵 | 일정 확인하기 · 진행 방식 확인하기 · 예매 공지 확인하기 · 상금 규정 확인하기 | 전부 확인하기. 읽고 끝난다 |
| 삼성미소금융 | 대출상품 확인하기 · 지원대상 확인하기 · 제외 기준 확인하기 · 절차 확인하기 | 대출받고 싶은 사람에게 읽으라고만 한다 |
| 의왕시(초안) | 지원 규모 확인하기 · 자격 살펴보기 · 항목 훑어보기 · 기준 따져보기 | 확인을 피하려다 전부 읽는 동사 |

→ M축이 이제 이걸 차단한다.

## 3. 후킹 공식

```
1문장  그 사람이 겪은 과거 좌절        "작년에 표 놓치고 영상으로만 보신 분들 계실 겁니다"
2문장  이번엔 왜 다른가 / 놓치면 뭘 잃나  "매진되면 현장에서는 아예 팔지 않습니다"
3문장  이번엔 …하시길 바랍니다          "이번엔 예매 성공하시길 바랍니다"
```

1문장이 빠지면 아무리 숫자를 넣어도 안내문이다.

**실제 1문장들 — 이 결로 쓴다**
- "케스파컵 본방 놓치고 다음 날 결과만 보신 적 있으실 겁니다"
- "다자녀 등록증만 있으면 자동으로 깎이는 줄 아셨다면 지금까지 낸 통행료는 그대로 나간 겁니다"
- "1차 때 신청 못 하고 등록금 다 내신 분들 많으실 겁니다"
- "은행에서 거절당하고 더 알아볼 곳이 없다고 생각하셨다면 여기가 남아 있습니다"
- "간판이 낡아 손님이 못 알아보고 지나친 적 있으실 겁니다"

---

## 4. 버튼 공식

```
[무엇을] + [즉시] + [목적 행위]      워터밤 부산 즉시 예매하기
```

- 6~14자. 기관명·수식어 금지("(한국도로공사 공식)" X).
- 사용자의 목적 행위로 쓴다 — 지원금 글이면 원하는 건 정보가 아니라 **돈**이다.
- 카드마다 동사를 다르게. 한 글에서 같은 동사가 절반을 넘으면 차단(L축).
- 읽는 동사(확인·보기·살펴·훑어·읽어·따져)가 절반을 넘으면 차단(M축).
- 실제 행동 버튼이 하나도 없으면 차단(M축).

| X | O |
|---|---|
| 지원 내용 확인하기 | 지원금 즉시 신청하기 |
| 신청 자격 살펴보기 | 내 자격 맞춰보기 |
| 접수 방법 알아보기 | 우리 동 센터 찾기 |
| 서류 안내 보기 | 신청 서류 챙기기 |
| 케스파컵 대진표·일정 조회하기 | 케스파컵 시청 바로가기 |
| 지금 다자녀 통행료 할인 사전등록하기 (한국도로공사 공식) | 다자녀 할인 등록하기 |

## 5. 문장 쓸 때 걸리는 것

마감은 통보가 아니라 권유로 닫는다.

- X "이번엔 8월 7일 오후 6시가 끝입니다"
- O "8월 7일 오후 6시까지이니 미리 신청하시길 바랍니다"

압박은 종결어미를 비틀어서가 아니라 사실(12곳 선정·18시 마감)로 준다.
세게 쓰려다 나온 비문은 K축이 차단한다 — 맞추십니다 / 대주는데 / 끝내십니다 /
걸리십니다 / 남으셨는데요 / 판단이 섭니다.

---

## 6. 금지

- 근거 없는 긴급("서두르세요", 확인 안 된 선착순·예산)
- 버튼에 기관명
- 다른 글과 같은 문장(B축 차단)
- 조건·자격을 앞세워 밀어내기 — "가입해야 볼 수 있습니다"는 이탈 문구다

## 7. 게이트 (`scripts/check-cue-value.ts`)

| 축 | 막는 것 |
|---|---|
| B | 다른 글과 같은 문구 |
| C·D | 버튼이 다 같은 곳으로 / 기관 메인으로 |
| H | 숫자·손실·기한·물음이 하나도 없는 문구 |
| I | 주어가 제도·기관인 문구 |
| J | 14자 초과·기관명 붙은 버튼 |
| K | 비문 |
| L | 같은 동사 버튼 도배 |
| M | 읽는 동사뿐 / 행동 버튼 0개 |

본문 쓰기 전에 문구만 먼저 검사한다:
```
npx tsx scripts/check-cue-value.ts --draft <초안파일>
```
