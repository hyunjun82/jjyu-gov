## 2. 패턴 규칙 (24개에서 도출)

### 구조: [핵심 질문 or 주제] + [구체 디테일·혜택·숫자]
세 가지 결합형이 반복된다:
- **질문? + 서술**: "자발적 퇴사도 받을 수 있을까? 인정되는 정당한 사유 총정리" (1·3·7·8·15·16·20·22)
- **쉼표 + ~까지/~법**: "권고사직 실업급여 조건과 신청 방법, 회사 불이익까지" (2·19·21)
- **콜론(:)**: "실업급여 수급자격 조건: 고용보험 180일 가입기간 계산법" (5)

### 허용 (이전 '금지' 규칙을 이 정본으로 갱신)
- ✅ **총정리** (1·6·14·23) — 자연스러우면 허용
- ✅ **~까지 / ~법은? / ~끝** (2·11·10)
- ✅ **콜론(:)** 1개 (5·9·…)
- ✅ **물음표** + 뒤에 서술절
- ✅ **숫자+단위**: 180일·만 50세·30일·7일·12개월·5단계·5년·2026 (구체 숫자가 클릭률↑)
- ✅ 연도는 맨 앞(7·13) 또는 생략

### 지양
- ❌ 키워드 조각만 "|"로 갖다붙이기 (양쪽이 완결된 절이어야 함)
- ❌ 한 타이틀에 구분기호 2개 이상 (콜론+물음표+쉼표 난사)
- ❌ 본문에서 안 다루는 내용을 타이틀에 약속 (→ §4 일치 규칙)
- ❌ "약 ~/대략" 등 추측 표현

### 연관 키워드 묶음 (E 그룹처럼)
같은 검색에서 함께 뜨는 유사 주제는 한 타이틀에 묶는다.
- "예술인·노무제공자 … 특고 고용보험 총정리" (23)
- "건강보험·국민연금 보험료는 어떻게 되나" (24)

## 4. 타이틀 ↔ 본문 일치 규칙 (필수)

> **타이틀이 약속한 것은 본문이 반드시 답한다.** (사장님 지적: 타이틀-본문 불일치 재발 방지)

1. **타이틀의 핵심 키워드·숫자는 본문 소제목(qa[].q)·내용에 그대로 등장**해야 한다.
   - 예) 타이틀 "고용보험 180일 가입기간 계산법" → 본문에 `180일`과 계산법을 다루는 qa 필수.
   - 예) 타이틀 "만 50세 … 30일 더 받는 법" → 본문에 `만 50세`·`30일` qa 필수.
2. **숫자 표기 통일**: 타이틀과 본문의 숫자 표기를 맞춘다(예: 둘 다 `7,000만원` 또는 둘 다 `7천만원`).
3. **타이틀이 묶은 주제(쉼표·콜론 뒤)도 본문에서 각각 다룬다**. "조건과 신청 방법, 회사 불이익까지"면 → 조건·신청·불이익 qa가 모두 있어야 함.
4. 검증: `bash scripts/check-title-body-match.sh [정책폴더]`
   - 타이틀 키워드(특히 `[숫자]`)가 본문에 없으면 경고. **[숫자] 경고는 반드시 해소**.
   - 휴리스틱이라 활용형·표기차 오탐 가능 → 표시 항목을 직접 확인해 맞춘다.

## 5. 신규 글 작성 전 순서 (요약)

```
0a. npx tsx scripts/collect-keywords.ts "{허브키워드}"   ← 자동완성 대량(suggest API) + byTheme
0b. 실브라우저(MCP Playwright)로 네이버·구글 SERP 열어 PAA·연관검색어 수확  ← 질문형 금쪽
    · 네이버 .related_srch .keyword / 구글 PAA [jsname][role=heading] + 하단 관련검색어
1. 0a+0b 합쳐 byTheme(A~F) 확인 → 부족하면 하위 씨앗어로 재수집
2. 위 §2 패턴으로 24식 자연 롱테일 타이틀 합성 (그룹별)
3. 사용자 승인
4. 작성 — §4 타이틀↔본문 일치 지키며 Format A 작성
5. check-spoke-quality.sh + check-title-body-match.sh 통과 → 승인 → push
```

> ⚠️ 자동완성(API)은 prefix만 준다. **PAA·연관검색어(질문형)는 반드시 실브라우저로 SERP를 열어 수확**한다. (10회 테스트로 검증: 헤드리스 스크래핑은 PAA·연관 0, 실브라우저는 둘 다 수확 성공.)
