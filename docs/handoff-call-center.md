## 회사 하나 추가하는 법 (이게 전부)

```
1) 공식 고객센터 페이지를 실브라우저로 연다
2) npx tsx scripts/capture-source.ts {slug}-call-center "<URL>" ["<URL2>"]
3) data/call-centers/{slug}.json 을 채운다
4) npx tsx scripts/new-call-center.ts data/call-centers/{slug}.json --approve
```

JSON 필수: `slug name industry brandColor official sourceUrl sourceName verifiedAt main hours ars numbers`
`industry` 는 `insurance` 또는 `securities`. 없으면 보험으로 떨어진다.

## 오늘 고친 것 (다시 같은 실수 안 하게)

- **`capture-source.ts` 가 표를 못 읽었다.** `innerText` 는 `rowspan` 셀을 빈칸으로 준다.
  교보증권 상담시간이 표 안에 있었는데 "없다"고 판정하고 회사를 버렸다.
  표를 셀 단위로 따로 떠서 추출본에 붙인다 — 고객센터만이 아니라 모든 글에 해당한다.
- **`public/search-index.json` 이 낡아 175편이 사이트 검색에서 빠져 있었다.** 게이트로 막는다.
- **홈에 고객센터 입구가 없었다.** `/category/call-center` 는 살아 있는데 아무도 링크를 안 걸었다.
- **회사 페이지에서 내부로 갈 곳이 허브 하나뿐이었다**(외부 링크는 12개).
  같은 업종 다른 회사 6곳 카드를 하단에 깔았다 — 내부 이동이 전면광고가 뜨는 자리다.
- **og:image 가 없었다.** 회사 45 + 허브 2 = 47장을 구웠다(`scripts/make-og-callcenter.ts`).
  회사를 추가하면 이 스크립트를 다시 돌려야 카드가 생긴다.
