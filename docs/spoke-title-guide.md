# 스포크 타이틀 작성 가이드 (KB Think 패턴 기반)

> 참고 사이트: https://kbthink.com (저축·투자·대출·라이프·부동산·세금 카테고리)
> 이 가이드를 위반하는 타이틀은 작성 금지.

---

## 0. 타이틀 작성 전 필수 절차 (Chrome 검색 수집 — 추측 절대 금지)

**타이틀을 단 하나도 쓰기 전에 아래 단계를 반드시 실행한다.**
검색어를 추측하거나 지식에서 꺼내는 것은 전면 금지.

### Step 1 — Google 검색 (Claude in Chrome)
```
검색어: {정책 키워드} 사이트:없음 (일반 검색)
수집:
  - 자동완성 제안어 (검색창에 키워드 입력 시 뜨는 목록)
  - People Also Ask (PAA) 질문 목록
  - 하단 '관련 검색어' 8개
  - 상위 3개 블로그/카페 글 제목
```

### Step 2 — Naver 검색 (Claude in Chrome)
```
검색어: {정책 키워드}
수집:
  - 연관 검색어 (우측 또는 하단 패널)
  - VIEW 탭 상위 글 제목 5개
  - 지식iN 질문 제목 5개
```

### Step 3 — 수집 결과 정리 후 타이틀 작성
수집된 실제 검색어·질문을 아래 6개 패턴에 맞게 타이틀로 변환.
수집 결과에 없는 표현은 타이틀에 넣지 않는다.

---

## 1. 핵심 원칙

스포크 타이틀은 **실제 사람이 검색창에 입력하거나 눈에 띄어 클릭하는 문장**이어야 한다.
키워드를 나열하는 게 아니라, 검색자의 **상황·불안·궁금증**을 담아야 한다.

---

## 2. 허용 패턴 (6가지)

### 패턴 A — 파이프 분리형
```
[구체적 상황/키워드 덩어리] | [부연 또는 핵심 답변]
```
예시:
- "어린이집 다니면 부모급여 얼마나 줄어드나 | 0세·1세 나이별 차이"
- "신용대출, 전세대출, 주택담보대출 차이 | 나에게 맞는 대출 고르는 법"

### 패턴 B — 범위형 (부터~까지)
```
[시작 키워드]부터 [끝 키워드]까지 [핵심 정보]
```
예시:
- "내일배움카드 발급 조건부터 사용처·잔액 확인까지"
- "에너지바우처 신청부터 전기·가스 결제 방법까지"

### 패턴 C — 의문+대조형
```
[A] vs [B], [결론 질문]?
또는 [A]이면 [B]도 되나? [조건]
```
예시:
- "자녀 1명 vs 2명, 자녀장려금 금액이 얼마나 차이 날까"
- "근로장려금 받는데 자녀장려금도 같이 신청되나"

### 패턴 D — 상황 선제형
```
[구체적 상황]이라면? [해결 방법/기준]
또는 [구체적 조건]인 경우 [결과/주의사항]
```
예시:
- "직장인도 내일배움카드 받을 수 있다? 재직자 신청 조건과 안 되는 경우"
- "65세 이후에도 일하면 기초연금 깎이나 | 근로소득 공제 기준"

### 패턴 E — 결론 선제형
```
[핵심 상황/인물], [결과/질문]
```
예시:
- "쌍둥이 낳으면 부모급여 두 배로 받을 수 있을까? 지급 기준 확인"
- "3.3% 원천징수 프리랜서, 근로장려금 신청하면 어떻게 되나"

### 패턴 F — 시점+범위형
```
[연도/시점] [키워드] [동작] | [대상]부터 [절차]까지
```
예시:
- "2026년 5월 종합소득세 신고 방법 | 대상부터 절차까지 한 번에"
- "작년 자녀장려금 신청 못 했다면 | 경정청구로 돌려받는 방법"

## 3. 절대 금지 패턴

| 금지 | 이유 | 대체 |
|------|------|------|
| `~~ 총정리` 단독 마무리 | AI 생성 느낌 | 패턴 A~F 사용 |
| `~~ 방법 총정리` | 동일 | "~~ 방법 \| 단계별 확인" |
| `~~ 조건 총정리` | 동일 | "~~ 조건부터 서류까지" |
| `2026 총정리` 조합 | 최악의 AI 패턴 | 연도 + 구체 내용 |
| 동일 패턴 3개 연속 | 단조로움 | 패턴 번갈아 사용 |
| 연도를 중간·끝에 배치 | 어색하고 검색 비친화적 | 연도는 맨 앞(F패턴) 또는 생략 |
| E패턴 물음표형 서술어 남용 | "~가 올라간다?" 어색 | E패턴은 인물+상황 후 담백한 의문문 |
| 탈세·미신고 조장 느낌 문구 | 정보성 글 신뢰 손상 | "소득 신고 기준" 등 중립 표현 |
| 지나친 구어체 ("나라에서 아나") | 신뢰도 저하, 검색 부적합 | "국가에서 파악하나", "적발 사례" 등 |

### 연도 배치 규칙 (중요)
- ✅ **허용**: `2026년 육아휴직 급여 | 엄마·아빠 순서별 금액 차이` (맨 앞)
- ✅ **허용**: 연도 생략 (대부분의 경우 자연스러움)
- ❌ **금지**: `육아휴직 순서별 금액 2026` (끝)
- ❌ **금지**: `엄마 이어 아빠도 쓰면 급여가 올라간다? 2026 육아휴직` (중간)

## 4. 스포크 세트 구성 규칙 (정책 1개 기준 4 spokes)

### 4-1. 개수 규칙
- 정책 1개당 스포크 **4개** 작성 (기본값)
- 기존 스포크 있으면 신규분만 채워 총 4개 맞춤

### 4-2. 패턴 배분 규칙 (4개 세트 기준)
| 패턴 | 허용 횟수 |
|------|---------|
| F (시점+범위형) | 최대 **2개** |
| A/B/C/D/E | 각 최대 2개, 연속 사용 금지 |
| 동일 패턴 연속 | **금지** |

예시 배분: A → C → F → D (4개, 패턴 모두 다름)

### 4-3. 연관 키워드 묶음 규칙
검색에서 같이 등장하는 유사 정책은 **한 타이틀에 묶어** 검색 포괄성 높임.

예시:
- "장애인연금 vs 장애수당, 어떻게 다르고 중복 되나" → 두 키워드 동시 포함
- "근로장려금 받는데 자녀장려금도 같이 신청되나" → 두 정책 동시 포함
- 단, 억지로 묶지 말 것 — 검색에서 같이 뜨는 경우만

## 5. 타이틀 체크리스트

- [ ] **Chrome 검색 수집 완료** (Google PAA + Naver 연관검색어)
- [ ] 타이틀 내 모든 표현이 수집된 실제 검색어에서 왔음
- [ ] 키워드 3~4개 자연스럽게 포함
- [ ] 검색자 상황(누가, 어떤 처지)이 느껴짐
- [ ] 구체적 숫자(금액·나이·기간·%) 1개 이상 (가능한 경우)
- [ ] 직전 2개 타이틀과 패턴이 겹치지 않음
- [ ] 연도(2026 등)는 맨 앞에만 (F패턴) 또는 생략
- [ ] "총정리" "나라에서 아나" 등 금지 표현 없음
- [ ] 실제 사람이 쓴 문장처럼 읽힘

## 6. 정책별 검색 니즈 맵

### 부모급여
- 어린이집 보내면 급여 깎일까봐 걱정 → 패턴 D/A
- 쌍둥이인데 두 배 받는지 모름 → 패턴 E
- 신청 늦게 해서 소급 가능한지 → 패턴 D

### 자녀장려금
- 아이 수에 따라 금액 차이 → 패턴 C
- 근로장려금이랑 중복 가능한지 → 패턴 C
- 기한 지나서 소급 가능한지 → 패턴 F

### 내일배움카드
- 직장 다니면서 신청 가능한지 → 패턴 D
- 잔액·사용처 확인 방법 → 패턴 B
- 실업급여랑 동시에 가능한지 → 패턴 C

### 주거급여
- 부모님이랑 동거인데 받을 수 있는지 → 패턴 D
- 집 수리 비용(수선유지급여)도 되는지 → 패턴 C
- 월세 vs 자가, 지원 방식이 다른지 → 패턴 C

### 에너지바우처
- 전기·가스 중에 어디 쓰는지 → 패턴 B
- 편의점·인터넷 결제 가능 여부 → 패턴 D
- 신청 기간·방법 → 패턴 F

### 기초연금
- 일하면 깎이는지 → 패턴 D
- 부부 중 한 명만 신청 → 패턴 C
- 재산 있으면 못 받는지 → 패턴 D

### 실업급여
- 월급 기준 하루 얼마인지 → 패턴 A (숫자 포함)
- 자발적 퇴사인데 받을 방법 → 패턴 D
- 알바하면서 받을 수 있는지 → 패턴 C

### 근로장려금
- 3.3% 프리랜서 신청 가능 → 패턴 E
- 맞벌이 기준 소득 한도 → 패턴 A
- 신청 기한 지났을 때 → 패턴 F

## 7. 좋은 예 vs 나쁜 예

| ❌ 나쁜 예 | ✅ 좋은 예 |
|-----------|----------|
| 부모급여 어린이집 총정리 | 어린이집 등록하면 부모급여 얼마나 줄어드나 \| 0세·1세 나이별 비교 |
| 자녀장려금 자격조건 2026 총정리 | 자녀 2명이면 장려금 두 배로 받나? 자녀 수별 지급 기준 |
| 내일배움카드 재직자 신청방법 총정리 | 직장인도 내일배움카드 된다? 재직자 조건과 안 되는 경우 |
| 주거급여 신청 방법 총정리 | 부모님과 같이 사는데 주거급여 신청 가능할까 \| 세대분리 기준 |
| 에너지바우처 사용처 총정리 | 에너지바우처 전기·가스·등유 사용 방법부터 온라인 결제까지 |
| 기초연금 근로소득 총정리 | 65세 이후에도 일하면 기초연금 깎이나 \| 근로소득 공제 기준 |
| 근로장려금 프리랜서 총정리 | 3.3% 원천징수 프리랜서, 근로장려금 신청하면 어떻게 되나 |
