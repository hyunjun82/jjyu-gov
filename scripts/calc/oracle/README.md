# 홈택스 연말정산 자동계산(2026년 귀속) 대조 도구

`lib/year-end-tax/engine.ts` 가 홈택스와 단계별로 일치하는지 시험하려고, 홈택스
"(모의계산) 연말정산 자동계산 2026년"(로그인 없이 열린다)에 같은 입력을 자동으로 넣어 결과를 받는다.

- `ht-lib.cjs` 화면 열기·총급여 입력 / `ht-run.cjs` 케이스 → 화면 입력 → 계산 → 항목별(183개) 응답 수집
  (화면이 막아 둔 칸·거절된 입력은 건너뛰고, 홈택스가 실제로 받은 값만 "유효 케이스"로 남긴다)
- `ht-batch.cjs cases.json out.json [workers]` 여러 케이스를 병렬로(이어서 실행 가능)
- `gen-*.cjs` 무작위 케이스(시드 고정)·항목별 탐침 케이스 생성
- 결과 비교: `npx tsx scripts/calc/compare.ts scripts/calc/data/*.json`

주의: 홈택스 쪽 요청에는 요청마다 바뀌는 보안 토큰이 있어 값을 바꿔 다시 보내는 방식은 쓰지 않는다. 화면 입력만 쓴다.
