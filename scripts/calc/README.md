# 연말정산 모의계산기 검증 (2026년 귀속)

`lib/year-end-tax/engine.ts` 가 계산하고, `app/calc/year-end-tax/` 가 화면이다.
계산이 맞는지는 **홈택스 "(모의계산) 연말정산 자동계산 2026년"** 과 같은 입력으로 단계별 대조해서 본다.
(로그인 없이 쓸 수 있고, 올해 개정 세법을 그대로 따른다. 2019년 귀속 모바일 간편계산기는 옛 세율이라 정답지로 쓰지 않는다.)

## 다시 돌려 보기

```
npm run calc:verify            # 저장된 홈택스 결과(scripts/calc/data)와 엔진을 비교 — 불일치 0 이어야 한다
node scripts/calc/oracle/gen-cases.cjs <시드> <개수> <접두어> > cases.json    # 무작위 케이스 (시드 고정, 재현 가능)
node scripts/calc/oracle/ht-batch.cjs cases.json out.json 4                   # 홈택스에 자동 입력해 결과 수집 (이어서 실행 가능)
npx tsx scripts/calc/compare.ts out.json                                      # 엔진과 비교
```

## 무엇을 비교하나

근로소득공제 · 근로소득금액 · 인적공제 · 소득공제 합계 · 과세표준 · 산출세액 · 세액공제 합계 · 결정세액 · 지방소득세,
그리고 소득공제 항목별(연금보험료·특별소득공제·그 밖의 소득공제). 한 항목이라도 다르면 불일치로 센다.

화면 입력칸이 엔진에 제대로 연결됐는지는 `ui-wiring.test.ts` 로 따로 본다(개발 서버가 떠 있어야 한다).

## 한계 (페이지에도 적는다)

- 입력하지 않은 항목(이월 기부금, 외국납부세액, 그 밖의 감면 등)은 화면에 없고 계산하지 않는다.
- 홈택스가 입력을 막는 경우(예: 배우자공제와 한부모공제 동시, 총급여 7천만원 초과 청약저축)는 같은 규칙으로 막는다.
- 홈택스 자체의 오류까지는 잡지 못한다. 최종 금액은 회사 정산과 국세청 확정이 기준이다.
- 소기업·소상공인 공제(노란우산)는 소상공인·법인 대표만 가입할 수 있어 근로자용 화면에는 두지 않았다(엔진은 홈택스와 일치).
