- 양도소득 기본세율 누진표(6~45%) — 분양권은 60%·70% 단일세율이라 글에 필요 없고, 누진표를 쓰면 계산 유도가 될 수 있음
- 양도세 신고·납부 기한 — 주어진 원문(세율 페이지)에 신고·납부 기한이 없음
- '22.5.10.~'26.5.9. 다주택자 기본세율 적용(각주 5) — 분양권이 아닌 주택 양도 특례이고 기간이 이미 지나 혼동 우려
- 예외 사유 중 상속주택 이전·이혼·배우자 일부 증여·공익사업 이주대책·채무불이행 경매 — 30개 한도 안에서 독자 빈도가 높은 사유만 남김
- 분양가상한제 주택 LH 우선 매입 — 소제목 범위 밖의 세부 절차
- 신고필증 발급 시 검인 의제 — 분양권 전매 신고 독자에게 필요성이 낮음
- 이득 목적 거짓신고 형사처벌(거래신고법 제26조, 3년/3천만원) — 전매제한 위반 처벌(f24)과 숫자가 같아 혼동 우려, 과태료 사실로 충분
- 주택 임대차 신고, 외국인 취득 신고, 토지거래허가 — 주제와 무관
- 부동산거래관리시스템 콜센터 1533-2949 — 상담 창구 안내라서 떠넘기기 금지 규칙에 해당
- 버튼 URL — 행동 링크가 주민등록법 링크 하나뿐이고 주제와 맞지 않음
- 거래신고법 제3조·제28조 개정 조문(시행 2026.12.17., 2027.9.9.) — 분양권 신고 기한(30일)과 과태료 금액(500만원)은 바뀌지 않아 충돌 없음
