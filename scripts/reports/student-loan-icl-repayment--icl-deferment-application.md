## 쓰지 않은 것
- 유예 신청 시 제출 서류 목록 — 원문 어디에도 서류 이름이 없음. '증빙 제출없는 상환유예 신청' 공지 제목만 있어 f11로만 적음
- 유예 기간·횟수·신청 기한 — 원문에는 '일정기간'이라는 말만 있고 구체적인 기간이나 기한이 없음
- 경제적 곤란 판정 소득 기준액 — 법률은 대통령령으로 정한다고만 적었고, 시행령 원문은 수집되지 않음
- 상환율 법정 범위 100분의 20~40과 조정 규정(제18조⑥) — 독자에게는 현재 상환율(f9)이면 충분함
- 상속·증여·퇴직소득에 대한 상환(제18조②단서, ③) — 유예 대상인 사업·근로소득과 관계없어 글 주제에서 벗어남
- 국세청 상담센터 126, 한국장학재단 1599-2000, 교육부 044-203-6271 — 다른 창구로 넘기는 정보라 글에 쓰지 않음
- 원천공제의무자 일정(10/12 신고·납부, 10/20 기한후신고) — 회사 쪽 일정이라 대출자 대상 글과 맞지 않음
- 근로소득 조회 방법·홈택스 링크 — 유예 신청 절차와 직접 관련이 없음
- ICL 누리집 주소(icl.go.kr) 버튼 — '행동 링크' 줄에 없는 주소라 버튼 목적지로 쓸 수 없음(규칙 8). 행동 링크에는 홈택스만 있음
- 회사가 공제하고 납부하지 않은 경우의 납부 인정(제24조③) — 유예 여부와 관련이 적음
