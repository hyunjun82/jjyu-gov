## 쓰지 않은 것
- 근로능력 없음 판정 기준(의학적 평가 점수, 질환·장애 기준, 활동능력 점수 등) — 두 원문에 판정 기준이 없음. 최종 판정은 주민센터에 문의하라는 안내(f13)만 있어 소제목 4는 추가 원문(보건복지부 근로능력평가 기준 고시 등)이 필요함
- 근로능력평가 신청 방법·신청처·제출서류 목록 — 원문에는 지자체가 공단에 의뢰한다는 내용(f6)과 진단서·진료기록지 언급(f7)만 있고, 수급자가 신청하는 절차는 없음
- 단계별 처리 기간 — 원문에 기간 숫자가 없음
- 조회하기 버튼 URL — 원문에 '행동 링크' 줄이 없어 버튼 목적지 URL을 고를 수 없음
- 심사청구 대상이 아닌 경우 표(단순 안내·처분의 신청·다른 기관의 처분·자격·급여·징수) — 국민연금 심사청구용 공통 표라서 근로능력평가 주제와 관계없음
- 해외이용 번호, 공단 주소, 만족도 조사 — 글 주제와 관계없는 메뉴·푸터 내용
