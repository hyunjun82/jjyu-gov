# 리라이트 — 연말정산 허브(year-end-tax) 스포크 5편 (2026-10-20, 옛 글 6월 작성). 옛 글은 서론 없음·출처가 국세청·홈택스 첫 화면뿐이라 사실이 얇다. 주소(slug)·옛 파일·export 이름 그대로
# 타이틀·소제목: 사장님이 10-20 확정. 소제목은 네이버 자동완성에 실제로 뜬 말만(2·5번 일부는 자동완성이 입력어를 그대로 돌려줌). 타이틀은 낱말 중복 없이 A부터 B까지
# 업그레이드 원칙: ①서론 200자 안에서 검색한 질문의 답을 먼저 말하고 바로 할 일로 넘긴다 ②소제목 카드는 4개, 카드마다 소제목 → (행동이 있으면 버튼) → 표 → 설명 ③숫자·비교·단계가 있는 카드는 표(3열 이하) ④어려운 용어는 처음 한 번 풀어 쓰고 문장은 짧게 ⑤원문으로 확인되지 않는 사실은 쓰지 않는다
# 원문: 국세청 연말정산 안내(nts.go.kr)·국세상담센터 Q&A(call.nts.go.kr)·국세청 보도자료(2026년 1월 개통)·홈택스 간소화 서비스·소득세법·국세기본법. 2026-10-20 Playwright 로 직접 연다
# 주의(귀속연도): 지금(2026-10)은 2026년 귀속 연말정산 안내가 나오기 전이다. 원문의 날짜·한도·금액은 어느 해 귀속인지(예: 2025년 귀속, 2026년 1월 실시)를 이름표로 붙여 쓴다. 올해(2026년 귀속) 일정·한도를 지어내지 않는다
# 주의(구분): 연말정산(근로소득, 회사가 2월 급여 때 정산)과 종합소득세(5월 확정신고)·경정청구(5년)는 다른 절차다 — 섞지 않는다. 한정 표현(다만·경우에만·예외)을 빠뜨리지 않는다
