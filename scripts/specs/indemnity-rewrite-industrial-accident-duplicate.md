# 주의(쓰지 않는 것): 산재 요양급여 금액·산재 승인 절차(근로복지공단 소관, 열지 않음), 보험사별 지급·거절 사례, 후기·블로그 내용, 실손24 '청구서비스 중단 안내' 공지(제목만 있고 기간·대상이 원문에 없다)
# 주의(구분): ①약관은 다른 법령에 따라 보상받는 의료비를 실손에서 어떻게 다루는지(공제·보상하지 않는 사항)를 원문 글자 그대로 — 산재가 그 문구에 해당하는지는 원문에 적힌 범위까지만 ②이미 실손을 받은 뒤 산재로 같은 진료비를 받으면 어떻게 되는지(환수·정산)는 원문에 근거가 있을 때만 쓰고 없으면 notUsed ③청구 서류는 손해보험협회 FAQ 원문 그대로
# 주의(행동): 독자가 지금 할 일 = 산재로 처리되는 진료비와 본인이 낸 진료비를 영수증에서 나눠 받아 두고 실손24 또는 보험사 앱으로 청구하는 것. 상단 버튼 문구는 '산재'를 넣어 다른 글과 겹치지 않게(버튼 도배 게이트)
# 주의(구성): 금액·비율·횟수가 든 비교는 카드 안 표(3열 이하)로 한 번 이상 넣는다. 표 값은 facts 의 값 그대로. 공제금액은 원문 표기 순서·이름표 그대로 '1만원(의원·병원) 또는 2만원(종합병원·상급종합병원)' 형태로 쓴다(이름표를 숫자 앞에 놓거나 '의원이면 1만원'처럼 풀어 쓰면 짝 검사에 걸린다). 세대·특약 한정이 붙은 값은 반드시 그 말을 함께 쓰고 '5세대'는 '5세대 실손'처럼 쓴다('5월' 같은 조합 금지). 약관 인용은 원문 글자 그대로, 한정 표현(다만·경우에만 등)은 빠뜨리지 않는다.
