# 한 편짜리 신규 — 2026-10-09. 소재: 소진공 혁신성장촉진자금 직접대출(공고 3-2, 융자규모 4,800억원 내외) — 혁신형·일반형.
# 주의(표기): 날짜·연도는 약식('25, '26.7.15.)으로 쓰지 말고 2025년, 2026년 7월 15일처럼 풀어 쓴다(약식 연도는 숫자로 오독돼 대조에서 걸린다)
# 주의(순서): 한도를 표·문장으로 나열할 때는 금액이 작은 쪽부터 쓴다 — 일반형(운전자금 1억원·시설자금 5억원) → 혁신형(운전자금 2억원·시설자금 10억원) 순서. 기업당 총 융자한도(대출잔액 합산 운전자금 5억원 이내, 시설자금 포함 시 10억원 이내)는 유형별 연간 한도와 다른 값이라 따로 이름표를 붙여 쓴다
# 소제목은 네이버 자동완성('혁신성장촉진자금 조건', '대상', '일반형', '신청', '10월')에 뜬 말로 지음. 자동완성의 '사업계획서'·'신용점수'·'후기'는 공고 원문에 없으면 쓰지 않는다
# 주의: 혁신형(수출 소상공인·2년 연속 매출 10% 이상 신장·스마트공장 도입·강한소상공인·로컬크리에이터·소상공인 졸업후보기업·직접대출 성실상환)과 일반형(스마트기술·백년소상공인·사회연대경제 조직·신사업창업사관학교 수료생)의 대상·한도를 섞지 않는다. 한도: 혁신형 연간 운전자금 2억원·시설자금 10억원, 일반형 운전자금 1억원·시설자금 5억원. 기간: 운전 5년(거치 2년 포함), 시설 8년(거치 3년 포함). 금리 기준금리+0.4%p, 2026년 4분기(10.10~1.9) 연 4.52%. 소상공인 졸업후보기업은 소기업 진입 시 금리 0.4%p 인하(원문 예시: 숙박·음식점업 평균매출 4.5억원 이상~15억원 이하, 상시근로자 3명 이상 5명 미만)
# 근거: 소상공인시장진흥공단(소진공) '2026년 소상공인 정책자금 융자계획 공고(5차 변경, 2026.10.2)'와 '2026년 4분기 소상공인정책자금 금리 안내(2026.10.6, 적용 2026.10.10~2027.1.9)'. 금리는 변동금리라 분기마다 바뀐다 — 4분기 금리 숫자에는 반드시 '2026년 4분기(10.10~1.9) 기준'이라고 적용 기간을 붙이고, 그 뒤 금리를 추정하지 않는다
# 주의: 자금마다 한도·금리·대상 숫자가 다르다 — 항상 자금 이름표(일반형/희망형/도약형, 혁신형/일반형 등)를 붙이고 섞지 않는다. 신청은 소상공인정책자금 누리집(ols.semas.or.kr) 온라인 또는 소진공 지역센터(전국 80곳) 방문. 원문에 없는 심사기간·입금일·접수 마감일은 쓰지 않는다. 문의처 1533-0100(소상공인정책자금 통합콜센터)·1357은 원문에 있으나 '문의하세요'로 떠넘기지 말고 원문의 조건·서류·절차를 먼저 충분히 쓴다
