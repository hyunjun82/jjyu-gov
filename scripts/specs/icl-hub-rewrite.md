# 리라이트 — 취업후상환 학자금대출 허브 본글 (2026-10-26, 노출 없는 옛 글·타이틀 불량). 옛 글은 원문 추출본 없음. 허브 Spokes 배열은 보존한다.
# 타이틀·소제목: 사장님 10-24·10-26 "40자 이내·소제목 4개와 일치·같은 낱말 두 번 금지·타이틀은 네이버 자동완성 연관검색어로". 자동완성: 취업 후 상환 학자금대출 이자·기간·금리·의무상환·상환. 허브는 개요(제도·금리·이자·소득요건), 상환기준소득 상세·일반 상환과의 비교는 스포크가 답한다.
# 원문: 한국장학재단 취업 후 상환 학자금대출 소개(tuition04_01_01)·상환의무(tuition05_01_01), 교육부 보도자료(moe.go.kr boardSeq=105052), 국세청 취업 후 학자금 상환(icl.go.kr).
# 주의(옛 글 오류 점검): 옛 글의 "재학 중에는 이자만 납부", "2026년부터 소득 요건 폐지"는 한국장학재단 안내에서 확인되는 표기와 다시 대조한다. 한국장학재단 상환의무 페이지에는 "대출 실행시점부터 단리로 일할 계산, 유예 기간에도 이자 발생"이라는 문구가 있다. 소득요건 폐지는 교육부 보도자료 또는 재단 안내에 시점과 범위(등록금대출인지 전체인지)가 글자 그대로 있을 때만 쓴다.
# 주의(구분): 금리는 학기와 대출 종류(취업 후 상환은 변동금리) 기준을 원문 표기대로. 한 페이지의 1.7%는 계산 예시용이라는 표기가 있으므로 확정 금리처럼 쓰지 않는다.
