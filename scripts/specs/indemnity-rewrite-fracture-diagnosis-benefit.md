# 원문: ①보험업감독업무시행세칙 [별표 15] 실손의료보험 표준약관(저장본, CAPTURED-BY) ②손해보험협회 실손의료보험 FAQ ③금융감독원 보험금 청구 안내
# 주의(쓰지 않는 것): 골절 진단비 금액·보험사별 지급 조건, 수술비 특약, 골절 치료 방법, 보험사별 지급·거절 사례, 후기·블로그 내용, 실손24 '청구서비스 중단 안내' 공지(제목만 있고 기간·대상이 원문에 없다)
# 주의(구분): ①실손은 실제로 낸 의료비를 보상하고 진단비는 진단 시 정액을 주는 별도 상품이라는 구분은 협회·금감원 원문에 있는 만큼만 ②골절 치료의 입원·통원·처방조제는 약관의 보상 구조(급여/비급여)와 공제·한도를 세대 이름표와 함께 그대로 ③청구 서류는 FAQ 원문 그대로
# 주의(행동): 독자가 지금 할 일 = 골절 치료 영수증과 입퇴원확인서·진단서로 실손24에서 청구하는 것. 상단 버튼 문구는 '골절'를 넣어 다른 글과 겹치지 않고 끝말을 '확인하기'로 쓰지 않는다(버튼 도배 게이트: 확인하기 비율 상한 40%).
# 주의(서론=클릭 공식, 사장님 10-13): 서론은 버튼을 누르게 만드는 글이다. 첫 문장은 독자가 검색한 질문의 답, 숫자는 facts 에서 하나만(낯선 용어 둘 이하), '다만 …에 따라 갈려서' 식 반전 한 번, 마지막은 '내 …'를 주어로 한 행동 한 문장. 버튼은 라벨이 약속한 곳으로 실제 가는 공식 딥링크여야 하고 계산기·도구는 만들지 않는다. 숙제형('서류 챙기기·확인해 두기') 라벨은 쓰지 않는다. 상단 버튼(heroAct)의 href 는 반드시 spec 의 button 주소(약관 원문·FAQ 페이지로 보내지 않는다). 서론 마지막 행동 문장에는 상단 버튼 라벨의 낱말(예: 청구·실손24로·금액)을 절반 이상 그대로 쓰고, 'X 하기 전에 Y부터 가늠해 두는 게 순서' 식 숙제 문장은 쓰지 않는다. 서론에 숫자는 하나, '내 … 보세요' 틀은 쓰지 않는다
# 주의(구성): 금액·비율·횟수가 든 비교는 카드 안 표(3열 이하)로 넣는다. 표 값은 facts 의 값 그대로. 공제금액은 원문 표기 순서·이름표 그대로 '1만원(의원·병원) 또는 2만원(종합병원·상급종합병원)' 형태로 쓴다(이름표를 숫자 앞에 놓거나 '의원이면 1만원'처럼 풀어 쓰면 짝 검사에 걸린다). 세대·특약 한정이 붙은 값은 반드시 그 말을 함께 쓰고 '5세대'는 '5세대 실손'처럼 쓴다('5월' 같은 조합 금지). 약관 인용은 원문 글자 그대로, 한정 표현(다만·경우에만 등)은 빠뜨리지 않는다.
