# 리라이트 — 양육비 선지급제 스포크 3편 (2026-10-26, 노출 없는 옛 글·타이틀 품질 불량). 옛 글(2026-07 작성)은 원문 추출본 없음, "2026년 10월부터"라고만 적어 시행일이 모호하다.
# 타이틀·소제목: 사장님 10-24·10-26 "40자 이내·소제목 4개와 일치·같은 낱말 두 번 금지·타이틀은 네이버 자동완성 연관검색어로". 자동완성: 양육비 선지급제 신청 방법·서류·폐지·소득·소급·시행일·기간·지급기간.
# 원문: 양육비이행관리원(childsupport.or.kr) 공지(소득기준 폐지·월 20만 원·만 18세까지), 정책브리핑 '10월부터 달라지는 제도'(소득기준 폐지 시행일), 정책브리핑 '7월부터 양육비 선지급제 시행', 찾기쉬운 생활법령 양육비 선지급 신청.
# 주의(시간): 소득기준 폐지 시행일은 정책브리핑 "하반기 달라지는 제도"(newsId=148967360)에 "성평등가족부는 10월 29일부터 … 소득기준을 폐지한다"로 적혀 있다. 작성일(10-26)은 시행 전이므로 "폐지됩니다/예정"으로 쓴다.
# 주의(쓰지 않는 것): 블로그 후기, 지급 대상 가구 수 추산, 채무자 제재 세부, 원문 표기가 엇갈리는 지급 기간(만 18세까지 vs 성년까지)은 양육비이행관리원 표기(만 18세까지)만 쓴다.
