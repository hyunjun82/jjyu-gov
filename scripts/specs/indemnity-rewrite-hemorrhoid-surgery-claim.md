# 주의(구분): ①약관에서 항문·직장 질환(질병코드 K60~K64 등)이 비급여 특약에서 어떻게 다뤄지는지 원문 그대로 — 급여 수술은 기본형 입원·통원 구조(세대 한정)로 설명 ②1세대·2세대 차이는 협회 안내·FAQ 원문에 있는 것만 ③청구 서류는 입원 서류 원문 그대로(진단서·수술확인서 등)
# 주의(행동): 독자가 지금 할 일 = 수술 전에 진단서의 질병코드와 급여·비급여 항목을 확인하고, 퇴원 때 입퇴원확인서와 영수증을 챙겨 청구하는 것. 상단 버튼 문구는 '치질'를 넣어 다른 글과 겹치지 않게(버튼 도배 게이트)
# 주의(구성): 금액·비율·횟수가 든 비교는 카드 안 표(3열 이하)로 한 번 이상 넣는다. 표 값은 facts 의 값 그대로. 공제금액은 원문 표기 순서·이름표 그대로 '1만원(의원·병원) 또는 2만원(종합병원·상급종합병원)' 형태로 쓴다(이름표를 숫자 앞에 놓거나 '의원이면 1만원'처럼 풀어 쓰면 짝 검사에 걸린다). 세대·특약 한정이 붙은 값은 반드시 그 말을 함께 쓰고 '5세대'는 '5세대 실손'처럼 쓴다('5월' 같은 조합 금지). 약관 인용은 원문 글자 그대로, 한정 표현(다만·경우에만 등)은 빠뜨리지 않는다.
