# 한 편짜리 신규 — 2026-10-10. 소재: 찾기쉬운 생활법령 '가처분 신청' + 민사집행법. 부동산처분금지가처분의 요건(피보전권리·보전의 필요성), 집행 방법(법원사무관 등이 등기소에 가처분 사항 기입을 등기 촉탁), 담보제공명령, 본안 제소 기간(제소기간 도과 시 채무자가 가처분 취소를 신청할 수 있는 기준 기간)은 원문 글자 그대로. 가압류(provisional-attachment-application)와 섞지 않는다. 판례 인용은 원문에 있을 때만
# 타이틀은 사장님이 정한 것을 글자 그대로 쓴다. 소제목은 네이버 자동완성에 뜬 말(부동산 가처분 신청·가처분 신청 요건·가처분 등기촉탁·가처분 본안소송)로 지음
# 주의(연도·개정): 법령은 개정으로 바뀐다 — 열린 원문의 현재 기준만 쓰고 개정 전후를 섞지 않는다. 약식 연도 금지. 원문에 없는 금액·기간·비율은 쓰지 않고 notUsed 에 사유와 함께 남긴다
# 주의(구성): 기간·금액·비율·기한이 든 비교(예: 가처분 취소 신청 제소기간·담보 공탁, 집행 단계별 기한)는 카드 안 표(3열 이하)로 반드시 한 번 이상 넣는다. 표 값은 facts 의 값 그대로. 숫자·범위가 하나도 없으면 표를 만들지 말고 원문 숫자부터 찾아 쓴다
