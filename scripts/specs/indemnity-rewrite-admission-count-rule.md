# 리라이트 — 실비 스포크 실비 입원 횟수 (2026-10-13). 노출 0 글 중 수요가 낮지만 타이틀이 어려운 글을 쉬운 말로 다시 쓴다(사장님 10-13 "조금 더 이해 쉽게"). 자동완성 수요 거의 없음(실비 입원일수 1)
# 타이틀·소제목: 사장님이 10-13 채팅에서 확정한 쉬운 타이틀 그대로. 타이틀에는 숫자를 쓰지 않는다
# 쉬운 글 원칙(사장님 10-13 "조금 더 이해 쉽게"): 서론에서 이 글로 알게 되는 것을 먼저 보이고, 어려운 약관 용어(보장대상의료비·재가입주기 등)는 처음 나올 때 한 번 풀어 쓴다. 문장은 짧게, 한 문장에 숫자 둘 이하로 쓴다. 약관 인용·숫자는 원문 그대로이고 풀이는 원문에 있는 뜻만 쓴다
# 원문: ①보험업감독업무시행세칙 [별표 15] 실손의료보험 표준약관(저장본, CAPTURED-BY) ②손해보험협회 실손의료보험 FAQ ③금융감독원 보험금 청구 안내
# 주의(쓰지 않는 것): 병원별 입원 기록 방식, 요양병원 입원 기준(별도 글), 보험사별 지급·거절 사례, 후기·블로그 내용, 실손24 '청구서비스 중단 안내' 공지(제목만 있고 기간·대상이 원문에 없다)
# 주의(구분): ①입원의 정의(의료기관에 입실하여 계속하여 6시간 이상 체류)와 입원 의료비 한도의 단위(1회당·연간·입원일수 등)는 약관 원문 그대로 ②퇴원 후 다시 입원했을 때 같은 입원으로 묶는지(동일 질병 재입원 합산 규정 등)는 원문에 있을 때만 쓰고, 없으면 '약관에 구분 문구가 없다'가 아니라 원문에서 확인한 입원 한도 구조만 설명하고 notUsed 에 둔다 ③세대·특약 한정이 붙은 입원 한도(병원급별 1회 한도 등)는 이름표와 함께
# 주의(행동): 독자가 지금 할 일 = 퇴원 영수증과 입퇴원확인서에서 입원 시작일·종료일을 확인하고, 재입원이면 날짜를 나눠 실손24 또는 보험사 앱으로 청구하는 것. 상단 버튼 문구는 '입원'를 넣어 다른 글과 겹치지 않고 끝말을 '확인하기'로 쓰지 않는다(버튼 도배 게이트: 확인하기 비율 상한 40%)
# 주의(구성): 금액·비율·횟수가 든 비교는 카드 안 표(3열 이하)로 한 번 이상 넣는다. 표 값은 facts 의 값 그대로. 공제금액은 원문 표기 순서·이름표 그대로 '1만원(의원·병원) 또는 2만원(종합병원·상급종합병원)' 형태로 쓴다(이름표를 숫자 앞에 놓거나 '의원이면 1만원'처럼 풀어 쓰면 짝 검사에 걸린다). 세대·특약 한정이 붙은 값은 반드시 그 말을 함께 쓰고 '5세대'는 '5세대 실손'처럼 쓴다('5월' 같은 조합 금지). 약관 인용은 원문 글자 그대로, 한정 표현(다만·경우에만 등)은 빠뜨리지 않는다. '원문에 없으니 문의하세요'식 떠넘기는 문장은 쓰지 않는다 — 없는 항목은 빼서 notUsed 에 둔다
