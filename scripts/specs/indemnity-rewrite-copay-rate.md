# 리라이트 — 실비 스포크 실손 자기부담금 (2026-10-13). 네이버 노출 0 글 우선 리라이트 10편 중 하나(사장님 10-13 지시). 자동완성: 실손 자기부담금(5세대·200만원·4세대·3세대·2세대·한도). 옛 글은 약관 문구만 되풀이하거나 타이틀 끝이 어색했다

# 원문: ①보험업감독업무시행세칙 [별표 15] 실손의료보험 표준약관(저장본, CAPTURED-BY) ②손해보험협회 실손의료보험 안내 ③손해보험협회 실손의료보험 FAQ
# 주의(쓰지 않는 것): 실제 환급액 계산 결과(개인별로 다르다), 건강보험 본인부담률 표 전체(건보 소관, 열지 않음), 보험사별 지급·거절 사례, 후기·블로그 내용, 실손24 '청구서비스 중단 안내' 공지(제목만 있고 기간·대상이 원문에 없다)
# 주의(구분): ①5세대 기본형 자기부담(입원 20%, 통원 ①~③ 중 큰 금액)과 특약1·특약2 비율(30%·50%)은 약관 표 그대로, 세대 이름표와 함께 ②연간 한도(입원 자기부담 연 200만원 초과분 보상, 특약 한도 등)는 원문 숫자 그대로 ③계산 구조는 약관 공식 그대로 한 번만 보이고 실제 금액을 지어내지 않는다 ④2~4세대 비율은 협회 안내 원문에 있을 때만
# 주의(행동): 독자가 지금 할 일 = 내 실손의 세대와 특약 구성을 확인하고, 약관 공식에 영수증 금액을 대입해 보는 것. 상단 버튼 문구는 '자기부담금'를 넣어 다른 글과 겹치지 않게(버튼 도배 게이트)
# 주의(구성): 금액·비율·횟수가 든 비교는 카드 안 표(3열 이하)로 한 번 이상 넣는다. 표 값은 facts 의 값 그대로. 공제금액은 원문 표기 순서·이름표 그대로 '1만원(의원·병원) 또는 2만원(종합병원·상급종합병원)' 형태로 쓴다(이름표를 숫자 앞에 놓거나 '의원이면 1만원'처럼 풀어 쓰면 짝 검사에 걸린다). 세대·특약 한정이 붙은 값은 반드시 그 말을 함께 쓰고 '5세대'는 '5세대 실손'처럼 쓴다('5월' 같은 조합 금지). 약관 인용은 원문 글자 그대로, 한정 표현(다만·경우에만 등)은 빠뜨리지 않는다.
