# 한 편짜리 신규 — 2026-10-07. 계기: 매일경제 10.6 "퇴직금 불려보려다 피눈물 난다…" (DB→DC 전환 급증 기사). 기사·의원실 자료의 전환자 수·손실률은 1차 출처가 아니라 쓰지 않는다 — 제도(DB·DC 차이, 전환 규정, 되돌리기 가능 여부)만 법령·고용노동부·정책브리핑으로 다시 씀. 기존 retirement-pension-check(조회)·retirement-pension-return-check(수익률)는 건드리지 않는다
# 타이틀·소제목은 네이버 자동완성('퇴직연금 DB형 DC형 차이·전환방법·변경', '퇴직연금 db dc 전환')에 뜬 말로 지음 — 4번째 소제목은 자동완성에 없어 내 초안(보고서 메모)
# 주의: 'DB→DC로 옮긴 적립금을 다시 DB로 되돌리는 것'은 고용노동부 행정해석(질의회시)에 명시된 문장이 수집에서 확인될 때만 쓴다. 확인 안 되면 notUsed 로 남기고 '되돌릴 수 없다'를 단정하지 않는다. 투자 권유·손실 단정 금지('전환하면 손해' 같은 말 금지)
