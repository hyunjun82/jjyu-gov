# 리라이트 — 실비 스포크 단체실손 (2026-10-13). 네이버 노출 0 글 우선 리라이트 10편 중 하나(사장님 10-13 지시). 자동완성: 단체실손(보험·개인전환·중지·전환·비교·청구). 옛 글은 약관 문구만 되풀이하거나 타이틀 끝이 어색했다
# 타이틀·소제목: 사장님이 10-13 채팅에서 "어색한 타이틀은 자연스럽게 교체"로 확정한 안 그대로
# 원문: ①손해보험협회 실손의료보험 안내 ②손해보험협회 실손의료보험 FAQ ③보험업감독업무시행세칙 [별표 15] 실손의료보험 표준약관(저장본, CAPTURED-BY) ④금융감독원 보험금 청구 안내
# 주의(쓰지 않는 것): 회사별 단체실손 보장 내용, 단체보험 보험료, 보험사별 지급·거절 사례, 후기·블로그 내용, 실손24 '청구서비스 중단 안내' 공지(제목만 있고 기간·대상이 원문에 없다)
# 주의(구분): ①여러 실손에 가입했을 때 실제 낸 치료비보다 많이 받을 수 없다(비례보상)는 약관·FAQ 문구 그대로 ②단체실손과 개인실손 중복 가입, 중지(휴지)·개인 전환 제도는 협회 안내·FAQ 원문에 있는 내용만 ③청구는 한 보험사에 서류를 내면 대행되는 서비스(FAQ 원문)와 함께 쓸 수 있다
# 주의(행동): 독자가 지금 할 일 = 내가 가입한 실손 목록을 확인하고, 중복이면 중지·전환 조건을 확인한 뒤 한 보험사에 서류를 제출해 청구하는 것. 상단 버튼 문구는 '중지'를 넣어 다른 글과 겹치지 않게(버튼 도배 게이트)
# 주의(구성): 금액·비율·횟수가 든 비교는 카드 안 표(3열 이하)로 한 번 이상 넣는다. 표 값은 facts 의 값 그대로. 공제금액은 원문 표기 순서·이름표 그대로 '1만원(의원·병원) 또는 2만원(종합병원·상급종합병원)' 형태로 쓴다(이름표를 숫자 앞에 놓거나 '의원이면 1만원'처럼 풀어 쓰면 짝 검사에 걸린다). 세대·특약 한정이 붙은 값은 반드시 그 말을 함께 쓰고 '5세대'는 '5세대 실손'처럼 쓴다('5월' 같은 조합 금지). 약관 인용은 원문 글자 그대로, 한정 표현(다만·경우에만 등)은 빠뜨리지 않는다.
