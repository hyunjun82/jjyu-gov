# 리라이트 — 치매상담콜센터 스포크 3편 (2026-10-26, 노출 없는 옛 글·타이틀 불량). 옛 글은 원문 추출본 없음. 가족돌봄스트레스 스포크는 그대로 둔다.
# 타이틀·소제목: 사장님 10-24·10-26 "40자 이내·소제목 4개와 일치·같은 낱말 두 번 금지·타이틀은 네이버 자동완성 연관검색어로". 자동완성: 치매상담콜센터 번호·전화번호, 치매 상담 전화·치매상담전화센터.
# 원문: 중앙치매센터 치매상담콜센터 소개·이용방법·사업안내(nid.or.kr support callcenter / callcenter_use / callcenter_intro).
# 주의(옛 글 오류 점검): 옛 글의 "24시간 365일 무료 상담"은 중앙치매센터 안내와 다르다. 안내는 "연중무휴(07시~22시)", "오전 7시부터 오후 10시까지 치매상담 가능"이다. 요금(무료)은 원문에 글자로 없으면 쓰지 않는다. "익명", "예약 불필요", "응급 우선"도 원문에 없으면 쓰지 않는다.
# 주의(구분): 돌봄상담(일상생활 케어기술·정신행동증상 대처·가족 돌봄 부담과 스트레스 관리·정서적 상담)과 정보상담(치매원인질병·증상·검사·치료·예방·맞춤형 치매관리 서비스·국가 정책)은 원문 표기대로 구분한다. 치매안심센터 안내와 섞지 않는다.
