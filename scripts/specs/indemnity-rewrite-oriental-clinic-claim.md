# 리라이트 — 실비 스포크 한의원 (2026-10-13). 네이버 실검색 "한의원 실비"에서 gov 글이 안 나오고 같은 허브의 첩약 글이 대신 나온다(수요 큼: 청구·보험 적용·서류·1세대·2세대). 60일 노출 0
# 타이틀·소제목: 사장님이 10-13 채팅에서 "노출 안 되는 글 우선"으로 확정한 안 그대로 (제안 → 작성 진행)
# 원문: ①보험업감독업무시행세칙 [별표 15] 실손의료보험 표준약관(저장본, CAPTURED-BY) ②손해보험협회 실손의료보험 FAQ ③금융감독원 보험금 청구 안내
# 주의(쓰지 않는 것): 한의원 진료·한약 가격(원문에 값이 없다), 한방 시술의 의학적 효과, 건강보험 한방 급여 범위(건보 소관, 열지 않음), 첩약 건강보험 시범사업 세부(첩약 글에서 다룸), 보험사별 지급·거절 사례, 후기·블로그 내용, 실손24 '청구서비스 중단 안내' 공지(제목만 있고 기간·대상이 원문에 없다)
# 주의(구분): ①약관의 한방 관련 문구(한방병원·한의원 비급여, 보상하지 않는 사항의 한방 항목 등)는 원문 글자 그대로 ②침·추나·한약은 소제목에 맞춰 원문에 근거가 있는 것만 — 급여(건강보험 적용 침·추나)와 비급여(한약 등)의 구분과 공제는 약관 구조(기본형·특약, 세대 한정)로만 설명하고 개별 시술을 보상한다고 단정하지 않는다 ③1세대·2세대 차이는 원문(FAQ·약관)에 있는 것만 ④청구 서류는 손해보험협회 FAQ 원문 그대로 ⑤'원문에 없으니 문의하세요'식 떠넘기는 문장은 쓰지 않는다 — 없는 항목은 빼서 notUsed 에 둔다
# 주의(행동): 독자가 지금 할 일 = 한의원 영수증의 진료비 세부산정내역에서 침·추나·한약 항목과 급여·비급여 구분을 확인하고 진단서·진료확인서의 질병코드를 챙겨 실손24 또는 보험사 앱으로 청구하는 것. 상단 버튼 문구는 '한의원'을 넣어 다른 글과 겹치지 않게(버튼 도배 게이트)
# 주의(구성): 금액·비율·횟수가 든 비교는 카드 안 표(3열 이하)로 한 번 이상 넣는다. 표 값은 facts 의 값 그대로. 공제금액은 원문 표기 순서·이름표 그대로 '1만원(의원·병원) 또는 2만원(종합병원·상급종합병원)' 형태로 쓴다(이름표를 숫자 앞에 놓거나 '의원이면 1만원'처럼 풀어 쓰면 짝 검사에 걸린다). 세대·특약 한정이 붙은 값은 반드시 그 말을 함께 쓰고 '5세대'는 '5세대 실손'처럼 쓴다('5월' 같은 조합 금지). 약관 인용은 원문 글자 그대로, 한정 표현(다만·경우에만 등)은 빠뜨리지 않는다
