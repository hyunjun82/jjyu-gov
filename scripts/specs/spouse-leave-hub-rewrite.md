# 리라이트 — 배우자 출산휴가급여 허브 본글 (2026-10-26, 노출 없는 옛 글·타이틀 불량). 옛 글은 원문 추출본 없음. 허브 Spokes 배열은 보존한다.
# 타이틀·소제목: 사장님 10-24·10-26 "40자 이내·소제목 4개와 일치·같은 낱말 두 번 금지·타이틀은 네이버 자동완성 연관검색어로". 자동완성: 배우자 출산휴가일·기간·급여·20일·분할. 허브는 개요(대상·20일 유급·사용 기한·신청), 분할·급여 계산·회사/정부 구분·9월 변경은 스포크가 답한다.
# 원문: 고용노동부 일생활균형 배우자 출산휴가(worklife.kr paternity_leave), 고용24 배우자 출산휴가급여(work24 SI00000395), 고용노동부 보도자료 시행령 개정안(2026-08-11, PDF), 정책브리핑 2026년 하반기 달라지는 제도.
# 주의(시간): 9월 18일부터 배우자 휴가·휴직이 확대됐다(시행 뒤). 보도자료 PDF·정책브리핑에 글자 그대로 있는 사항만 쓴다.
# 주의(옛 글 오류 점검): "모르면 손해보는 함정" 같은 표현과 확인되지 않은 상한액·기간은 쓰지 않는다. 20일 유급·120일 이내·3회 분할·통상임금 지급은 고용24·고용노동부 안내 표기와 대조한다.
