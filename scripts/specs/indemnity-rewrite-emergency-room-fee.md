# 리라이트 — 실비 스포크 응급실 (2026-10-13). 네이버 실검색 "응급실 실비"에서 gov 글이 거의 안 나온다(수요 큼: 청구·청구 서류·독감·청구 되나요·처리·한도). 60일 노출 0. 옛 글은 '응급환자가 아니면 관리료가 안 나오나?'로 약관 문구만 되풀이했다
# 타이틀·소제목: 사장님이 10-13 채팅에서 "노출 안 되는 글 우선"으로 확정한 안 그대로 (제안 → 작성 진행)
# 원문: ①보험업감독업무시행세칙 [별표 15] 실손의료보험 표준약관(저장본, CAPTURED-BY) ②손해보험협회 실손의료보험 FAQ ③금융감독원 보험금 청구 안내
# 주의(쓰지 않는 것): 응급실 진료비·관리료 금액(원문에 값이 없다), 응급환자 의학적 분류(KTAS 등), 응급의료법 조문(열지 않음), 보험사별 지급·거절 사례, 후기·블로그 내용, 실손24 '청구서비스 중단 안내' 공지(제목만 있고 기간·대상이 원문에 없다)
# 주의(구분): ①약관에 응급실·응급환자·응급의료 관련 문구(보상하지 않는 사항, 입원의 정의, 통원 정의 등)가 있으면 원문 글자 그대로, 없는 것은 '이름이 없다'고 쓰지 말고 원문에서 확인한 조항으로만 설명한다 ②'일반 환자도 되나?'는 약관에서 응급 여부가 보상 조건으로 적혀 있는지를 원문 문구로만 답한다(없으면 쓰지 않고 notUsed) ③관리료는 급여·비급여 구분과 공제 방식(원문 비율·금액, 세대 한정)으로만 설명한다 ④한도는 원문의 통원·입원 한도(세대·특약 이름표와 함께) 그대로 ⑤청구 서류는 손해보험협회 FAQ 원문 그대로 ⑥'원문에 없으니 문의하세요'식 떠넘기는 문장은 쓰지 않는다 — 없는 항목은 빼서 notUsed 에 둔다
# 주의(행동): 독자가 지금 할 일 = 응급실 영수증에서 응급의료관리료·진료비 항목과 급여·비급여를 확인하고, 입원이면 입퇴원확인서까지 챙겨 실손24 또는 보험사 앱으로 청구하는 것. 상단 버튼 문구는 '응급실'을 넣어 다른 글과 겹치지 않게(버튼 도배 게이트)
# 주의(구성): 금액·비율·횟수가 든 비교는 카드 안 표(3열 이하)로 한 번 이상 넣는다. 표 값은 facts 의 값 그대로. 공제금액은 원문 표기 순서·이름표 그대로 '1만원(의원·병원) 또는 2만원(종합병원·상급종합병원)' 형태로 쓴다(이름표를 숫자 앞에 놓거나 '의원이면 1만원'처럼 풀어 쓰면 짝 검사에 걸린다). 세대·특약 한정이 붙은 값은 반드시 그 말을 함께 쓰고 '5세대'는 '5세대 실손'처럼 쓴다('5월' 같은 조합 금지). 약관 인용은 원문 글자 그대로, 한정 표현(다만·경우에만 등)은 빠뜨리지 않는다
