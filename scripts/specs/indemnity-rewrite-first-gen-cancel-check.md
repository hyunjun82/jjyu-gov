# 리라이트 — 실비 스포크 예전(1세대) 실손 해지 (2026-10-13). 노출 0 글 중 수요가 낮지만 타이틀이 어려운 글을 쉬운 말로 다시 쓴다(사장님 10-13 "조금 더 이해 쉽게"). 자동완성 수요 거의 없음(1세대 실손 해지 0)
# 타이틀·소제목: 사장님이 10-13 채팅에서 확정한 쉬운 타이틀 그대로. 타이틀에는 숫자를 쓰지 않는다
# 쉬운 글 원칙(사장님 10-13 "조금 더 이해 쉽게"): 서론에서 이 글로 알게 되는 것을 먼저 보이고, 어려운 약관 용어(보장대상의료비·재가입주기 등)는 처음 나올 때 한 번 풀어 쓴다. 문장은 짧게, 한 문장에 숫자 둘 이하로 쓴다. 약관 인용·숫자는 원문 그대로이고 풀이는 원문에 있는 뜻만 쓴다
# 원문: ①손해보험협회 실손의료보험 안내 ②손해보험협회 실손의료보험 상품 소개 ③손해보험협회 실손의료보험 FAQ ④보험업감독업무시행세칙 [별표 15] 실손의료보험 표준약관(저장본, CAPTURED-BY)
# 주의(쓰지 않는 것): 해지 후 보험료 변화 금액·보험사별 전환 혜택(원문에 값이 없는 것), 보험사별 지급·거절 사례, 후기·블로그 내용, 실손24 '청구서비스 중단 안내' 공지(제목만 있고 기간·대상이 원문에 없다)
# 주의(구분): ①'예전 실손'은 세대 구분(1세대 등 판매 시기)을 원문(협회 안내)의 판매 시기·재가입주기 표 그대로 설명한다 — 타이틀에는 숫자를 쓰지 않았지만 본문에는 세대 이름을 원문대로 쓴다 ②해지하면 이전 세대의 보장(자기부담·재가입주기 없음 등)을 다시 받을 수 없다는 점은 원문에 근거가 있는 만큼만, 전환 시 비교 항목(보장 범위·자기부담·보험료 갱신)도 원문 그대로 ③해지 후 재가입은 가입 가능한 상품(5세대 등)과 알릴 의무·유병력자 실손 안내를 원문에 있는 것만
# 주의(행동): 독자가 지금 할 일 = 내 실손이 어느 세대인지 확인하고, 해지하기 전에 전환 조건과 비교해 보는 것. 상단 버튼 문구는 '해지'를 넣어 다른 글과 겹치지 않고 끝말을 '확인하기'로 쓰지 않는다(버튼 도배 게이트: 확인하기 비율 상한 40%)
# 주의(구성): 금액·비율·횟수가 든 비교는 카드 안 표(3열 이하)로 한 번 이상 넣는다. 표 값은 facts 의 값 그대로. 공제금액은 원문 표기 순서·이름표 그대로 '1만원(의원·병원) 또는 2만원(종합병원·상급종합병원)' 형태로 쓴다(이름표를 숫자 앞에 놓거나 '의원이면 1만원'처럼 풀어 쓰면 짝 검사에 걸린다). 세대·특약 한정이 붙은 값은 반드시 그 말을 함께 쓰고 '5세대'는 '5세대 실손'처럼 쓴다('5월' 같은 조합 금지). 약관 인용은 원문 글자 그대로, 한정 표현(다만·경우에만 등)은 빠뜨리지 않는다.
