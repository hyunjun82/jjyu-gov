# 한 편짜리 신규 — 2026-10-08. 소재: 국토교통부 10.6 보도자료 「전세사기특별법」 시행령 개정안 6일 국무회의 의결 — 임차보증금 최소보장제(보증금 1/3 회복 보장)·선지급-후정산 제도 11.13 시행. 기존 jeonse-fraud-victim(피해자 결정 신청 안내)은 건드리지 않는다 — 이 글은 '최소지원금·선지급금' 신설 제도
# 타이틀·소제목은 네이버 자동완성('전세사기 최소보장제 / 대상 / 금액 / 신청방법 / 시행일')에 뜬 말로 지음. 자동완성에 뜬 '소급'은 원문에 없어 쓰지 않는다
# 주의: 시행일은 법 개정(2026.5.12 공포, 11.13 시행)에 따른 11.13이고, 시행령은 의결을 마쳤으며 원문은 '시행 예정'이라고 쓴다 — '예정'을 뺀 단정으로 바꾸지 않는다. 최소지원금(경·공매 종료 후 피해회복금액이 보증금의 3분의 1에 못 미칠 때 부족분)과 선지급금(경·공매 등 종료 전, 신탁사기 등 무권계약자 대상)을 섞어 쓰지 않는다 — 항상 두 이름표를 붙인다. 원문의 지급 사례(보증금 1.5억원 등)는 원문이 '가정 시' 예시라고 밝힌 것이므로 쓸 때 '정부 안내 사례(가정)'임을 밝힌다. 신청 시기·제출서류·90일(30일 범위 1회 연장)·이의신청 30일·반납·과태료 최대 3,000만원·LH 업무위탁은 원문 그대로. 피해자 결정이 있어야 신청한다는 근거는 원문 '피해자 결정문' 제출 서류에서만 쓴다
