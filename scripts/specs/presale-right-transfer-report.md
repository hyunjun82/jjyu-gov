# 한 편짜리 신규 — 2026-10-12. 소재: 분양권 전매(입주자 지위 양도) 시 부동산거래신고, 전매제한 기간, 양도소득세. 신고 기한(거래계약 체결일부터 30일 이내)·신고 대상, 전매제한 기간과 예외, 분양권 양도소득세율(보유기간·조정대상지역에 따른 세율)은 법령·국세청·생활법령 원문 그대로. 검색 자료마다 기한(30일/60일)·세율이 시점별로 다르다 — 열린 원문의 현재 시행 기준만 쓰고 옛 기준과 섞지 않는다. 분양권 양도세율은 국세청 세율 페이지의 현행 표만 쓴다. 기존 real-estate-transaction-report(부동산 거래신고 일반)와 겹치지 않게 분양권 전매에 집중한다
# 타이틀은 사장님이 정한 것을 글자 그대로 쓴다. 소제목은 네이버 자동완성에 뜬 말(분양권 전매 신고·분양권 전매제한·분양권 전매 신고 기한·분양권 전매 양도세)을 바탕으로 지음
# 주의(연도·개정): 법령·고시·소득표는 개정으로 바뀐다 — 열린 원문의 현재 기준만 쓰고 개정 전후를 섞지 않는다. 약식 연도 금지. 원문에 없는 금액·기간·비율은 쓰지 않고 notUsed 에 사유와 함께 남긴다
