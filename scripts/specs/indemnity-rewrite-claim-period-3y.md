# 리라이트 — 실비 스포크 청구 기간 (2026-10-13). 네이버 실검색 "실비 청구 기간"에서 gov 글이 안 나오고 같은 허브의 다른 글이 대신 나온다(수요 있음: 3년·5년·지나면·2년·1년). 60일 노출 0. 타이틀에 숫자를 쓰지 않는 규칙 때문에 '3년' 대신 '소멸시효'로 지었다(본문에는 숫자를 원문 그대로 쓴다)
# 타이틀·소제목: 사장님이 10-13 채팅에서 "노출 안 되는 글 우선"으로 확정한 안 그대로 (제안 → 작성 진행)
# 원문: ①상법 제662조(소멸시효) ②보험업감독업무시행세칙 [별표 15] 실손의료보험 표준약관(저장본, CAPTURED-BY — 보험금 청구권 소멸시효·지급 기한) ③손해보험협회 실손의료보험 FAQ ④금융감독원 보험금 청구 안내
# 주의(쓰지 않는 것): 시효가 지난 청구를 보험사가 임의로 받아 주는 사례·비율(원문에 없다), 시효 중단·재판 사례(열지 않음), 보험사별 지급·거절 사례, 후기·블로그 내용, 실손24 '청구서비스 중단 안내' 공지(제목만 있고 기간·대상이 원문에 없다)
# 주의(구분): ①보험금 청구권의 소멸시효 기간(3년)과 시작점('지급사유가 발생한 날'이 아니라 약관·법에 적힌 기준)은 상법·약관 원문 글자 그대로 — 숫자와 기산점 문구를 바꾸지 않는다 ②'지나면 접수될까'는 원문에 접수 자체를 거절한다는 문구가 없으면 단정하지 않고, 원문에 적힌 소멸시효 효과(청구권 소멸)와 '5년·2년·1년' 같은 다른 기간이 원문에 있으면 각각의 대상(예: 계약 종료 후 입원 추가보상 기간 등)과 함께만 쓴다 ③지급 기한(서류 접수 후 3영업일, 조사 시 30영업일, 지급예정일 등)은 표준약관 원문 그대로 ④소멸시효 전에 할 일(서류 챙기기·접수 방법)은 FAQ 원문 그대로 ⑤'원문에 없으니 문의하세요'식 떠넘기는 문장은 쓰지 않는다 — 없는 항목은 빼서 notUsed 에 둔다
# 주의(행동): 독자가 지금 할 일 = 진료일(지급사유 발생일)로부터 시효가 얼마나 남았는지 달력으로 세어 보고, 서류를 받아 실손24 또는 보험사 앱으로 먼저 접수하는 것. 상단 버튼 문구는 '청구 기간'을 넣어 다른 글과 겹치지 않게(버튼 도배 게이트)
# 주의(구성): 기간·횟수가 든 비교는 카드 안 표(3열 이하)로 한 번 이상 넣는다. 표 값은 facts 의 값 그대로. 세대·특약 한정이 붙은 값은 반드시 그 말을 함께 쓰고 '5세대'는 '5세대 실손'처럼 쓴다('5월' 같은 조합 금지). 공제금액을 쓴다면 원문 표기 순서·이름표 그대로 '1만원(의원·병원) 또는 2만원(종합병원·상급종합병원)' 형태로 쓴다. 약관·법 인용은 원문 글자 그대로, 한정 표현(다만·경우에만 등)은 빠뜨리지 않는다
