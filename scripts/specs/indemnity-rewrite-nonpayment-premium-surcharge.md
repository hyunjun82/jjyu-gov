# 원문: ①손해보험협회 실손의료보험 안내 ②손해보험협회 실손의료보험 상품 소개 ③손해보험협회 실손의료보험 FAQ ④보험업감독업무시행세칙 [별표 15] 실손의료보험 표준약관(저장본, CAPTURED-BY)
# 주의(쓰지 않는 것): 할증 보험료 금액·보험사별 할증률(원문에 값이 없다), 보험사별 지급·거절 사례, 후기·블로그 내용, 실손24 '청구서비스 중단 안내' 공지(제목만 있고 기간·대상이 원문에 없다)
# 주의(구분): ①비급여 이용량에 따라 갱신 때 보험료가 할인·할증되는 제도는 협회 안내 원문에 적힌 구간·기준만(숫자는 원문 그대로, 세대 한정 포함) ②할증을 푸는(할증 단계가 내려가는) 조건은 원문에 있을 때만 — 없으면 쓰지 않고 notUsed ③갱신 전에 할 일은 원문에 근거 있는 것만
# 주의(행동): 독자가 지금 할 일 = 내 실손 세대에 할증 제도가 있는지 확인하고, 갱신 전 비급여 이용 내역을 확인하는 것. 상단 버튼 문구는 '할증'를 넣어 다른 글과 겹치지 않게(버튼 도배 게이트)
# 주의(구성): 금액·비율·횟수가 든 비교는 카드 안 표(3열 이하)로 한 번 이상 넣는다. 표 값은 facts 의 값 그대로. 공제금액은 원문 표기 순서·이름표 그대로 '1만원(의원·병원) 또는 2만원(종합병원·상급종합병원)' 형태로 쓴다(이름표를 숫자 앞에 놓거나 '의원이면 1만원'처럼 풀어 쓰면 짝 검사에 걸린다). 세대·특약 한정이 붙은 값은 반드시 그 말을 함께 쓰고 '5세대'는 '5세대 실손'처럼 쓴다('5월' 같은 조합 금지). 약관 인용은 원문 글자 그대로, 한정 표현(다만·경우에만 등)은 빠뜨리지 않는다. '원문에 없으니 문의하세요'식 떠넘기는 문장은 쓰지 않는다 — 없는 항목은 빼서 notUsed 에 둔다
