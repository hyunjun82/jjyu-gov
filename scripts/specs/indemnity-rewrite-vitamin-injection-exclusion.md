# 주의(구분): ①약관 보상하지 않는 사항의 호르몬 투여·보신용 투약·의약외품 문구와 '치료 목적' 인정 요건(허가사항 범위 등)은 원문 글자 그대로 ②비타민·영양주사가 어디에 해당하는지는 원문 문구까지만 — 해당한다/아니다를 단정하지 않는다 ③주사료는 3대 비급여(주사료) 한도·횟수 표에 있는 값만(세대·특약 이름표와 함께) ④청구 서류는 FAQ 원문 그대로
# 주의(행동): 독자가 지금 할 일 = 처방전·진료확인서에 주사의 치료 목적(진단명)이 적혔는지 확인하고, 약제비 영수증과 함께 청구하는 것. 상단 버튼 문구는 '영양주사'를 넣어 다른 글과 겹치지 않게(버튼 도배 게이트)
# 주의(구성): 금액·비율·횟수가 든 비교는 카드 안 표(3열 이하)로 한 번 이상 넣는다. 표 값은 facts 의 값 그대로. 공제금액은 원문 표기 순서·이름표 그대로 '1만원(의원·병원) 또는 2만원(종합병원·상급종합병원)' 형태로 쓴다(이름표를 숫자 앞에 놓거나 '의원이면 1만원'처럼 풀어 쓰면 짝 검사에 걸린다). 세대·특약 한정이 붙은 값은 반드시 그 말을 함께 쓰고 '5세대'는 '5세대 실손'처럼 쓴다('5월' 같은 조합 금지). 약관 인용은 원문 글자 그대로, 한정 표현(다만·경우에만 등)은 빠뜨리지 않는다.
