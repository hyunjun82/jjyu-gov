# 주의(쓰지 않는 것): 보험사별 부활 심사 기준·부활 가능 기한 안내(약관·법에 있는 것만), 해지환급금 금액(상품마다 다르고 원문에 값이 없다), 보험사별 사례, 후기·블로그 내용, 실손24 '청구서비스 중단 안내' 공지(제목만 있고 기간·대상이 원문에 없다)
# 주의(구분): ①'실효'(보험료 연체 등으로 계약의 효력이 상실)는 '해지'와 다르다 — 원문(상법·표준약관)에 적힌 요건·기간(납입최고·유예기간 등 숫자는 원문 그대로)만 쓴다 ②부활은 일정 기간 안에 연체 보험료와 이자를 내고 심사를 받아 계약을 되살리는 것 — 기간·절차·고지 의무는 원문 그대로, 원문에 없으면 쓰지 않는다 ③실효 기간에 생긴 의료비는 청구할 수 없다는 점과 부활 뒤 청구는 원문에 근거가 있을 때만 쓴다(근거가 없으면 notUsed) ④'원문에 없으니 문의하세요'식 떠넘기는 문장은 쓰지 않는다 — 없는 항목은 빼서 notUsed 에 둔다
# 주의(행동): 독자가 지금 할 일 = 보험사 앱·홈페이지에서 내 계약 상태(정상·실효)와 연체 보험료를 확인하고, 실효라면 부활 신청이 가능한 기한을 확인하는 것. 상단 버튼 문구는 주제어('실효'·'부활')를 넣어 다른 글과 겹치지 않게(버튼 도배 게이트)
# 주의(구성): 금액·기간·횟수가 든 비교는 카드 안 표(3열 이하)로 한 번 이상 넣는다. 표 값은 facts 의 값 그대로. 세대·특약 한정이 붙은 값은 반드시 그 말을 함께 쓰고 '5세대'는 '5세대 실손'처럼 쓴다('5월' 같은 조합 금지). 공제금액을 쓴다면 원문 표기 순서·이름표 그대로 '1만원(의원·병원) 또는 2만원(종합병원·상급종합병원)' 형태로 쓴다. 약관·법 인용은 원문 글자 그대로, 한정 표현(다만·경우에만 등)은 빠뜨리지 않는다
