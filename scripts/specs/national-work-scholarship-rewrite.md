# 리라이트 — 국가근로장학금 스포크 2편 (2026-10-26, 노출 없는 옛 글·타이틀 품질 불량). 옛 글(2026-05-17 작성)은 원문 추출본 없음. 허브 안 소제목(work-types 등)은 건드리지 않는다.
# 타이틀·소제목: 사장님 10-24·10-26 "40자 이내·소제목 4개와 일치·같은 낱말 두 번 금지·타이틀은 네이버 자동완성 연관검색어로". 자동완성: 국가근로장학금 월급·월급 지급일·신청·신청기간·신청자격·신청대상·신청 2차·지급 방식·방학.
# 원문: 한국장학재단 국가근로장학금 소개·신청(kosaf.go.kr scholarship05_04_01), FAQ(scholarship05_04_09p), 2025학년도 1학기 2차 신청 안내 공지, 정책브리핑 '2학기 국가장학금·근로장학금 신청 기간' 정책포커스.
# 주의(시간): 한국장학재단에 2027학년도 1학기 국가근로장학금 공고가 아직 없다(2026-10-26 확인). 신청 일정·시급·월 지급액은 공고 전이면 "공고 전, 지난 학기 기준"으로 쓰고 2027 일정을 단정하지 않는다. 2차 신청은 대학별 선택 운영이라는 원문 표기를 그대로 쓴다.
# 주의(쓰지 않는 것): 블로그 후기, 확인되지 않은 시급·월 근로 한도 숫자, 중복 수혜 규정이 원문에 없으면 "안내에 없다"로 쓰고 지어내지 않는다(국가장학금 Ⅰ유형의 중복지원 불가 문구를 근로장학금 규정처럼 쓰지 않는다).
# 주의(구분): 지원 자격(소득 9구간 이내·직전 학기 C0(70/100) 이상)은 현행 한국장학재단 안내 표기대로.
