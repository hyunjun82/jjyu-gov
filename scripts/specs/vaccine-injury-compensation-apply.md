# 타이틀중복허용 — 사장님이 정한 타이틀(2026-10-23), 글자 그대로 둔다
# 한 편짜리 신규 — 2026-10-23. 소재: 당일 기사 "예방접종 후 장애 판정…대법 '미지급 진료비 줘야'"(YTN 등). 기사 판결 내용은 1차 출처(질병관리청 안내)에 없으면 쓰지 않고 notUsed 에 남긴다. 독감 접종철 검색 대비
# 타이틀은 사장님이 정함(2026-10-23): "예방접종 피해보상은 어디서 받나요? 백신 부작용 보상 신청방법" — 글자 그대로. 한 타이틀 안에 '보상'이 겹치는 점은 보고서 메모 한 줄로만
# 소제목은 내가 지음. 네이버 자동완성에는 '백신 부작용 보상 신청방법' 한 건뿐이라 수요가 약함 — 질병관리청 안내 순서(대상→서류→기한→이의신청)로 구성
# 주의(범위): 일반 국가예방접종·임시예방접종의 '예방접종피해 국가보상제도'(감염병예방법, 1995년부터)가 중심이다. 코로나19 특별법 피해보상은 별도 제도라 섞지 않고, 다룬다면 '다른 제도'로 한 줄만
# 주의(기한): 코로나19 특별법의 추가 이의신청 기한(2026.10.23.)은 이미 지난 정보 — '아직 할 수 있다'로 쓰지 않는다. 일반 제도의 신청 기한·이의신청 횟수(1회)는 질병관리청 페이지 글자 그대로
# 주의(출처 보강): 일반 제도의 신청 서류·기한은 질병관리청 안내에 없어 법령(감염병예방법 제71조, 시행령 제30·31조)을 더함. 법령에 있는 말만 쓴다
# 주의(숫자): 진료비 30만 원 미만 시·도 위임, 120일 이내 결정 같은 숫자는 질병관리청·정부 문서에서 확인된 것만. 법률 블로그·변호사 글은 1차 출처로 쓰지 않는다
# 주의(행동): 신청 창구가 시·도(보건소)인지 질병관리청인지 원문 글자 그대로. 접수처를 지어 쓰지 않는다. 인과관계 입증·인정 여부는 심의 결과에 달렸다는 범위 안에서만
