# 한 편짜리 신규 — 2026-10-10. 소재: 정부24 '부동산종합증명서 열람·발급' + 일사편리(kras.go.kr). 종합형·맞춤형 종류와 수수료(정부24와 일사편리 인터넷 발급이 다름)·방문 발급 창구(시군구·읍면동)·처리기간은 열린 페이지 글자 그대로. 수수료 숫자는 두 경로를 섞지 않고 경로별로 쓴다. 열람은 무료인지 원문 기준. 기존 building-register-certificate(건축물대장)·real-estate-registry-certificate(등기부등본)와 다른 증명서임을 구분한다
# 타이틀은 사장님이 정한 것을 글자 그대로 쓴다. 소제목은 네이버 자동완성에 뜬 말(부동산종합증명서 발급 방법·부동산종합증명서 인터넷 발급·부동산종합증명서 수수료·부동산종합증명서 발급처)로 지음
# 주의(연도·개정): 법령·고시·수수료는 개정으로 바뀐다 — 열린 원문의 현재 기준만 쓰고 옛 연도 안내와 섞지 않는다. 약식 연도 금지. 원문에 없는 금액·기간은 쓰지 않고 notUsed 에 사유와 함께 남긴다
# 주의(구성): 기간·금액·비율처럼 숫자가 든 비교(예: 유형별 수수료·단계별 기간)는 카드 안 표(3열 이하)로 넣는다. 표 값은 facts 의 값 그대로
