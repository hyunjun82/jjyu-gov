# 리라이트 — 자활사업 스포크 3편 (2026-10-26, 노출 없는 옛 글·타이틀 품질 불량: 같은 낱말 반복). 옛 글(2026-05-18 작성)은 원문 추출본 없음. 허브 안 소제목은 건드리지 않는다.
# 타이틀·소제목: 사장님 10-24·10-26 "40자 이내·소제목 4개와 일치·같은 낱말 두 번 금지·타이틀은 네이버 자동완성 연관검색어로". 자동완성: 자활사업 뜻·참여·종류·급여·대상자, 자활근로 급여·급여 지급일·급여 계산·급여 인상·신청기간·종류, 자활기업 조건·혜택.
# 원문: 보건복지부 보도자료 "자활급여 설 명절 전 조기 지급"(지급일), 한국자활복지개발원 자활근로사업 소개, 보건복지부 자활정책(자활근로사업 mid=a10708020200, 수급자선정기준 mid=a10708010300), 2026년 기초생활 보도자료, 맞춤형 자활지원체계 보도자료, 복지로 청년 자활 안내. 유형별 단가는 공식 자료에서 확인되지 않아 쓰지 않는다(옛 글의 "단가" 약속을 지키지 않는다). 지급일은 보도자료 표기(매달 말일, 변동 시 다음 달 3일까지)만 쓴다.
