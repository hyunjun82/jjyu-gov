# 리라이트 — 에너지바우처 스포크 연탄전환 1편 (2026-10-21). 옛 글(8월 작성)이 금액을 일반 에너지바우처 표(1인 295,200원~4인 701,300원)로 적어 놨는데, 공식 안내(energyv.or.kr/info/coal_support_info.do)는 세대원 수 구분 없이 576,000원 한 가지다 — 틀린 수치가 라이브에 있어 바로 고친다
# 타이틀·소제목: 내가 지음(한 편짜리 규칙). 네이버 자동완성에 실제로 뜬 말은 '연탄전환 에너지바우처 신청방법' 하나뿐이라, 나머지 소제목은 같은 주제어에 행동 키워드(대상·금액·사용기간)를 붙였다
# 원문: 한국에너지공단 에너지바우처 '연탄전환 에너지바우처 안내' 3쪽(coal_support_info·coal_apl_info·coal_use_info). 신청 2026.8.3~12.31, 사용 2026.10.3~2027.5.31, 금액 576,000원(산업통상부 연탄쿠폰 금액과 동일) — 공식 페이지 글자 그대로
# 주의(쓰지 않는 것): 일반 에너지바우처 금액표(295,200~701,300원)는 이 글에 쓰지 않는다. 기사·블로그의 연탄쿠폰 금액(47만 2천 원 등 옛 연도)과 다른 사이트의 54.6만 원 표기도 쓰지 않는다
# 주의(구분): 연탄전환 에너지바우처(연탄보일러를 비연탄보일러로 바꾼 세대, 한국에너지공단·복지로 신청)와 연탄쿠폰(연탄을 계속 쓰는 세대, 한국광해광업공단, 올해 접수 종료)은 다른 제도다. 지원 제외 대상(긴급복지 동절기 연료비·연탄쿠폰·동절기 에너지바우처 수급)을 원문대로
