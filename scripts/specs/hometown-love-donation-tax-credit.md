# 1차 출처 = 고향사랑e음(ilovegohyang.go.kr) 제도 안내·온라인 기부방법·연말정산 세액공제 안내·주의사항, 조세특례제한법 제58조, 고향사랑기부금법 제8조(상한 2천만 원)
# 주의(숫자 충돌): 조세특례제한법 제58조는 10만 원 이하 110분의 100, 10만~20만 원 이하 100분의 40, 20만 원 초과 2천만 원 이하 100분의 15(특별재난지역 100분의 30)인데 블로그·지자체는 44%·16.5%로 안내한다. 고향사랑e음 안내 페이지에 적힌 숫자와 조문을 비교해 다르면 충돌로 보고서에 남기고, 본문에는 원문 글자 그대로 한 쪽 기준만 쓴다(두 기준을 한 문장에 섞지 않는다)
# 주의(범위): 2027년부터 지역별 공제율을 다르게 하는 세제개편안은 국회 심사 중이라 쓰지 않는다. 한도는 법 제8조 '개인별 연간 상한액 2천만 원'. 기부 가능 시간·답례품 비율은 고향사랑e음 원문 글자 그대로
# 주의(행동): 12월 31일 기한은 원문에 있으면 쓴다(없으면 '해당 연도 지출분' 범위 안에서만). 기부는 거주지 외 지자체만 — 원문에 있는 범위어 그대로. 연말정산 자동 제출 여부는 고향사랑e음 안내 글자만
