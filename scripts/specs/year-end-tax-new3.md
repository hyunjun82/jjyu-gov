# 신규 — 연말정산 허브(year-end-tax) 스포크 3편 (2026-10-20). 22편 때 근거가 얇아 보류했던 주제를 자동완성을 다시 확인해 진행. 환급금 미지급(1번)은 사장님이 버림
# 타이틀·소제목: 사장님 확정(추가납부·전통시장). 원천징수영수증은 공식 근거(근로자가 홈택스에서 직접 내려받는 메뉴는 확인 안 됨)에 맞춰 '누구에게 받나요?'로 고침. 소제목은 네이버 자동완성에 실제로 뜬 말
# 주의(귀속연도): 지금(2026-10)은 2026년 귀속 안내가 나오기 전이다. 원문의 날짜·한도·금액은 귀속연도 이름표를 붙여 쓴다
# 주의(구분): 추가납부는 소득세법 제137조 분납(10만원 초과) 근거만, 원천징수영수증은 발급 주체(회사 = 원천징수의무자)·기한(다음 연도 2월 말일) 근거만. 홈택스 직접 발급 경로는 원문에 없으면 쓰지 않는다
# 주의(버튼): 상단 버튼은 spec cta 문구와 button 주소를 글자 그대로. 라벨에 '조문'을 쓰지 않는다
