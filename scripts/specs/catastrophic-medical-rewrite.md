# 리라이트 — 재난적의료비 스포크 2편 (2026-10-26, 노출 없는 옛 글·타이틀 품질 불량). 옛 글(2026-05-17 작성)은 원문 추출본 없음. 허브 안 소제목(eligibility 등)은 건드리지 않는다.
# 타이틀·소제목: 사장님 10-24·10-26 "40자 이내·소제목 4개와 일치·같은 낱말 두 번 금지·타이틀은 네이버 자동완성 연관검색어로". 자동완성: 재난적의료비 지원·지원 대상·신청·신청기간·서류·기준·소득기준·지원금액·본인부담상한제·신청서 쓰는 법. 글마다 한 가지만 답한다(금액·비율·한도 / 신청기간·외래·중증질환).
# 원문: 국민건강보험공단 재난적 의료비 지원 사업 안내(nhis.or.kr), 복지로 재난적의료비 지원(WLF00003247), 정책브리핑 [K-희망사다리] 재난적 의료비 지원사업, 보건복지부 보도자료.
# 주의(쓰지 않는 것): 블로그 후기, 개별 사례 금액, 구 안내(연 2천만원 한도 등)와 최신 자료(최대 5천만원)가 엇갈리는 한도는 2026년 기준이 확인된 값만(확인 안 되면 "안내 기준일에 따라 다르다"로 쓰고 숫자를 단정하지 않는다)
# 주의(최신): 2024-01-01 신청 건부터 입원·외래 구분 없이 모든 질환을 합산해 지원하므로 "외래는 6개 중증질환만" 같은 옛 틀로 쓰지 않는다. 치과·한방병원·정신병원 등은 개별심사로 선별 지원(원문 표기).
# 주의(기준선): 소득별 "본인부담 의료비 총액 기준선"(기초수급·차상위 80만원, 중위소득 50% 이하 1인 120만원 등)은 원문 표 그대로 "소득 구간 → 기준선" 짝으로만 쓰고, 다른 구간의 금액과 섞거나 "기준 중위소득"과 "기준선" 이름표를 바꿔 쓰지 않는다.
# 주의(구분): 소득 구간별 지원 비율(50~80%), 퇴원일 다음날부터 180일 신청 기한, 외래는 중증질환 한정 여부는 원문 표기와 기준일 그대로.
