# 리라이트 — 실비 스포크 실비 소급 청구 (2026-10-13). 노출 0 글 중 수요가 낮지만 타이틀이 어려운 글을 쉬운 말로 다시 쓴다(사장님 10-13 "조금 더 이해 쉽게"). 자동완성 수요 0(실비 소급 청구 0)
# 타이틀·소제목: 사장님이 10-13 채팅에서 확정한 쉬운 타이틀 그대로. 타이틀에는 숫자를 쓰지 않는다
# 쉬운 글 원칙(사장님 10-13 "조금 더 이해 쉽게"): 서론에서 이 글로 알게 되는 것을 먼저 보이고, 어려운 약관 용어(보장대상의료비·재가입주기 등)는 처음 나올 때 한 번 풀어 쓴다. 문장은 짧게, 한 문장에 숫자 둘 이하로 쓴다. 약관 인용·숫자는 원문 그대로이고 풀이는 원문에 있는 뜻만 쓴다
# 원문: ①상법 제662조(소멸시효) ②보험업감독업무시행세칙 [별표 15] 실손의료보험 표준약관(저장본, CAPTURED-BY) ③손해보험협회 실손의료보험 FAQ ④금융감독원 보험금 청구 안내
# 주의(쓰지 않는 것): 시효가 지난 청구를 보험사가 받아 준 사례(원문에 없다), 병원별 오래된 기록 보관 기간, 보험사별 지급·거절 사례, 후기·블로그 내용, 실손24 '청구서비스 중단 안내' 공지(제목만 있고 기간·대상이 원문에 없다)
# 주의(구분): ①'소급 청구'는 이미 지난 진료비를 뒤늦게 청구하는 것 — 보험금 청구권은 3년간 행사하지 않으면 소멸한다는 상법·약관 문구와 시작점(지급사유 발생일 등) 표현을 원문 그대로 ②계약이 끝난 뒤(해지·만기) 청구는 약관에 적힌 청구 가능 범위(계약 종료 후 입원 추가보상 등 원문 기간)만 ③오래된 진료의 서류(진료비 계산서·세부내역서) 발급 방법은 FAQ 원문에 있는 것만
# 주의(행동): 독자가 지금 할 일 = 진료일로부터 시효가 얼마나 남았는지 달력으로 세어 보고, 서류를 받아 실손24 또는 보험사 앱으로 먼저 접수하는 것. 상단 버튼 문구는 '소급'를 넣어 다른 글과 겹치지 않고 끝말을 '확인하기'로 쓰지 않는다(버튼 도배 게이트: 확인하기 비율 상한 40%)
# 주의(구성): 금액·비율·횟수가 든 비교는 카드 안 표(3열 이하)로 한 번 이상 넣는다. 표 값은 facts 의 값 그대로. 공제금액은 원문 표기 순서·이름표 그대로 '1만원(의원·병원) 또는 2만원(종합병원·상급종합병원)' 형태로 쓴다(이름표를 숫자 앞에 놓거나 '의원이면 1만원'처럼 풀어 쓰면 짝 검사에 걸린다). 세대·특약 한정이 붙은 값은 반드시 그 말을 함께 쓰고 '5세대'는 '5세대 실손'처럼 쓴다('5월' 같은 조합 금지). 약관 인용은 원문 글자 그대로, 한정 표현(다만·경우에만 등)은 빠뜨리지 않는다.
