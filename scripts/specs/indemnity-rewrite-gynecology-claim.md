# 주의(쓰지 않는 것): 산부인과 진료·시술 가격(원문에 값이 없다), 자궁근종 시술 종류별 급여 여부(심평원 소관, 열지 않음), 난임시술 정부 지원 금액·요건(복지부 소관, 열지 않음), 보험사별 지급·거절 사례, 후기·블로그 내용, 실손24 '청구서비스 중단 안내' 공지(제목만 있고 기간·대상이 원문에 없다)
# 주의(구분): ①약관 보상하지 않는 사항의 임신·출산·불임·인공수정 관련 문구와 질병코드(N96~N98 등)는 원문 글자 그대로 — 해당 코드·항목이 약관에 적힌 대로만 쓰고 개별 시술이 거기 해당한다고 단정하지 않는다 ②질염·초음파·자궁근종은 약관에 병명이 없으면 '이름이 없다'고 쓰지 말고 원문에서 확인한 조항(급여·비급여 구분, 예방진료 제외 등)으로만 설명한다 ③급여·비급여에 따른 공제금액·자기부담은 세대 한정과 함께 원문 그대로 ④청구 서류는 손해보험협회 FAQ 원문 그대로(질병분류코드가 적힌 서류·청구 금액 구간) ⑤'원문에 없으니 문의하세요'식 떠넘기는 문장은 쓰지 않는다 — 없는 항목은 빼서 notUsed 에 둔다
# 주의(행동): 독자가 지금 할 일 = 진료비 영수증·진단서에 질병코드가 어떻게 적혔는지 확인하고, 급여·비급여를 나눠 영수증을 받아 실손24 또는 보험사 앱으로 청구하는 것. 상단 버튼 문구는 '산부인과'를 넣어 다른 글과 겹치지 않게(버튼 도배 게이트)
# 주의(구성): 금액·비율·횟수가 든 비교는 카드 안 표(3열 이하)로 한 번 이상 넣는다. 표 값은 facts 의 값 그대로. 공제금액은 원문 표기 순서·이름표 그대로 '1만원(의원·병원) 또는 2만원(종합병원·상급종합병원)' 형태로 쓴다(이름표를 숫자 앞에 놓거나 '의원이면 1만원'처럼 풀어 쓰면 짝 검사에 걸린다). 세대·특약 한정이 붙은 값은 반드시 그 말을 함께 쓰고 '5세대'는 '5세대 실손'처럼 쓴다('5월' 같은 조합 금지). 약관 인용은 원문 글자 그대로, 한정 표현(다만·경우에만 등)은 빠뜨리지 않는다
