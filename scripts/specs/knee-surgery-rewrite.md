# 리라이트 — 노인 무릎인공관절 스포크 2편 (2026-10-26, 노출 없는 옛 글·타이틀 불량). 옛 글은 원문 추출본 없음. 신청자격·건강보험후국가지원본인부담금 스포크는 그대로 둔다.
# 타이틀·소제목: 사장님 10-24·10-26 "40자 이내·소제목 4개와 일치·같은 낱말 두 번 금지·타이틀은 네이버 자동완성 연관검색어로". 자동완성: 무릎 인공관절 수술비 지원·지원금·지원 대상·실비·얼마, 노인 무릎 인공관절 지원.
# 원문: 노인의료나눔재단 무릎인공관절 수술지원사업(ok6595.or.kr knee01 신청방법·절차, knee02 지원대상, knee03 지원금액·제외·중복), 정부24 노인 무릎인공관절 수술 지원.
# 주의(옛 글 오류 점검): 옛 글의 금액·자격·기한은 원문과 다시 대조한다. 원문에 없는 서류 목록(진단서 외)은 쓰지 않는다. 신청서·수술비 청구서 서식이 있다는 사실과 진단서 발급 절차만 원문대로 쓴다.
# 주의(쓰지 않는 것): 블로그 후기, 병원별 실제 본인부담액, 확인되지 않은 접수 기간(연중 접수·예산 소진 문구는 원문에 있을 때만).
