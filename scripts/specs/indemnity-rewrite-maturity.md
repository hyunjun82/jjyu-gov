# 리라이트 — 실비 스포크 만기 (2026-10-13, 노출 큰 글 업그레이드). 60일 노출 11,980·클릭 398·CTR 3.3%·순위 2.5. "실비보험 만기" 노출 18·38.9%, "실비보험 갱신 주기" 27.8%, "실비보험 만기 환급금". 자동완성: 실비 만기(재가입·환급금·후 갱신·연장·재가입 방법·15년)
# 타이틀·소제목: 사장님이 10-13 채팅에서 "훨씬 사용자 중심으로 타이틀·시각화까지" 지시해 새로 짠 안 그대로. 주소(slug)는 그대로
# 업그레이드 원칙(사장님 10-13 "훨씬 사용자 중심으로"): 이미 노출되는 글이라 옛 글(7월·8월 작성: 서론 없음·표가 카드 아래·소제목 7개)보다 훨씬 쉽고 보기 편해야 한다. ①서론 200자 안에서 독자가 검색한 질문의 답(결론)을 먼저 말하고 바로 할 일로 넘긴다 ②소제목 카드는 4개, 카드마다 소제목 → (행동이 있으면 버튼) → 표 → 설명 순서 ③숫자·비교·단계가 있는 카드는 표나 단계 표(3열 이하)로 시각화하고, 4개 카드 중 최소 3개에 표를 넣는다 ④어려운 약관 용어는 처음 나올 때 한 번 풀어 쓰고 문장은 짧게, 한 문장에 숫자 둘 이하 ⑤옛 글이 순위를 얻은 핵심 문장(검색어와 같은 표현)은 소제목·서론에 그대로 살린다 ⑥옛 글의 사실 중 원문으로 확인되지 않는 것은 쓰지 않는다
# 원문: ①손해보험협회 실손의료보험 안내 ②손해보험협회 실손의료보험 상품 소개 ③손해보험협회 실손의료보험 FAQ ④보험업감독업무시행세칙 [별표 15] 실손의료보험 표준약관(저장본, CAPTURED-BY)
# 주의(쓰지 않는 것): 환급금 금액·보험사별 환급 조건(원문에 값이 없다), 보험사별 지급·거절 사례, 후기·블로그 내용, 실손24 '청구서비스 중단 안내' 공지(제목만 있고 기간·대상이 원문에 없다)
# 주의(구분): ①실손에서 '만기'가 없는 상품과 갱신·재가입주기가 있는 상품의 구분은 협회 안내·FAQ 원문 그대로(세대별 숫자 포함) ②만기·재가입 시점에 보장 내용이 바뀌는 점과 재가입 때 건강상태 심사 여부는 원문 그대로 ③환급금은 실손에 있는지 원문에 있을 때만 쓰고 없으면 notUsed
# 주의(행동): 독자가 지금 할 일 = 내 실손의 세대와 갱신·재가입 시점을 보험사 앱에서 확인하는 것. 상단 버튼 문구는 '만기'를 넣어 다른 글과 겹치지 않고 끝말을 '확인하기'로 쓰지 않는다(버튼 도배 게이트: 확인하기 비율 상한 40%)
# 주의(구성): 금액·비율·횟수가 든 비교는 카드 안 표(3열 이하)로 넣는다. 표 값은 facts 의 값 그대로. 공제금액은 원문 표기 순서·이름표 그대로 '1만원(의원·병원) 또는 2만원(종합병원·상급종합병원)' 형태로 쓴다(이름표를 숫자 앞에 놓거나 '의원이면 1만원'처럼 풀어 쓰면 짝 검사에 걸린다). 세대·특약 한정이 붙은 값은 반드시 그 말을 함께 쓰고 '5세대'는 '5세대 실손'처럼 쓴다('5월' 같은 조합 금지). 약관 인용은 원문 글자 그대로, 한정 표현(다만·경우에만 등)은 빠뜨리지 않는다. '원문에 없으니 문의하세요'식 떠넘기는 문장은 쓰지 않는다 — 없는 항목은 빼서 notUsed 에 둔다
