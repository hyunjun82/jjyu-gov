# 신규 — 국가건강검진 허브(national-health-checkup) 스포크 2편 (2026-10-21). 11월~연말 유입(검진기간 12월 31일 종료) 대비. 허브에 이미 있는 4편(대상자 짝수홀수·연령별 검사항목·예약 검진기관·안 받으면 불이익)과 겹치지 않게 짓는다
# 타이틀·소제목: 내가 지음(한 편짜리 규칙). 소제목은 네이버 자동완성에 뜬 말. '안 받으면 불이익·과태료' 는 기존 글과 겹쳐 제외
# 주의(연도): 검진기간 안내는 공단 원문의 현재 문구만 쓴다. 과거(2021년 기간 연장 등) 한시 조치는 쓰지 않는다
# 주의(구분): 일반건강검진 기간 12.31 종료와 전년도 미수검자 추가등록은 일반검진 페이지, 암검진 기간(연장 없음, 2단계 검사 다음해 1.31)은 암검진 페이지 근거
# 주의(버튼): 상단 버튼은 spec cta 문구와 button 주소를 글자 그대로. 로그인이 필요한 페이지는 목적지로 열리는지만 확인하고 안내 문구에서 로그인 필요를 밝힌다
