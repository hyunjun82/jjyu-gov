# 리라이트 — 실비 스포크 generation-check (2026-10-14, 노출 0 글 리라이트). 60일 노출 0. 옛 글(7·8월 작성)은 서론 없음·표가 카드 아래·소제목 7개
# 타이틀·소제목: 사장님이 10-14 "노출 안된 거부터"로 지시해 짠 안. 자동완성 롱테일 기준, 주소(slug)는 그대로
# 업그레이드 원칙: ①서론 200자 안에서 검색한 질문의 답을 먼저 말하고 바로 할 일로 넘긴다 ②소제목 카드는 4개, 카드마다 소제목 → (행동이 있으면 버튼) → 표 → 설명 ③숫자·비교·단계가 있는 카드는 표(3열 이하)로, 4개 중 최소 3개에 표 ④어려운 약관 용어는 처음 한 번 풀어 쓰고 문장은 짧게, 한 문장에 숫자 둘 이하 ⑤옛 글의 사실 중 원문으로 확인되지 않는 것은 쓰지 않는다
# 원문: ①손해보험협회 실손의료보험 상품 소개 ②손해보험협회 실손의료보험 안내 ③손해보험협회 실손의료보험 FAQ ④보험업감독업무시행세칙 [별표 15] 실손의료보험 표준약관(저장본, CAPTURED-BY)
# 주의(쓰지 않는 것): 보험사별 상품명·판매 시기 일정 중 원문에 없는 것, 보험사별 지급·거절 사례, 후기·블로그 내용, 실손24 '청구서비스 중단 안내' 공지(제목만 있고 기간·대상이 원문에 없다)
# 주의(구분): ①1~5세대 구분(판매 시기)은 협회 상품 소개·안내 원문의 숫자 그대로 ②세대별 보장 차이는 원문에 있는 만큼만 ③세대를 가입일로 확인하는 방법(증권·보험사 앱)은 원문에 있을 때만
# 주의(행동): 독자가 지금 할 일 = 가입 시기로 내 실손이 몇 세대인지 상품 안내에서 가려 보는 것. 상단 버튼 문구는 '세대'를 넣어 다른 글과 겹치지 않고 끝말을 '확인하기'로 쓰지 않는다(버튼 도배 게이트: 확인하기 비율 상한 40%).
# 주의(서론=클릭 공식, 사장님 10-13): 서론은 버튼을 누르게 만드는 글이다. 첫 문장은 독자가 검색한 질문의 답, 숫자는 facts 에서 하나만(낯선 용어 둘 이하), '다만 …에 따라 갈려서' 식 반전 한 번, 마지막은 '내 …'를 주어로 한 행동 한 문장. 버튼은 라벨이 약속한 곳으로 실제 가는 공식 딥링크여야 하고 계산기·도구는 만들지 않는다. 숙제형('서류 챙기기·확인해 두기') 라벨은 쓰지 않는다. 상단 버튼(heroAct)의 href 는 반드시 spec 의 button 주소(약관 원문·FAQ 페이지로 보내지 않는다). 서론 마지막 행동 문장에는 상단 버튼 라벨의 낱말(예: 청구·실손24로·금액)을 절반 이상 그대로 쓰고, 'X 하기 전에 Y부터 가늠해 두는 게 순서' 식 숙제 문장은 쓰지 않는다. 서론에 숫자는 하나, '내 … 보세요' 틀은 쓰지 않는다. 버튼 문구는 간결하게(사장님 10-14): 상단은 '주제어 + 청구 바로가기' 형태 12자 안팎(예: '골절 치료비 청구 바로가기'), 카드 버튼도 '… 바로가기'로 짧게. 서론 행동 문장에는 라벨의 주제어와 '청구'를 그대로 쓴다
# 주의(구성): 금액·비율·횟수가 든 비교는 카드 안 표(3열 이하)로 넣는다. 표 값은 facts 의 값 그대로. 공제금액은 원문 표기 순서·이름표 그대로 '1만원(의원·병원) 또는 2만원(종합병원·상급종합병원)' 형태로 쓴다(이름표를 숫자 앞에 놓거나 '의원이면 1만원'처럼 풀어 쓰면 짝 검사에 걸린다). 세대·특약 한정이 붙은 값은 반드시 그 말을 함께 쓰고 '5세대'는 '5세대 실손'처럼 쓴다('5월' 같은 조합 금지). 약관 인용은 원문 글자 그대로, 한정 표현(다만·경우에만 등)은 빠뜨리지 않는다. '원문에 없으니 문의하세요'식 떠넘기는 문장은 쓰지 않는다 — 없는 항목은 빼서 notUsed 에 둔다
