# 한 편짜리 신규 — 2026-10-23. 소재: 당일 보도자료 "지방세 환급금, 이제 평소 쓰던 민간 앱에서 간편하게 확인하고 신청까지 한 번에!"(행정안전부 2026.10.22.). 기존 local-tax-refund-claim(id 318, 위택스 청구)과 겹치지만 이 글은 '조회·찾기' 각도
# 타이틀은 사장님 승인(2026-10-23) 그대로. 소제목은 네이버 자동완성(2026-10-23)에 뜬 말: 지방세 환급금 조회 / 신청 방법 / 통지서 / 문자 / 지급일 / 처리기한
# 주의(한정 표현): 민간 앱(카카오페이 등)에서의 조회·신청은 2026년 12월 시작 '예정'이다. 지금 되는 것(위택스·정부24·시군구)과 12월 이후 예정을 반드시 구분하고, 예정을 '된다'로 쓰지 않는다. keepWord/keepWhy 판단 필수
# 주의(범위): 업무협약 참여 기관 이름·페이머니 종류는 보도자료 글자 그대로(기사마다 표기가 다름 — 기사·블로그 표기 쓰지 않는다). 업무협약은 10월 22일
# 주의(소제목): '통지서·문자'는 1차 출처에 근거가 없으면 지어 쓰지 않는다 — 있는 범위만 쓰고 나머지는 notUsed. 처리기한은 정부24 '즉시(근무시간 내 3시간)' 등 원문 글자 그대로
# 주의(행동): 위택스 메뉴 경로는 열린 페이지 글자 그대로(환급 → 환급금 빠른조회 등). 로그인 방식도 화면 글자 그대로
