# 리라이트 — 실비 스포크 당뇨 (2026-10-13). 네이버 실검색 "당뇨 실비"에서 gov 글이 첫 웹문서로 나오는데도 60일 노출은 0(수요 있음: 마운자로·보험·청구·가입·환급하는법). 옛 글은 '1형 2형 뭐가 다를까?'가 타이틀 뒤를 흐렸다
# 타이틀·소제목: 사장님이 10-13 채팅에서 "노출 안 되는 글 우선"으로 확정한 안 그대로 (제안 → 작성 진행)
# 원문: ①질병관리청 국가건강정보포털 당뇨병(옛 글 근거) ②손해보험협회 실손의료보험 안내 ③금융감독원 보도자료(옛 글 근거) ④보험업감독업무시행세칙 [별표 15] 실손의료보험 표준약관(저장본, CAPTURED-BY) ⑤손해보험협회 실손의료보험 FAQ
# 주의(쓰지 않는 것): 당뇨 치료비·약값 금액(원문에 값이 없다), 당뇨병 진단 수치 기준·관리 방법의 의학 해설(질병청 원문에 있는 것만 최소한으로), 마운자로 등 개별 약제 판단(마운자로 글에서 다룸), 진단비 특약의 보험사별 금액(실손 표준약관 밖의 별도 상품이라 원문에 값이 없다), 보험사별 지급·거절 사례, 후기·블로그 내용, 실손24 '청구서비스 중단 안내' 공지(제목만 있고 기간·대상이 원문에 없다)
# 주의(구분): ①실손은 '실제 낸 의료비'를 보상하고 당뇨 '진단비'는 별도 정액 특약이라는 구분은 원문(협회·금감원)에 있는 만큼만 쓴다 ②당뇨 진료비·약값은 급여 여부에 따라 기본형·특약 구조로 보상된다 — 공제금액·자기부담은 세대 한정과 함께 원문 그대로 ③'가입 제한'은 계약 전 알릴 의무·유병력자 실손 등 원문(협회 안내)에 있는 것만, 숫자(연령 등)는 원문 그대로 ④1형·2형 구분은 질병청 원문에 있을 때만 쓰고 보험 보상이 달라진다고 단정하지 않는다 ⑤청구 서류는 손해보험협회 FAQ 원문 그대로 ⑥'원문에 없으니 문의하세요'식 떠넘기는 문장은 쓰지 않는다 — 없는 항목은 빼서 notUsed 에 둔다
# 주의(행동): 독자가 지금 할 일 = 진료비·약제비 영수증과 처방전·세부산정내역을 받아 급여·비급여를 나누고, 이미 당뇨 진단을 받았다면 신규 가입 때 알릴 의무를 확인한 뒤 실손24 또는 보험사 앱으로 청구하는 것. 상단 버튼 문구는 '당뇨'를 넣어 다른 글과 겹치지 않게(버튼 도배 게이트)
# 주의(구성): 금액·비율·횟수가 든 비교는 카드 안 표(3열 이하)로 한 번 이상 넣는다. 표 값은 facts 의 값 그대로. 공제금액은 원문 표기 순서·이름표 그대로 '1만원(의원·병원) 또는 2만원(종합병원·상급종합병원)' 형태로 쓴다(이름표를 숫자 앞에 놓거나 '의원이면 1만원'처럼 풀어 쓰면 짝 검사에 걸린다). 세대·특약 한정이 붙은 값은 반드시 그 말을 함께 쓰고 '5세대'는 '5세대 실손'처럼 쓴다('5월' 같은 조합 금지). 약관 인용은 원문 글자 그대로, 한정 표현(다만·경우에만 등)은 빠뜨리지 않는다
