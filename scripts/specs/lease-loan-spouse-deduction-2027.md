# 한 편짜리 신규 — 2026-10-06. 소재: 재정경제부 2026 세제개편안(8.3) 주택임차차입금 원리금상환액 소득공제 대상자 확대(주소지가 다른 세대주의 배우자인 근로자 포함). 기존 mortgage-interest-deduction(주택담보 이자)은 다른 소재라 건드리지 않는다
# 타이틀·소제목은 네이버 자동완성('주택임차차입금 원리금 공제·전세대출 소득공제 세대원·소득요건·서류')에 뜬 말로 지음
# 주의: 개편안은 국회 의결 전 정부안이다. 헌법 제59조를 근거로 '법률 개정을 거쳐 확정'을 한정 표현으로 쓴다. 개정안의 추가 대상은 '세대주의 배우자인 근로자'이며 요건 (ⅰ)(ⅱ)를 둘 다 충족해야 한다 — '모두'를 빼지 않는다. 현행 요건은 국세청 안내에 있는 것만 쓴다
