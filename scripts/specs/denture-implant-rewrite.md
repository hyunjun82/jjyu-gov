# 리라이트 — 의료급여 노인 틀니·임플란트 스포크 3편 (2026-10-26, 노출 없는 옛 글·타이틀 불량). 옛 글은 원문 추출본 없음. 틀니7년주기사후유지관리 스포크와 허브 본글은 그대로 둔다.
# 타이틀·소제목: 사장님 10-24·10-26 "40자 이내·소제목 4개와 일치·같은 낱말 두 번 금지·타이틀은 네이버 자동완성 연관검색어로". 자동완성: 의료급여 틀니·틀니 지원 방법·틀니신청방법·임플란트 등록방법, 노인 틀니 지원 대상·지원 금액·지원 신청, 노인 임플란트 지원 금액·건강보험.
# 원문: 국민건강보험공단 노인틀니 급여안내(nhis.or.kr wbmac0217), 치과임플란트 급여안내(wbmac0221), 노인틀니 급여 관련 Q&A(wbmac0217_2.pdf).
# 주의(옛 글 오류 점검): 옛 글 "지정 치과" 표기는 공단 안내에서 확인되지 않으면 쓰지 않는다. 의료급여 수급권자의 등록 신청은 관할 보장기관(시군구)에서만 가능하다는 공단 문구를 쓴다. 의료급여 1종 5%·2종 15%(틀니), 1종 10%·2종 20%(임플란트)는 공단 안내 원문 표기와 맞을 때만 쓴다. 나이 기준은 원문 표기(만 65세 이상)대로.
# 주의(구분): 건강보험 가입자(30%)·차상위(5%·15%)·의료급여(1종·2종)를 이름표 섞지 말고 짝으로만 쓴다. 임플란트는 본인부담상한제 미적용이라는 원문 문구가 있으면 틀니와 구분해 쓴다.
# 주의(쓰지 않는 것): 블로그 후기, 병원별 실제 가격, 지자체별 추가 지원(김포시 등)
