## 4. 작업 순서(승인 후)

1. 사장님이 spec(허브 타이틀 + 스포크 타이틀·소제목 4개씩) 주면 → `scripts/specs/vat-*.md` 로 옮긴다.
2. `npm run gov -- scripts/specs/{주제}.md` (국세청·홈택스 1차 출처 수집 → facts → 작성 → 대조 → 시험).
3. 기존 스포크 8개는 리라이트(URL 유지, `file:`/`export:`), 허브는 날짜·기한 갱신.
