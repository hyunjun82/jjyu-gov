# 리라이트 — 국가근로장학금 허브 본글 (2026-10-26, 노출 없는 옛 글·타이틀 품질 불량). 옛 글(2026-05-17 작성)은 원문 추출본 없음. 허브 Spokes 배열(14개)은 보존한다.
# 타이틀·소제목: 사장님 10-24·10-26 "40자 이내·소제목 4개와 일치·같은 낱말 두 번 금지·타이틀은 네이버 자동완성 연관검색어로". 허브는 개요(자격·신청기간·월급 지급일·교내외 차이), 신청 방법·중복은 스포크가 답한다.
# 원문: 한국장학재단 국가근로장학금 소개·신청(kosaf.go.kr scholarship05_04_01), FAQ, 정책브리핑 '2학기 국가장학금·근로장학금 신청 기간' 정책포커스.
# 주의(시간): 한국장학재단에 2027학년도 1학기 국가근로장학금 공고가 아직 없다(2026-10-26 확인). 일정·시급·월 지급액은 공고 전이면 "공고 전, 지난 학기 기준"으로 쓰고 2027 일정을 단정하지 않는다.
# 주의(쓰지 않는 것): 블로그 후기, 확인되지 않은 시급·월 근로 한도 숫자
