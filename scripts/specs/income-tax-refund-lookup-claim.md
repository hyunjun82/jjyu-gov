# 한 편짜리 신규 — 2026-10-10. 소재: 당일 기사 "'무료 환급 조회'라더니 수수료 44%…공정위, 세무 플랫폼 '과장광고' 조사"(온라인 세무 대행 플랫폼의 종합소득세 환급 대행 수수료 피해). 1차 출처 = 국세청 국세상담센터 '종합소득세 환급 기간'·'근로소득자 신고서(경정청구)', 국세청 '모두채움 신고 안내(환급)', 정책브리핑 공정위 세무 플랫폼 표시광고 제재 보도. 기존 national-tax-refund-lookup(국세 환급금 조회)과 겹치지만 이 글은 '종합소득세 환급 조회·신청·경정청구를 홈택스에서 직접 하는 법'
# 주의(범위): 기사의 수수료 44%·270만 원·평균 환급금 1,500여만 원은 기사 속 사례 숫자라 1차 출처에 없으면 쓰지 않고 notUsed 에 남긴다. 특정 업체 이름은 쓰지 않는다(공정위 제재 보도는 '세무 대행 플랫폼의 표시광고 위반 제재' 사실만, 과징금·위반 내용은 원문 그대로)
# 주의(기간): 환급금 조회는 조회일로부터 5년 이내만 조회, 환급 청구(경정청구)는 납부기한으로부터 5년 이내 — 국세청 문장 그대로. 5월 정기 신고(2026년 5월)와 신고 후 환급 신청·경정청구·기한 후 신고를 섞지 않는다. 연도는 약식 금지('26 → 2026년)
# 주의(방법): 홈택스 메뉴 경로는 열린 페이지에 적힌 글자 그대로(로그인 → 신고/납부 → 종합소득세 …). 프리랜서 원천징수 환급이 맞는지는 원문에 있는 범위만 쓴다
