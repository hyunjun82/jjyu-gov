# 주의(행동): 독자가 지금 할 일 = 거절 통보서에 적힌 근거 조항과 진단서의 질병코드를 비교해 보고, 서류를 보완해 다시 접수하는 것. 상단 버튼 문구는 '요실금'를 넣어 다른 글과 겹치지 않게(버튼 도배 게이트)
