# 리라이트 — 배우자 출산휴가급여 스포크 4편 (2026-10-26, 노출 없는 옛 글·타이틀 불량). 옛 글은 원문 추출본 없음. 급여상한액우선지원신청 스포크는 그대로 둔다(상한액·고용24 신청은 그 글이 답한다).
# 타이틀·소제목: 사장님 10-24·10-26 "40자 이내·소제목 4개와 일치·같은 낱말 두 번 금지·타이틀은 네이버 자동완성 연관검색어로". 자동완성: 배우자 출산휴가일·기간·급여·20일·20일 급여·계산·주말·분할, 배우자 출산휴가비 신청 방법.
# 원문: 고용노동부 일생활균형 배우자 출산휴가(worklife.kr paternity_leave), 고용24 배우자 출산휴가급여(work24 SI00000395), 고용노동부 보도자료 「남녀고용평등법 시행령」·「고용보험법 시행령」 개정안 국무회의 의결(2026-08-11, PDF), 정책브리핑 2026년 하반기 달라지는 제도.
# 주의(시간): 9월 18일부터 배우자 휴가·휴직이 확대됐다(유산·사산휴가와 급여 신설, 배우자의 임신 중에도 배우자 출산전후휴가·육아휴직 사용). 오늘(2026-10-26)은 시행 뒤다. 보도자료 PDF·정책브리핑에 글자 그대로 있는 일수·기간·급여만 쓰고, 언론 기사나 블로그에만 있는 숫자(예: 상한액, 출산예정일 50일 전 같은 값)는 원문 PDF·공식 페이지에서 확인될 때만 쓴다.
# 주의(옛 글 오류 점검): 옛 글의 "통상임금 100% 지급", "상한 1,684,210원", "120일 이내 3회 분할", "20일 전부 유급"은 고용24·고용노동부 안내의 현재 표기와 대조한다. 우선지원대상기업 여부에 따라 급여 지급 주체가 다른 점은 원문 표기대로 짝으로만 쓴다.
# 주의(쓰지 않는 것): 블로그 후기, 회사별 사례, 확인되지 않은 일수·금액
