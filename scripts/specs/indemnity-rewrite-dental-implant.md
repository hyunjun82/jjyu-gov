# 원문: ①보험업감독업무시행세칙 [별표 15] 실손의료보험 표준약관(저장본, CAPTURED-BY) ②손해보험협회 실손의료보험 FAQ ③금융감독원 보험금 청구 안내
# 주의(쓰지 않는 것): 임플란트·뼈이식 비용·병원별 가격(원문에 값이 없다), 건강보험 임플란트 급여 대상·본인부담률(건보 소관, 열지 않음), 보험사별 지급·거절 사례, 후기·블로그 내용, 실손24 '청구서비스 중단 안내' 공지(제목만 있고 기간·대상이 원문에 없다)
# 주의(구분): ①약관에서 치과 치료·임플란트·뼈이식이 보상하지 않는 사항(또는 비급여 면책)에 어떻게 적혀 있는지는 원문 글자 그대로 — 임플란트라는 말이 직접 있으면 인용하고, 없으면 '이름이 없다'고 쓰지 말고 원문에서 확인한 조항으로만 설명한다 ②뼈이식이 같이 빠지는지는 원문에 근거가 있을 때만 쓴다 ③'면책 사유' 소제목은 원문의 보상하지 않는 사항 열거와 한정 표현(다만 등)만 쓴다 ④급여·비급여에 따른 공제금액·자기부담은 세대 한정과 함께 원문 그대로 ⑤청구 방법은 손해보험협회 FAQ·금융감독원 안내 원문 그대로(접수 경로·서류)
# 주의(행동): 독자가 지금 할 일 = 치과 영수증에서 급여·비급여와 진료 항목(임플란트·뼈이식)을 나눠 보고, 진단서에 적힌 병명·치료 목적을 확인한 뒤 청구 가능 여부를 보험사 앱·실손24에서 접수해 확인하는 것
# 주의(구성): 금액·비율·횟수가 든 비교는 카드 안 표(3열 이하)로 한 번 이상 넣는다. 표 값은 facts 의 값 그대로. 공제금액은 원문 표기 순서·이름표 그대로 '1만원(의원·병원) 또는 2만원(종합병원·상급종합병원)' 형태로 쓴다(이름표를 숫자 앞에 놓거나 '의원이면 1만원'처럼 풀어 쓰면 짝 검사에 걸린다). 세대·특약 한정이 붙은 값은 반드시 그 말을 함께 쓰고 '5세대'는 '5세대 실손'처럼 쓴다('5월' 같은 조합 금지). 약관 인용은 원문 글자 그대로, 한정 표현(다만·경우에만 등)은 빠뜨리지 않는다
