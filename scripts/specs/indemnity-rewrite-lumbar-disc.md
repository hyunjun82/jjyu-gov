# 리라이트 — 실비 스포크 허리디스크 (2026-10-12). 네이버 실검색 "허리디스크 실비"에서 gov 글이 안 나온다(수요 있음: 서류·청구·가입·보험 적용). 옛 글이 약관 문구만 되풀이해 치료별 정보가 얇았다.
# 타이틀·소제목: 사장님이 10-12 채팅에서 "하나씩 작성" 지시로 확정한 안 그대로
# 원문: ①보험업감독업무시행세칙 [별표 15] 실손의료보험 표준약관(저장본, CAPTURED-BY) ②손해보험협회 실손의료보험 FAQ ③금융감독원 보험금 청구 안내
# 주의(쓰지 않는 것): 허리디스크 수술·시술 비용(병원마다 다르고 원문에 값이 없다), 병원별 시술 종류의 의학적 적정성, 질병코드별 급여 인정기준(심평원 소관, 열지 않음), 보험사별 지급·거절 사례, 도수치료 관리급여 전환(별도 글), 후기·블로그 내용
# 주의(구분): ①약관에 허리디스크라는 병명은 없다 — 병명이 아니라 급여냐 비급여냐(기본형 vs 특별약관), 비급여 중 3대 항목(도수치료·체외충격파·증식치료, 주사료, MRI·MRA)이냐에 따라 한도·횟수·공제가 갈린다. 해당 수치는 원문의 세대 한정(예: 5세대)·특약 이름표와 함께 그대로 쓴다 ②MRI·주사·수술은 각각 소제목에 맞춰 원문에 있는 내용만 쓴다 ③'허리디스크 실비 가입'은 가입 전 알릴 의무·유병력자 관련 원문이 있으면 그대로, 없으면 쓰지 않고 notUsed 로 남긴다 ④청구 서류는 손해보험협회 FAQ 원문 그대로(입원·통원·금액 구간)
# 주의(행동): 독자가 지금 할 일 = 진료비 영수증과 세부산정내역에서 급여·비급여를 나누고, MRI·주사 항목이 있으면 특약 한도를 확인한 뒤 실손24 또는 보험사 앱으로 청구하는 것
# 주의(구성): 금액·비율·횟수가 든 비교는 카드 안 표(3열 이하)로 한 번 이상 넣는다. 표 값은 facts 의 값 그대로. 공제금액은 원문 표기 순서·이름표 그대로 '1만원(의원·병원) 또는 2만원(종합병원·상급종합병원)' 형태로 쓴다(이름표를 숫자 앞에 놓으면 짝 검사에 걸린다). 세대·특약 한정이 붙은 값은 반드시 그 말을 함께 쓴다. 약관 인용은 원문 글자 그대로, 한정 표현(다만·경우에만 등)은 빠뜨리지 않는다
