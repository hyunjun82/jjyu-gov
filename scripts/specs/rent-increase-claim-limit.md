# 한 편짜리 신규 — 2026-10-10. 소재: 찾기쉬운 생활법령정보(법제처) 부동산/임대차 분야 행동 키워드. 타이틀은 사장님이 정한 것을 글자 그대로 쓴다. 1차 출처 = 생활법령 해당 목차 + 관련 법령 원문
# 주의(범위): 증액 상한 5%, 계약 후 1년 이내 증액 불가는 법령 글자 그대로. 갱신요구권 행사 시 증액 상한과 같은 규칙인지 원문 기준으로만. 상가 규정은 섞지 않는다
# 주의(연도·개정): 법령은 개정으로 숫자·기한이 바뀐다 — 열린 원문의 현재 시행 기준만 쓰고, 개정 전후를 섞지 않는다. 약식 연도('26 → 2026년) 금지. 원문에 없는 금액·기간·비율은 쓰지 않고 notUsed 에 사유와 함께 남긴다
# 주의(중복): 이미 쓴 글(jeonse-protection·housing-lease-report·lease-fixed-date·commercial-lease-*·court-auction 등)과 겹치는 내용은 이 글의 소제목 주제에 해당하는 것만 쓴다
