# 한 편짜리 신규 — 2026-10-10. 소재: 지방세기본법상 지방세 이의신청(재산세 부과처분에 대한 불복). 이의신청 기한(처분 통지를 받은 날부터 90일 이내 등), 이의신청서·첨부 서류, 결정 기간(이의신청을 받은 날부터 90일 이내)과 결정 통지, 심판청구로 이어지는 절차는 법령 원문 글자 그대로. 이의신청과 심사·심판청구, 행정소송 기간을 섞지 않는다. 재산세 고지 시기·세액 산정은 쓰지 않는다. 기존 글(property-tax 일반)과 겹치지 않게 불복 절차에 집중한다
