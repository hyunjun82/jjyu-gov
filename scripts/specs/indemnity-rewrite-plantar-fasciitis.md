# 리라이트 — 실비 스포크 족저근막염 (2026-10-12). 네이버 실검색 "족저근막염 실비"에서 gov 글이 안 나온다(수요 있음: 청구·서류·코드·청구 방법). 옛 글이 약관 문구만 되풀이해 치료별 정보가 얇았다.
# 타이틀·소제목: 사장님이 10-12 채팅에서 "하나씩 작성" 지시로 확정한 안 그대로
# 원문: ①보험업감독업무시행세칙 [별표 15] 실손의료보험 표준약관(저장본, CAPTURED-BY) ②손해보험협회 실손의료보험 FAQ ③금융감독원 보험금 청구 안내
# 주의(쓰지 않는 것): 족저근막염 시술·체외충격파 가격(병원마다 다르고 원문에 값이 없다), 병명에 붙는 질병코드의 의학적 분류 해설(원문에 없다 — 소제목 '질병코드'는 '약관이 보상 여부를 한국표준질병사인분류 코드로 정한다는 점과 청구 서류에 코드가 적힌다는 점'만 원문 그대로), 질병코드별 급여 인정기준(심평원 소관, 열지 않음), 보험사별 지급·거절 사례, 도수치료 관리급여 전환(별도 글), 후기·블로그 내용
# 주의(구분): ①약관에 족저근막염이라는 병명은 없다 — 병명이 아니라 급여냐 비급여냐, 비급여 중 체외충격파(3대 비급여 도수치료·체외충격파·증식치료)냐에 따라 한도·횟수·공제가 갈린다. 해당 수치는 원문의 세대 한정(5세대 등)·특약 이름표와 함께 그대로 쓴다 ②체외충격파 한도·횟수는 원문 표에 있는 것만 쓰고, 표에 없으면 쓰지 않는다 ③청구 서류는 손해보험협회 FAQ 원문 그대로(입원·통원·금액 구간)
# 주의(행동): 독자가 지금 할 일 = 진료비 영수증과 진료비 세부산정내역에서 질병코드·급여 여부·체외충격파 항목을 확인하고 실손24 또는 보험사 앱으로 청구하는 것
# 주의(구성): 금액·비율·횟수가 든 비교는 카드 안 표(3열 이하)로 한 번 이상 넣는다. 표 값은 facts 의 값 그대로. 공제금액은 원문 표기 순서·이름표 그대로 '1만원(의원·병원) 또는 2만원(종합병원·상급종합병원)' 형태로 쓴다(이름표를 숫자 앞에 놓으면 짝 검사에 걸린다). 세대·특약 한정이 붙은 값은 반드시 그 말을 함께 쓴다. 약관 인용은 원문 글자 그대로, 한정 표현(다만·경우에만 등)은 빠뜨리지 않는다
