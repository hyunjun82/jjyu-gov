# 리라이트 — 고령운전자 교통안전교육 스포크 2편 (2026-10-26, 노출 없는 옛 글·타이틀 불량). 옛 글은 원문 추출본 없음. 65세무료75세의무비교·2026온라인이수방법 스포크와 허브 본글은 그대로 둔다(65세75세 비교는 비교 글이 이미 있어 이번 글은 예약 쪽으로 방향을 바꾼다).
# 타이틀·소제목: 사장님 10-24·10-26 "40자 이내·소제목 4개와 일치·같은 낱말 두 번 금지·타이틀은 네이버 자동완성 연관검색어로". 자동완성: 75세 면허 갱신 교육·방법·온라인교육, 고령운전자 교통안전교육 예약·온라인·확인증·이수증, 고령운전자 교육장소·시간·신청하기.
# 원문: 도로교통공단 안전운전 통합민원 고령운전자 교통안전교육 안내(safedriving.or.kr oldTraSafeEdu), 교통안전 교육센터(trafficedu.koroad.or.kr).
# 주의(옛 글 오류 점검): 옛 글의 수강료·이수증·인센티브(자진반납 10만원 등)·"3년 주기" 표기는 이 안내 페이지에 없으면 쓰지 않는다. 안내 페이지에 "수강료"와 "이수증" 언급이 없으면 쓰지 말고, 필요하면 "이 안내에는 없다"고만 쓴다. 미이수 불이익은 페이지 문구(75세 이상은 교육을 이수해야 정기적성검사를 받을 수 있다)만 쓴다.
# 주의(구분): 65세 이상 = 권장·오프라인만, 75세 이상 = 의무. 예약은 2차 인증 도입으로 고객지원센터를 통한 예약은 불가하고 홈페이지에서 본인인증 후 직접 신청한다는 원문 문구를 이름표 섞지 말고 쓴다.
# 주의(쓰지 않는 것): 블로그 후기, 보험료 할인율(원문에 율이 없으면), 지역별 교육장 목록
