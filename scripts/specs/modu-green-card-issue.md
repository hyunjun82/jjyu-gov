# 한 편짜리 신규 — 2026-10-07. 계기: 네이버페이 머니스토리 10.6 "교통비 환급에 에코머니까지, 10월에 나오는 '모두의그린카드'란?"(기사 문장·'월 최대 1만 포인트' 같은 기존 그린카드 기준 설명은 쓰지 않고 국토교통부·기후부 9.22 보도자료 원문으로 다시 씀). 기존 k-pass-modu-card(모두의카드)·climate-card-refund(그린카드)는 건드리지 않는다
# 타이틀·소제목은 네이버 자동완성(모두의 그린카드 발급·혜택·신청, 그린카드 에코머니 사용)에 뜬 말로 지음 — 체크카드 소제목은 원문에 근거가 없어 에코머니 사용으로 바꿈
# 주의: 보도자료에 '10월부터 순차 발급'만 있으면 정확한 출시일·카드사별 조건·적립 한도는 쓰지 않는다(기사 속 '월 1만 포인트', '전월실적 20만 원'은 기존 그린카드 기준 설명이라 보도자료 원문에 없으면 notUsed). 카드사 6곳 이름은 원문에 있는 대로만
# 버튼 주의(2026-10-07 사장님): 상단 버튼은 K-패스 사이트(기존 K-패스, 모두의그린카드 안내 없음)가 아니라 그린카드 공식 사이트다. 모두의그린카드는 아직 '10월부터 순차 발급 예정'이므로 '지금 발급된다'고 쓰지 않는다. 서론 행동 문장은 '그린카드 발급'을 확인하는 행동으로 쓰고, K-패스 회원가입·카드 등록은 신청 소제목에서 다룬다. 그린카드 사이트에 '모두의그린카드' 안내가 아직 없으면 그렇게 쓰지 말고 그린카드 카드 소개·에코머니 안내로만 쓴다
