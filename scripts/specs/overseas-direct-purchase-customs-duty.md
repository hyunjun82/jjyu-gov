# 한 편짜리 신규 — 2026-10-23. 11월 트래픽 선점(11.11 광군제·블랙프라이데이 직구철). 개인용 전용 글이 없음. 자동완성: 해외직구 관세 기준/납부/납부 방법/계산/내는법, 직구 관세 환급(방법)
# 타이틀·소제목은 내가 지음(사장님이 '다 작성' 지시, 2026-10-23). 소제목은 자동완성에 뜬 말: 관세 기준 / 관세 계산 / 관세 납부 방법 / 관세 환급
# 1차 출처 = 관세청 해외직구물품 예상세액 조회 페이지(면세 기준·목록통관·수입신고), 관세청 보도자료 2026.03.31 '해외직구 반품, 관세 환급이 편리해집니다'(환급권 전자 양도), 2026.07.31 '면세품 교환 쉬워지고 관세 납부 편리해진다'(납부 가능 금융기관 확대·자가사용 물품 반품 시 부과 취소)
# 주의(숫자): 150달러 이하는 면세, 150달러 초과 시 공제 없이 총과세가격(물품가격+운임+보험료 등)에 과세. 미국은 목록통관 200달러 이하 — '목록통관 대상'과 '면세통관'은 페이지에 나뉘어 적혀 있으니 글자 그대로 구분해 쓴다(섞으면 오해). 블로그의 세율(의류 13% 등)·15~18% 간이세율은 관세청 원문에 없으면 쓰지 않는다
# 주의(범위): 건강기능식품·의약품 등 목록통관 배제 품목은 원문에 있는 범위만. 환율은 '금일 수입신고 과세환율이며 오차 있음'이라는 원문 단서를 살린다. 한도 하향 논의(소액면세 폐지)는 확정된 것이 없어 쓰지 않는다
# 주의(환급): 반품 환급의 기한·금액 기준(수입신고 수리일부터 6개월 이내, 200만 원 등)은 이 보도자료에 있는 것만 쓴다. 정책뉴스(2024)·블로그 숫자는 쓰지 않는다. 환급권 전자 양도·모바일 신청은 보도자료 글자 그대로
# 주의(납부): 납부 가능 금융기관 1곳→3곳 확대는 보도자료 시행 시기를 확인해 '시행 중인지 예정인지' 구분한다(한정 표현 keepWord 판단). 납부 방법은 보도자료·관세청 페이지에 있는 것만
# 주의(행동): 구매 전 예상세액 조회가 첫 행동. 시키는 말투 금지, 서론 200자 이내, 행동 문장에 버튼의 말(예상세액·조회) 포함
