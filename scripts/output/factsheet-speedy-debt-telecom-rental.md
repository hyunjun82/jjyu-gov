## 2. 단서 조항 (본문 반영)

- 조정은 협약을 맺은 채권금융회사에만 미친다 — 내 통신사·할부사가 협약기관인지 조회로 확인해야 한다 (500) → qa1·qa3·qa4
- 인수한 채권도 대상으로 본다 (협약 제5조②) → qa4
- 렌탈료는 대상채권 여덟 가지에 이름이 없고, 렌탈사라는 협약기관 구분도 없다 → qa3에서 "공식 목록에 없음"으로 서술

## 3. 확보하지 못한 것 (본문에 쓰지 않음)

- 렌탈료(정수기·가전·가구)가 심의위원회 인정 채권(협약 제5조①8)으로 다뤄진 사례: 공식 안내 없음
- 통신채무 조정 시 감면율·조정 방식의 세부 기준: 협약 별표에 없고 보도자료에도 없음
- 통합채무조정 이용자 수·금액(29,700명·612.5억원 등): 2025.3월 발표 시점 통계라 현행 수치가 아님 → 본문 미사용
- 자동차 담보가 설정된 할부채권의 담보권 실행 처리: 협약은 부동산담보만 규정, 자동차는 공식 안내 없음
- 핸드폰 기기값(단말기 할부)과 통신요금의 구분 처리: 공식 안내 없음
