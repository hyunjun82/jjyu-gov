# 구성표 — jeonse-guarantee-compare (승인 2026-08-18)

## 타이틀
전세보증보험 가입조건과 보증료 비교, 전세권 설정했으면 거절되나
- 사장님이 주신 키워드(전세보증보험 / 가입 조건 / 비용 / 전세권 설정 차이) 유지
- title-formula 충족: 세부키워드(조건·비교) + 행동어(가입) + 후킹(거절)

## hero 서론 (행동 6단계)
1 공감      전세금 떼일까 불안해서 보증보험 알아본다
2 대안난점  기관마다 요율이 달라 어디에 넣어야 할지 모르겠다
3 금액      같은 2억이라도 연 20만4천원 vs 8만원 — 2.5배 차이
4 반전      HF가 싸지만 전세자금보증 이용 중이어야 한다 / 전세권 설정돼 있으면 말소·이전 필요
5·6 확인·신청 -> 상단 버튼

## 소제목 6개
| 앵커 | 소제목 | 버튼 |
|---|---|---|
| q-where | 전세보증보험 어디에 가입하나요? (HUG vs HF) | |
| q-condition | 가입 조건이 어떻게 되나요? | 슬롯(인덱스 2) |
| q-fee | 보증료는 얼마인가요? | |
| q-discount | 보증료 할인은 누가 받나요? | 슬롯(인덱스 4) |
| q-jeonse-right | 전세권 설정을 했는데 가입되나요? | |
| q-apply | 신청은 어디서 하나요? | 슬롯(마지막) |

## 버튼 목적지
- 상단(ctaLabel/applyUrl) -> HUG 전세보증금반환보증 상품개요
- qa2 -> HUG 상품개요(가입조건)
- qa4 -> HUG 보증료 할인
- 마지막 -> HUG 인터넷보증 / 위탁은행 안내

## 1차 출처
- HUG 전세보증금반환보증 상품개요 (khug.or.kr) — 보증료율 24행 화면캡처 대조
- HF 일반전세지킴보증 (hf.go.kr)

## 쓰지 않는 것
- SGI 서울보증 전세금보장신용보험의 보험료율·가입조건
  사유: sgic.co.kr 이 "보안 프로그램 설치 필요" 알림으로 브라우저·HTML 양쪽 차단.
  안심전세포털도 HUG 상품만 안내해 교차 확인 불가. 공식 채널 확인으로 안내.
- 전세권설정등기 비용 자체 -> 기존 글 jeonse-right-registration 로 연결
