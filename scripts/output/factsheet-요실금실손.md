## 3. 예외·단서 조항 (긍정문 뒤집는 "다만" 전수)

- 미보상 대상은 **그 세 코드로 분류된 요실금**이다. 다른 상병으로 진단·처리된 경우까지 미보상이라고 단정하지 않는다
- 실제 보상 여부는 약관과 구체적 사실관계에 따라 달라질 수 있음(협회가 다른 문항에서 명시한 표현)

## 4. 확인 못 해 쓰지 않는 것

- "자궁탈출증이면 보상된다" 같은 단정 — 협회 원문에 없음. 진단·상병 확인 안내로 처리
- 요실금 수술 급여 기준(심평원) — 이 글에서 확인 안 함
