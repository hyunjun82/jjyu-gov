# 구성표 — learning-card-employed-worker

- 타이틀: 재직자 내일배움카드 신청과 근로시간 기준, 근로계약서와 재직 확인
- 확정: 사장님이 14~26편 세트로 직접 확정 (2026-09-18, 세트 15번). 타이틀·소제목 4개 원문 그대로.
- 허브: /policy/learning-card

## 소제목 (사장님 확정, 변경 금지)

1. 재직 중인 직장인도 신청할 수 있나요?
2. 주 몇 시간 근무부터 재직자로 보나요?
3. 근로계약서를 제출해야 하나요?
4. 재직 사실은 어떻게 확인하나요?

## 2번 소제목 처리 방침

운영규정에는 "재직자"의 근로시간 정의가 없다. 카드 발급은 근로시간과 무관하다.
근로시간이 실제로 갈리는 자리는 따로 있다 — ① 훈련장려금(1개월 소정근로시간 60시간 미만,
1주 15시간 미만 포함이면 대상) ② 고용보험 피보험자 여부(법정직무·외국어 수강 자격,
소득 제외 항목의 예외). 이 구조로 답한다. 없는 기준을 지어내지 않는다.

## 근거

- 제4조제1항 — 대상을 열거하지 않는다(재직·실업 구분 없음)
- 제4조제2항제11호와 단서 5가지 — 대규모기업 만 45세 미만 월평균 임금 300만원 이상 제외,
  기간제·단시간·파견·일용 / 180일 이내 이직 예정 / 경영상 90일 이상 무급휴직 / 사업주 훈련
  미수강 3년 이상 / 육아휴직 중은 제외에서 빠짐
- 제4조제3항 — 제10의2호·제12~15호는 고용보험 피보험자면 지원 가능
- 제6조제1항·제3항 — 제출 서류 4종, 지원대상 확인 서류는 관서장 인정 시 생략,
  관서장이 신원·지원대상 요건 충족 여부를 확인해 HRD-Net 입력
- 제8조제2항 — 법정직무·외국어훈련과정은 피보험자만 수강 신청
- 제49조제1항제2호가목 — 1개월 소정근로시간 60시간 미만(1주 15시간 미만 포함) 피보험자는
  훈련장려금 대상
- 고용24 발급안내 — 재직자(육아휴직 등 휴직자 포함)는 원칙적으로 구직신청 불필요,
  다만 국기훈련·K-DT·일반고 특화·돌봄 특화는 재직 중이어도 구직신청 필요.
  대부분 준비 서류 없음, 자영업자·특고 등 일부만 제출 서류 있을 수 있음
