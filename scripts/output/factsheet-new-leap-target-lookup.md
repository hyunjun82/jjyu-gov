## 2. 단서 조항 (본문 반영)

- 본인명의 휴대폰이 없으면 화면 조회 대신 콜센터·상담센터 확인 → qa3
- 지자체 등록 대부업자 채권은 채권자변동조회로 확인 불가 → qa4
- 채권자변동조회로도 안 나오는 채무(지자체 등록 대부업체, 사인간 채무 등)가 있을 수 있음 → qa4
- 채권자변동정보는 채무자 본인만 열람, 신용점수에 영향 없음 → qa1
