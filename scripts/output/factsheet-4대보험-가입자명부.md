# 팩트시트 — 4대보험 가입자명부 (4대보험-가입자명부)

**타이틀** 4대보험 가입자명부 발급부터 방법까지, 늦으면 손해

## 0. 관할 확정

| 항목 | 내용 |
|---|---|
| 소관 | 국민건강보험공단 (건강보험 EDI, edi.nhis.or.kr) |
| 1차 출처 | https://edi.nhis.or.kr/webedi/help/html/confi/co_03.html (사업장가입자명부발급 신청서 작성법) · https://edi.nhis.or.kr/webedi/help/html/confi/co_06.html (사업장가입자명부 업무설명·용도) |

## 1. 수치

| 항목 | 값 | 1차 출처 | 교차 출처 |
|---|---|---|---|
| 처리기간 | 당일 또는 익일 (받은문서함 확인) | edi.nhis.or.kr co_03.html | - (EDI 자체 안내, 교차 출처 없음 — 단독 출처로만 서술) |

## 2. 단서 조항

- 가입자명부는 건강보험관리 등의 목적 외에는 사용할 수 없다. 신청서 작성 시 명부의 용도를 명확히 기재해야 한다(co_06.html).
- 건강보험 업무목적 외로 사용할 경우 EDI로 신청할 수 없고, 해당 사업장 관할 지사에 직접 방문해 신청해야 한다(co_03.html).
- 명부에는 사업장에서 취득·상실한 가입자의 자격취득일·자격상실일이 나온다. 신청 시 "가입자 전원"과 "가입자 일부" 중 선택하고, 각각 "상실자 포함/미포함"을 선택할 수 있다(co_03.html).
- 명부는 EDI에 등록된 "가입자"(취득신고된 근로자) 기준으로 나온다. 직원을 채용해 4대보험에 가입시킨 이력이 없는 1인 개인사업자는 애초에 사업장 적용(가입) 자체가 되어 있지 않으므로(관련: self-employed-four-insurance-join 글의 사실), 명부에 오를 가입자 자체가 없다 — 이는 두 출처를 결합한 논리적 귀결이며 EDI 페이지가 이 사례를 직접 언급하지는 않는다는 점을 본문에 명시한다.

## 3. 확보하지 못한 것 (본문에 쓰지 않음)

- 팩스·모바일 발급 절차의 세부 화면 — EDI 도움말 페이지가 PC 웹 신청 기준만 설명하고 있어 팩스·모바일 경로는 본문에 구체적으로 쓰지 않는다.
- 국민연금·고용보험·산재보험 각각의 "가입자명부"에 해당하는 서류의 발급 절차 — 이번 조사는 건강보험 EDI 기준만 확인했다.

## 4. 오해 소지 — 본문에서 푼 자리

1. "가입자명부는 아무 용도로나 뗄 수 있다" → 건강보험관리 등의 목적 외에는 사용할 수 없고, 신청 시 용도를 명확히 적어야 한다.
2. "4대보험 가입자명부는 4insure.or.kr에서만 된다" → 건강보험분은 건강보험 EDI(edi.nhis.or.kr)에서 직접 발급된다.
3. "1인 개인사업자도 직원 명부처럼 발급된다" → 채용 이력이 없으면 명부에 오를 가입자 자체가 없다(추론, 직접 출처 없음 — 본문에 추론임을 명시).
