# 팩트시트 — learning-card-unemployment-benefit

- 관할: 고용노동부 / 1차 출처: 국민내일배움카드 운영규정 제4조·제10조·제49조·제50조
  https://www.law.go.kr/LSW/admRulInfoP.do?admRulSeq=2100000279150
- 교차 출처: 고용24 제도안내 / 발급안내
- 확인일: 2026-09-18

## 수치

| 항목 | 값 | 근거 |
|---|---|---|
| 실업급여 수급자 발급 제외 | 없음 | 제4조제2항에 해당 항목 없음 |
| 구직급여 수급 기간과 중복 | 훈련장려금 미지급 | 제50조제1호 |
| 구직활동 지원 수당과 중복 | 미지급 | 제50조제3호 |
| 재정지원 일자리사업 참여와 중복 | 미지급 | 제50조제4호 |
| 훈련 지시 시 진단·상담 | 생략 가능 | 제10조제1항제2호 |
| 장려금 기본 요건 | 총 훈련시간 140시간 이상, 단위기간 출석률 80% 이상 | 제49조제1항 |

## 단서

- 지원제외 열여섯 가지에 실업급여 수급자라는 항목은 없다. 수급 중에도 카드는 발급된다.
- 실업급여나 국민취업지원제도를 신청하면서 이미 구직등록을 마쳤다면 카드 발급을 위해 다시 등록할 필요가 없다(고용24 발급안내).
- 제10조제1항제2호는 「고용보험법」 제51조에 따라 지방고용노동관서의 장이 이 고시에 따른 훈련을 받도록 지시한 사람에 대해 훈련 진단·상담을 생략할 수 있다고 정한다. 고용센터가 훈련을 지시하는 제도가 존재한다는 근거다.
- 훈련장려금은 훈련 참여 기간과 구직급여를 지급받는 기간이 중복되면 미지급이다(제50조제1호). 고용24 제도안내도 실업급여 수급 중이면 훈련장려금을 지급하지 않을 수 있다고 안내한다.
- 구직급여가 끝난 뒤 남은 훈련 기간은 중복이 아니므로, 다른 요건을 채우면 그 단위기간부터 장려금 대상이 될 수 있다.

## 오해 소지

- "실업급여 받으면 카드가 안 나온다"는 틀리다. 막히는 것은 카드가 아니라 훈련장려금 중복 지급이다.
- "훈련을 들으면 실업급여가 자동으로 연장된다"도 내일배움카드 운영규정으로는 말할 수 없다. 훈련연장급여는 고용보험법 소관이다.

## 쓰지 않는 것

- 훈련 수강이 실업인정일의 구직활동으로 몇 회 인정되는지 — 고용보험법·실업인정 기준 소관이고 내일배움카드 운영규정에 근거 조항이 없다. 확인하지 않은 범위라 단정하지 않고 고용센터 확인으로 안내한다.
- 훈련연장급여의 지급 요건·기간 — 같은 이유로 쓰지 않는다. 운영규정에서 확인되는 "훈련 지시" 제도의 존재(제10조제1항제2호)까지만 쓴다.
