# 구성표 — learning-card-account-balance

- 타이틀: 내일배움카드 훈련계좌 개설과 연결 통장, 이체 방법과 잔액 확인
- 확정: 사장님이 13편 세트로 직접 확정 (2026-09-18, 세트 4번). 타이틀·소제목 4개 원문 그대로.
- 허브: /policy/learning-card

## 소제목 (사장님 확정, 변경 금지)

1. 훈련계좌는 어떻게 개설하나요?
2. 어떤 통장을 연결 계좌로 쓸 수 있나요?
3. 계좌로 돈을 이체하는 방법은 무엇인가요?
4. 계좌에 남은 금액은 어디서 확인하나요?

## 이 글의 축 — 전제부터 바로잡는다

검색한 사람은 "훈련계좌 = 돈 넣는 통장"으로 알고 들어온다. 실제로는 직업능력개발계좌는
훈련비 지원한도를 관리하는 전산상의 계좌이고, 입금·이체 절차가 없다. 카드로 결제하면
지원액이 계좌 한도에서 차감되는 구조다(운영규정 제12조제2항). 이걸 3번 소제목에서
정면으로 답한다. 전제를 부정하되 소제목은 사장님 확정본 그대로 쓴다.

## 근거

- 운영규정 제4조제1항 — "훈련비 등을 지원할 수 있는 직업능력개발계좌"
- 제12조제2항 — 카드로 결제해야 하는 금액 3가지(자기부담금·추가부담 훈련비·계좌잔액 초과분)
- 제14조 — 계좌한도 300만원 + 추가 200만원, 총 500만원
- 제15조 — 계좌잔액 차감 / 제16조 — 유효기간 5년, 만료 시 잔액 소멸
- 고용24 발급안내 — 훈련장려금은 별도 신청 없이 본인이 등록한 계좌로 지급
- 1350 상담 — 결제 은행계좌를 해지하면 사고등록계좌가 되어 사용 불가, 출금계좌 변경은 카드사
