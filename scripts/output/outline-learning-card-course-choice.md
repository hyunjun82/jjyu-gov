## 2번 소제목 처리 방침

공식 인기 순위 통계는 공개돼 있지 않다. 지어내지 않는다. 대신 2026-09-18 고용24 훈련
통합검색에서 키워드별 개설 과정 수를 직접 세어(컴퓨터활용능력 1,561 / 제과제빵 916 /
미용사 895 / 요양보호사 758 / 파이썬 299 / 지게차 144 / 굴착기 128 / 영어 69) "과정이
많이 열린 분야"로 답한다. 공식 인기 순위가 없다는 사실도 본문에 밝힌다.
