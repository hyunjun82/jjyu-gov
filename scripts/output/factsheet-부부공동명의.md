재산세는 공동명의로 나눠도 총액이 그대로이며(제113조③), 양도세는 각자 기본공제로 유리하고,
증여세는 명의를 바꾸는 순간 과세 대상이 된다. 세목을 섞어 "공동명의가 절세다"로 뭉치면 틀린다.

⚠ 법령 소관 부처명이 **기획재정부 → 재정경제부**로 표기돼 있다(2025.12.30 개정 반영).
법령 원문 표기를 그대로 쓴다.

## 0-B. 원문 캡처 확인 (절대규칙 7-A)

- 각 1차 출처를 Playwright로 열고 **화면을 캡처해 눈으로 확인했는가**: 예
- 캡처에서 확인한 것(표 구조·단서 위치 등):
  - **국세청 「공동명의 1주택자 특례」 전용 페이지** (nts.go.kr mi=40361&cntntsId=238930, 전체 캡처).
    핵심이 **두 개의 표**로 되어 있어 캡처 없이는 뭉갠다.
    ① "부부가 2주택 이상을 소유한 경우" 표 — 1주택/특례주택/납세의무자 3열 5행. 지분 조합별로
    납세의무자가 배우자·본인·선택으로 갈린다.
    ② "특례 적용 시 혜택" 표 — 특례적용 vs 특례 미적용을 나란히 놓아 **공제금액 12억원 대 각각 9억원씩**,
    **세액공제 가능(최대 80%) 대 불가능**이 한눈에 대조된다. 텍스트로 뽑으면 두 열이 한 줄로 붙어
    12억과 9억이 같은 항목처럼 보인다.
    표 아래 * 각주에 연령·보유기간 공제율이 붙어 있다.
  - **종합부동산세법 제10조의2 캡처** — 제2항 "당해 연도 9월 16일부터 9월 30일까지"가 조문 본문에 있다.
    같은 화면에 제9조 ⑥ 연령별 공제율 표와 ⑧ 보유기간별 공제율 표가 함께 보여, 세액공제가
    두 개의 별도 표로 구성되고 합계 80% 한도(⑤)라는 구조를 눈으로 확인했다.
  - **지방세법 제113조 캡처** — ③항이 "주택을 2명 이상이 공동으로 소유하거나…**합산한 과세표준에** 세율을 적용"
    이다. 바로 위 제111조의2에 1세대 1주택 특례세율 **4구간 표**(6천만원 이하 0.05% … 3억 초과 0.35%)가 있어,
    누진 구간을 지분으로 쪼갤 수 없다는 구조가 표와 조문을 함께 봐야 잡힌다.
  - **소득세법 제103조·제97조의2 캡처** — 제103조는 "각각 연 250만원", 제97조의2는 "양도일부터 소급하여 **10년**".
    제97조의2 ②의 예외 3호(이월과세 적용 세액이 미적용보다 적으면 적용 안 함)가 항 안쪽 번호 목록에 있어
    텍스트로는 본문에 붙어 보인다.
  - **상속세 및 증여세법 제53조 캡처** — 배우자 6억원이 각 호 목록의 1호. 본문 앞부분에 "증여를 받기 전
    **10년 이내**에 공제받은 금액을 합한 금액"이라는 합산 규정이 있어, 6억이 1회 한도가 아니라
    10년 누적 한도라는 점이 목록이 아니라 **본문 문장**에 숨어 있다.
- 텍스트 추출만으로 판단한 항목이 있는가:
  - 조문 문자열의 정확한 인용을 위해 `browser_evaluate`로 텍스트를 함께 뽑았다. 다만 판단(표 구조·단서 위치·
    구간 대조)은 위 캡처를 보고 했고, 텍스트는 인용 오타 방지용이다.

## 2. 단서 조항 전수 확인 ("다만 / 제외")

| 조항 | 단서 |
|---|---|
| 특례 대상 | 세대원 중 1명과 **그 배우자만** 1주택 소유, **둘 다 거주자** (시행령 제5조의2②) |
| 특례 대상 제외 | **배우자가 다른 주택의 부속토지를 소유**하면 제외 (시행령 제5조의2② 단서) |
| 특례 대상 제외 | **배우자가 다른 주택을 소유**하면 특례 적용 안 됨 (국세청 신청대상) |
| 재신청 | 최초 신청 연도의 **다음 연도부터는 변동 없으면 별도 신청 없이 계속 적용** (국세청) / 변동 시 변경신청 (시행령 제5조의2⑤) |
| 세액공제 기준 | **공동명의 1주택자(지정된 사람)의** 연령·보유기간 기준 (시행령 제5조의2⑧) |
| 과세표준 | 배우자 소유 주택지분을 **합산하여** 계산 (시행령 제5조의2⑥) |
| 재산세 세율 | 공동 소유라도 **합산한 과세표준에** 세율 적용 (지방세법 제113조③) → 지분 분할로 누진 회피 불가 |
| 재산세 납세의무 | 공유재산은 **지분권자 각자** 납세의무자, 지분 표시 없으면 균등 (제107조①1호) → 고지서는 나뉜다 |
| 이월과세 예외 | 이월과세 적용 세액이 **미적용보다 적으면 적용하지 않음** (소득세법 제97조의2②3호) |
| 이월과세 필요경비 | 납부한 **증여세 상당액은 필요경비에 산입** (제97조의2①3호) |
| 이월과세 기간 계산 | **등기부에 기재된 소유기간**에 따름 (제97조의2③) |
| 증여공제 | 6억은 **10년 이내 공제받은 금액 합산** 한도 (상증세법 제53조 본문) |

## 3. 경쟁글과 어긋나는 지점 → 교차 판정

### (1) 납세의무자를 누가 되는가 — 국세청 페이지 안에서 서술이 갈린다 ★

- **국세청 「신청대상」**: "해당 1주택의 공동 소유자 중 주택에 대한 **소유 지분율이 큰 자가 납세의무자**가 되며,
  소유 지분율이 동일한 경우 부부간 합의에 따라 신청한 1인이 납세의무자가 됨"
- **국세청 「특례 적용 시 혜택」 표**: 납세의무자 = "**지분율과 무관하게 선택 가능**(본인, 배우자)"
- **시행령 제5조의2③ (개정 2026. 2. 27.)**: "해당 1주택을 소유한 세대원 1명과 그 배우자 중
  **공동 소유자간 합의로 정한 사람**"

**판정**: 시행령이 2026년 2월 27일 개정으로 "지분율이 큰 자" 기준을 없애고 **합의로 정한 사람**으로 바뀌었다.
국세청 「신청대상」 설명은 **개정 전 문구가 남은 것**으로 보이며, 같은 페이지 혜택 표의
"지분율과 무관하게 선택 가능"이 개정 후 규정과 일치한다.
→ 본문은 **시행령(개정 2026.2.27) 기준 = 부부 합의로 정한 사람**으로 쓴다.
국세청 페이지에 두 서술이 함께 있다는 점을 밝히고, 실제 신청 전 관할세무서 확인을 안내한다.
(CLAUDE.md 절대규칙 7의 "정부 페이지도 맹신 금지" 사례 — worklife.kr 350/400만원 건과 같은 유형)

### (2) "공동명의로 하면 재산세가 반으로 줄어든다"

블로그·커뮤니티에 널리 퍼진 서술 → **지방세법 제113조③이 정면으로 부정한다.**
공동 소유라도 주택의 토지와 건물 가액을 **합산한 과세표준**에 세율을 적용한다.
지분권자 각자가 납세의무자가 되어(제107조①1호) **고지서가 나뉘는 것**을 세금이 줄어든 것으로 오해한 것이다.
→ **총액은 같다.** 본문의 핵심 반전으로 쓴다.

### (3) "공동명의로 바꾸면 양도세가 절반"

단독→공동 변경은 배우자 증여다. 증여 후 **10년 이내 양도하면 이월과세**로 취득가액을
증여자가 취득했을 때 금액으로 되돌린다(제97조의2①1호). 즉 10년을 못 기다리면 절세효과가 사라진다.
다만 이월과세를 적용한 세액이 미적용보다 적으면 적용하지 않는다(②3호).
→ "무조건 유리"도 "무조건 불리"도 아니다. 기간과 계산으로 갈린다.

### (4) "매년 9월에 다시 신청해야 한다"

→ 국세청은 최초 신청 연도의 **다음 연도부터 변동이 없으면 별도 신청 없이 계속 적용**된다고 밝힌다.
변동이 있을 때 변경신청(시행령 제5조의2⑤).

## 4. 2026 세제개편안과의 관계 (섞지 않는다)

기획재정부 2026년 8월 3일 발표 개편안은 1주택 종부세 과세기준을 공시 12억 → 14억으로,
양도소득 기본공제를 250만 → 2,500만원으로 올리는 내용이다.
**국회 통과 전이고 종부세는 2027년부터, 양도세는 2028~29년 단계 시행 예정이다.**
→ 본문 계산은 **현행 12억 / 250만원**으로 하고, 개편안은 "확정 아님"을 명시해 별도로만 언급한다.
개편안 수치로 계산하면 지금 신청하는 사람에게 틀린 안내가 된다.
(기존 허브 real-estate-tax-reform-2026 이 개편안을 담당한다 — 중복 서술하지 않는다)

## 5. 쓰지 않는 것

- **개인별 유불리 결론** — 공시가격·지분율·연령·보유기간 조합으로 갈린다. 일반화하면 틀린다.
  내부 계산기(/calc/jongbuse)로 넘긴다.
- **취득세 절세 효과** — 취득세는 취득 당시 과세표준 전체에 세율을 적용하므로 공동명의로 나눠도
  총액이 달라지지 않는다. 다만 조문 대조를 이번에 하지 않았으므로 **수치로 단정하지 않는다.**
  (지방세법 취득세 장 별도 검증 후 스포크화 — 백로그)
- **주택임대소득 분산 효과** — 별도 검증 필요. 이번 범위 아님.
- **홈택스 딥링크** — 세션 토큰이 붙어 글에 못 박는다(사용자 지시로 홈택스 외부행 금지).
  버튼은 내부 계산기와 국세청 특례 안내 페이지로 보낸다.
