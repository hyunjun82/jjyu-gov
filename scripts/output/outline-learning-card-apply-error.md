# 구성표 — learning-card-apply-error

- 타이틀: 내일배움카드 신청 오류와 선처리 실패, 전산 상담과 고용센터 문의
- 확정: 사장님이 14~26편 세트로 직접 확정 (2026-09-18, 세트 24번). 타이틀·소제목 4개 원문 그대로.
- 허브: /policy/learning-card

## 소제목 (사장님 확정, 변경 금지)

1. 내일배움카드 신청이 안 될 때는 어떻게 하나요?
2. 선처리 작업 실패는 무슨 뜻인가요?
3. 전산 상담은 어디에 요청하나요?
4. 고용센터에는 무엇을 물어보면 되나요?

## 2번 소제목 처리 방침

"선처리 작업 실패"는 운영규정에도, 고용24 고객센터에도 정의가 없다.
2026-09-18 고용24 고객센터 통합검색에서 "선처리"로 검색한 결과가 0건이었다
(자주 묻는 질문·자료실·고용정책 전체 대상). 뜻을 지어내지 않는다.
대신 규정이 실제로 정해 둔 것 — 접수 거부·미발급은 반드시 문서나 설명으로 통지된다는
제6조제4항·제7조제2항 — 을 두고, 화면 메시지는 전산 문의로 넘긴다.

## 근거

- 제4조제2항 — 지원제외 대상 16호 (공무원연금·사학연금 재직자, 만 75세 이상, 외국인,
  지원·융자·수강 제한 기간 미종료, 반환명령 미이행, 타 부처 훈련 참여, 생계급여 수급,
  초·중등 재학생, 고등교육법 재학생, 대규모기업 45세 미만 월평균임금 300만원 이상,
  월평균소득 500만원 이상 사업자, 매출 4억원 이상 사업자 등)
- 제4조제5항·제6항 — 지원제외 판단 시점(신청일 기준 / 제11~15호는 2년 주기 첫 수강신청)
- 제5조제1항 — 계좌발급 절차 3단계(접수 → 적격 확인 → 발급)
- 제6조제1항 — 제출 서류 4종(별지 제1호 신청서, 제2호 동의서, 제1호의2 확인서, 지원대상 확인 서류)
- 제6조제4항 — 법령 위반·지원제외가 아니면 접수 보류·거부·반려 금지, 접수하지 않으면 이유를 구체적으로 설명
- 제7조제1항 — 접수일부터 7일 이내 발급 여부를 HRD-Net 또는 서면으로 통지
- 제7조제2항 — 미발급 시 별지 제5호서식 계좌 미발급 통지서로 문서 통지
- 제7조제3항 — 이의신청(별지 제6호서식) → 접수일부터 7일 이내 이의심사 결과 통지(별지 제7호서식)
- 제7조제4항 — 필요시 제55조 내일배움카드심의회 심의
- 제8조제1항 — 140시간 이상 과정·국취제 참여자 등은 훈련 진단·상담 후 수강신청
- 제9조제1항 — 훈련 진단·상담은 14일 이내
