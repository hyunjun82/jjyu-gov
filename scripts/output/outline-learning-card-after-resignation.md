# 구성표 — learning-card-after-resignation

- 타이틀: 퇴사 후 내일배움카드 신청과 상실신고, 퇴직증명서와 유형 변경
- 확정: 사장님이 14~26편 세트로 직접 확정 (2026-09-18, 세트 17번). 타이틀·소제목 4개 원문 그대로.
- 허브: /policy/learning-card

## 소제목 (사장님 확정, 변경 금지)

1. 퇴사한 뒤에 내일배움카드를 신청해도 되나요?
2. 고용보험 상실신고가 끝나야 하나요?
3. 퇴직증명서를 내야 하나요?
4. 재직자에서 실업자로 유형이 바뀌나요?

## 축 — "유형"이라는 말 자체를 바로잡는다

2020년 1월 1일부터 국민내일배움카드는 실업자·재직자 구분 없이 하나로 통합됐다(1350 상담).
따라서 "재직자 카드 → 실업자 카드"로 갈아타는 유형 변경 절차는 없다.
달라지는 것은 ① 구직신청 필요 여부 ② 훈련장려금 대상 여부 ③ 외국어·법정직무 수강 자격이다.
상실신고 완료를 발급 요건으로 정한 조항도 없다 — 없는 요건을 만들지 않는다.

## 근거

- 제4조제1항·제2항 — 대상 열거 없음, 지원제외에 "퇴사자" 항목 없음
- 제4조제5항 — 지원제외 해당 여부는 신청일 기준으로 판단
- 제6조제1항 — 제출 서류 4종, 지원대상 확인 서류는 관서장 인정 시 생략
- 제6조제3항 — 관서장이 신원·지원대상 요건 충족 여부 확인 후 HRD-Net 입력
- 제7조제1항 — 접수일로부터 7일 이내 발급 여부 통지
- 제8조제2항 — 법정직무·외국어는 피보험자만 수강
- 제49조제1항 — 근로계약을 체결하지 않은 사람이 장려금 기본 대상
- 고용24 발급안내 — 실업 상태면 구직신청 필요, 재직자는 원칙적으로 불필요
- 1350 상담 — 2020.1.1부터 실업자·재직자 구분 없이 하나로 통합
