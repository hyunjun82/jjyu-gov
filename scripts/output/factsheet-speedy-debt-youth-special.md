- speedy-debt-youth-special-1.png(1940 화면): 상단 탭 "지원대상별 특례" → 하위탭 "미취업청년·대학(원)생"이 기본 선택. 요약 카드 5개(연체기간 90일 이상 / 대상 34세 이하 미취업청년, 대학(원)생 / 원금감면 미상각채권 최대 30%, 상각채권 20~70% / 상환유예 최장 5년 이내 / 신청비용 5만원 면제), 신청 서류 표(본인확인서류 택1 + 자격확인서류)까지 눈으로 확인

## 2. 단서 조항 (본문 반영)

- 대학(원)생은 나이가 아니라 재학 여부로 본다 — 「고등교육법」 또는 기타 법률에 따른 대학·대학원 재학생 (1940) → qa1·qa2
- 청년 특례는 연체 90일 이상이 전제라 연체 30일 이하인 신속채무조정과 대상이 갈린다 (1940 · 520) → qa4
- 서류는 신분증이 기본이고, 소득·재산·신청조건 확인을 위해 추가 서류를 요청할 수 있다 (520 · 1940) → qa3
- 미취업 증명은 사실증명원(지방세무서 또는 국세청 홈택스)으로 한다 (1940) → qa3

- 2022년 금융위 발표 「신복위 신속채무조정 청년 특례」의 감면 내용·시행기간·종료 여부: 보도설명자료(fsc 78108)에는 취지만 있고 요건이 없으며, 현행 신복위 특례 페이지에는 청년이 없다 → 현행 화면 사실만 서술
