# 구성표 — learning-card-university-student

- 타이틀: 대학생 내일배움카드 신청과 수업연한, 휴학생과 복학해도 되나요
- 확정: 사장님이 14~26편 세트로 직접 확정 (2026-09-18, 세트 18번). 타이틀·소제목 4개 원문 그대로.
- 허브: /policy/learning-card

## 소제목 (사장님 확정, 변경 금지)

1. 대학생도 내일배움카드를 신청할 수 있나요?
2. 수업연한이 얼마나 남아야 되나요?
3. 휴학생이나 군휴학 중에도 되나요?
4. 복학하면 자격이 없어지나요?

## 3·4번 소제목 처리 방침

운영규정 제4조제2항제10의2호는 "「고등교육법」 제2조 및 제29조의2에 따른 학교의 재학생"을
제외하고, 가목(졸업까지 남은 수업연한 2년 이내)과 라목(원격대학 재학생)을 단서로 뺐다.
휴학생이 "재학생"에 포함되는지, 복학 시 자격이 어떻게 되는지는 조문이 직접 답하지 않는다.
확인된 것(재학생 기준·판단 시점)만 쓰고, 휴학 처리 여부는 고용센터 확인으로 넘긴다.
제4조제5항(신청일 기준 판단)과 제6항(2년 주기 판단)이 시점 문제의 근거다.

## 근거

- 제4조제2항제10의2호 — 고등교육법 제2조·제29조의2 학교 재학생 제외,
  가목 졸업까지 남은 수업연한 2년 이내, 라목 원격대학 재학생은 제외에서 빠짐
- 제4조제2항제10호 — 초·중등교육법 학교 재학생 제외(고3은 단서로 빠짐)
- 제4조제3항 — 제10의2호에 해당해도 고용보험 피보험자면 지원 가능
- 제4조제5항 — 지원제외 해당 여부는 신청일 기준 판단
- 제4조제6항 — 제11호~제15호는 계좌발급일로부터 매 2년 주기 첫 수강신청에서만 판단
  (제10의2호는 이 주기 대상이 아님 → 수강신청 때마다 신청일 기준으로 본다)
- 고용24 발급안내 — "졸업까지 남은 수업연한이 2년 이상인 대학/대학원 재학생" 제외로 안내
