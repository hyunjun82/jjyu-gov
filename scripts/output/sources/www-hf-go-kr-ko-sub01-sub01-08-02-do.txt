공사홈페이지 인터넷금융서비스 또는 스마트주택금융APP에서 신청 가능

신청 전 준비
- 본인인증: 신청인의 공동인증서(기혼 또는 결혼 예정의 경우 배우자 또는 결혼예정자의 배우자의 공동인증서도 필요)
- 기본서류: 신청인 및 배우자의 재직 및 소득 정보 / 사망에 따른 상속인 채무인수 시 사망사실 및 상속자격 증빙서류(망자의 기본증명서, 상속인의 가족관계증명서 등) / (신청 이후 담당자 안내에 따라) 채무인수신청서 및 채무인수약정서, 근저당권변경계약서
- 필요정보: 신청 시 채무인수 대상 대출에 대한 아래의 정보 필요
  ① 대출 취급기관
  ② 공사가 관리하는 채무인수 계좌번호
  ③ 채무 인수 사유(매매, 상속, 부부간 채무인수, 배우자 상속, 기타(증여 등))
- 신청일자: 스크래핑(온라인 서류제출)을 위해 월~금 09:00-22:00 권장. 이외 시간대 신청 시 스크래핑 오류가 발생할 수 있으며, 이 경우 신청 후 별도로 스크래핑이나 실물로 서류 제출을 해야 함

[보금자리론 채무인수 신청 절차 요약]
채무인수대상 대출계좌조회 → 채무인수 금융기관/계좌번호 입력 → 채무인수 사유(매매/상속/부부간 채무인수/배우자 상속/기타(증여 등)) 입력 → 정보제공동의 → 담보주택정보 등록(채무인수 예정일/담보제공자 입력) → 인적사항·가족현황 등록 → 주택보유 정보 등록(보금자리론은 무주택자만 신청 가능) → 소득정보 등록(부부합산소득 7천만원 이하 충족, 합산소득 0이면 채무인수 불가. 단 배우자 사망에 따른 상속인의 채무인수, 배우자 간 채무인수는 소득 산정 생략) → 우대금리 정보 등록(기존 대출에 적용된 우대금리를 초과하는 금리 우대 불가. 다만 사망에 따른 상속인의 채무인수는 기존대출의 금리우대 요건 미충족 시에도 기존 우대금리 적용 가능) → 대출가능여부 확인 → 신청 완료

[디딤돌대출 채무인수 신청 절차 요약]
채무인수대상 대출계좌조회 → 채무인수 사유 입력 → 세대주 확인(디딤돌대출의 신청인은 민법상 성년인 세대주) → 담보주택정보 등록 → 인적사항·가족현황 등록 → 주택보유 정보 등록(디딤돌대출은 무주택자만 신청 가능) → 자산정보 등록(부부합산 자산금액이 일정금액을 초과할 경우 신청불가, 대출신청 완료 후 주택도시보증공사(HUG)에서 자산심사 진행) → 소득정보 등록(부부합산소득 7천만원 이하 충족, 합산소득 0이면 채무인수 불가) → 부채정보 등록 → 우대금리 정보 등록 → 대출가능여부 확인 → 신청 완료
