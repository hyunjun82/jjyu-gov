===== [1] 유형별 임대료 (원문 표기 그대로) =====
영구임대      : 시세의 30%
국민임대      : 시중 시세 60~80%
행복주택      : 시중 시세 60~80%
통합공공임대   : 시중 임대시세 35~90% (소득 구간에 따라 35%부터 90%까지)
장기전세      : 전세 계약 방식

통합공공임대 임대료는 소득 구간별로 시세의 35%, 40%, 50%, 60%, 70%, 80%, 90%로 나뉜다.
가장 낮은 구간이 35%, 가장 높은 구간이 90%다.

===== [2] 매입임대 임대료 (원문 표기 그대로) =====
대상에 따라 시세의 30%~90%
청년 매입임대        : 시세의 40~50%
고령자 매입임대      : 시세의 40%
신혼·신생아 매입임대 Ⅰ : 시세의 30~40%
신혼·신생아 매입임대 Ⅱ(전세형) : 시세의 70~80%

===== [3] 소득 기준 잣대 =====
통합공공임대만 기준 중위소득을 쓰고, 영구·국민·행복·장기전세는 도시근로자 월평균소득을 쓴다.
통합공공임대 : 우선공급 중위 100% 이하 / 일반공급 중위 150% 이하
국민임대     : 도시근로자 월평균소득 70% 이하 (1인 90%, 2인 80%)
행복주택     : 도시근로자 월평균소득 100% (1인 +20%p, 2인 +10%p, 맞벌이 120%)
장기전세     : 도시근로자 월평균소득 100% 이하 (60㎡ 이하)

===== [4] 자산 기준 =====
총자산 34,500만원 / 자동차 4,542만원 (국민·행복·통합공공임대)
장기전세 : 총자산 34,500만원 × 지역계수 / 자동차 4,542만원

===== [5] 거주기간 (원문 표기 그대로) =====
국민임대 : 30년, 분양전환 안 됨
행복주택 : 대학생·청년·산업단지근로자 10년
          신혼부부·한부모가족·일자리연계형 지원주택 입주자 10년(자녀 있는 경우 14년)
          주거급여수급자·고령자 20년
장기전세 : 20년 범위
영구임대·통합공공임대 : 임대가이드에 표기 없음

===== [6] 공급 방식 =====
LH가 이미 지어진 집을 사서 다시 임대하는 매입임대가 따로 있다.
