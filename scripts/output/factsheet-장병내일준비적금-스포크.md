## 2. 확정 수치·조건

### 가입
- 가입대상: 대한민국 병역의무 이행자 — **현역병, 상근예비역, 사회복무요원, 대체복무요원** (리플릿 1쪽)
  - 국방부 페이지 단서: "병 급여 및 복무관리 체계를 적용받는 자원 한정" → **장교·부사관(간부)은 대상 아님**
- 가입기간: 최소 1개월 이상 최대 24개월
  - 육군·해병·상근예비역 1~18개월 / 해군 1~20개월 / 공군·사회복무요원 1~21개월 / 대체복무요원 1~24개월
- **잔여 복무기간이 1개월 이상 남은 자에 한하여 신규가입 가능** (리플릿 1쪽 각주 / 4쪽 재확인)
  - 연혁: 원래 최소 6개월 이상 → **'24. 6월부터 최소 1개월 이상** (국방부 페이지)
- 가입한도
  - [2024년 12월까지] 1인 2계좌(동일은행 불가), 각 계좌별 월 20만원, 개인별 최대 월 40만원
  - **[2025년 1월부터] 1인 2계좌(동일은행 불가), 각 계좌별 월 최대 30만원, 개인별 최대 월 55만원**
  - **납입한도는 5만원 단위로 가능 / 납입한도 중도 변경 불가** ← 중요
- 가입 가능 은행 **14개**: NH농협·신한·우리·하나·IBK기업·KB국민·수협·DGB대구·BNK부산·광주·제주·전북·BNK경남·우정사업본부

### 가입자격확인서
- 신병교육기관: 부대 인사담당자가 통합 발급 → 개인(훈련병) 분배
- 자대 전입 후 현역병·상근예비역: 행정반의 **국방인사정보체계**에서 본인 신청 → 부대 인사담당자 승인 후 출력
- 사회복무요원: [온라인] **사회복무포털 sbm.mma.go.kr** / [오프라인] 소속 복무기관 담당자
- 대체복무요원: 소속 복무기관 담당자에게 신청
- 온라인 비대면(현역병·상근예비역·사회복무요원): 나라사랑포털 APP → '장병내일준비적금 가입신청' → 증명서(가입자격확인서) 신청·발급 → '장병내일준비적금가입하기' → 제출 은행 선택 → 호출된 은행 앱에서 가입
- **가입자격확인서는 외부 인터넷 상 발급 불가** (부모님께는 나라사랑포털로 메일 발송 가능)
- **유효기간 발급일로부터 3개월**
- 2개 은행 가입 시 확인서 **2부** 필요
- 개명(改名)자는 적금 개설이 거절될 수 있음 → 은행에 제출서류 사전 확인

### 납입
- 방법 3가지: 자동이체 / 급여 중앙공제 / 개인 직접 납입
- **가입 첫달 납입액은 반드시 개인이 직접 납입** (중앙공제·자동이체 모두 다음달부터 반영)
- **전역(소집해제) 해당월도 중앙공제가 안 되므로 전역일 전까지 개인이 직접 납입**
- 중앙공제는 **월 20일 이전 신청**해야 반영 / 20일 이후 신청 시 공제 안 될 수 있음
- 중앙공제 예시: 월 급여 610,200원 − 월 적금액 200,000원 = 실제 급여입금 410,200원
- **개인 미확인으로 정상 납입되지 못한 회차는 소급 납입도, 매칭지원금도 지급하지 않음** ← 손실 재료

### 해지 / 매칭지원금
- 매칭지원금 = '22년 1월 납입분부터. 연도별 지원비율 **'22년 원리금의 33%, '23년 원리금의 71%, '24년~ 원금의 100%**
- 대상: 장병내일준비적금을 가입하고 **만기해지**하는 병역의무 이행자
- **중도해지 시 이자소득 비과세 혜택과 정부지원금 모두 못 받음** (국방부 페이지 유의사항 1)
- 지급: 만기해지 시 가입은행별 개인계좌로 입금 — **적금 해지시점 익월 25일**
- **별도 신청 불필요** — 해지 시 전역일(소집해제일)이 포함된 서류를 은행에 제출하면 매칭지원금이 자동 신청됨 (5쪽 Q&A)
- 조기전역자·신분전환자: 만기해지 후 소속부대 인사과로 추가서류(만기해지영수증, 적금거래내역서) 제출 → **2~3개월 소요**
- 전체 복무기간 동안 다 납입하지 않았어도 대상 — 해지 시 최종 납입된 금액 기준으로 지원
- 대면 해지: 가입 은행 방문, 신분증 지참 필수. 서류는 병역증·전역증·병적증명서·복무사실확인서(대체복무요원) 중 **택 1(원본)**.
  전역에 따른 만기해지는 **전역일(소집해제일)이 포함된 서류** 필수. 은행별 1부씩(2개 은행이면 2부)
- 비대면 해지: 나라사랑포털 APP → 장병내일준비적금 → 전역확인서(전자지갑) 발급 → 증명서 제출 → 은행 선택 → 은행 APP 호출 → 해지신청
  - 이용대상: 국방부(현역병·상근예비역), 병무청(사회복무요원)
  - 제외: 조기전역자·신분전환자(은행 방문 후 소속부대 인사과 제출) / 법무부 소속 대체복무자(DB 미구축)

### 자산형성 예시 (육군 18개월 / 월 40만원 기준 — 국방부 표기 그대로)
- '23년 12월까지 납입분: 원금 720만 + 은행이자(5%) 28.5만 + 국가지원이자(1%) 5.7만 = 만기 시 754.2만
  + 매칭지원금 약 535.5만(원리금의 71%) = **약 1,289만원**
- '24년 납입분부터: 원금 720만 + 은행이자(5%) 28.5만 = 만기 시 748.5만
  + 매칭지원금 720만(원금의 100%) = **약 1,468.5만원**

## 4. 경쟁글과 어긋나는 지점 → 교차 판정

- 블로그 다수가 "월 40만원 한도"로 적혀 있음 → **2024년 12월까지의 옛 한도**다.
  2025년 1월부터 55만원. 국방부 페이지·리플릿 두 곳에서 동일 확인 → **55만원이 맞다.**
- "매칭지원금은 따로 신청해야 한다"는 서술 → 5쪽 Q&A가 **자동 신청**이라고 명시.
  단 전역일 포함 서류 제출이 조건. → **"신청서를 따로 내는 것은 아니고, 서류가 신청을 대신한다"**로 쓴다.
