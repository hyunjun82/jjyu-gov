## 2. 행동 검증

- 버튼 목적지 URL을 확인했는가: 예
  - 내보험찾아줌 https://cont.knia.or.kr — **Playwright는 매크로 차단(Mbuster) 페이지로 막히나 실제 브라우저 UA로 HTTP 200 확인**. 사용자는 정상 이용 가능. check-cue-value SERVICE_ROOTS에 이미 등록된 도메인
  - 손보협회 실손 FAQ https://kpub.knia.or.kr/productDisc/lostHealth/lostHealthFaq.do — 200, 직접 열람 완료
  - 실손24 https://www.silson24.or.kr/claim/web/ — 앞선 검증에서 확인 완료
- 로그인/보안프로그램/인증서 등 진입 장벽: 내보험찾아줌은 본인인증 필요, 협회 공시는 없음
- 누가 신청할 수 있는가: 내보험찾아줌은 본인 명의 계약 조회(사망자 계약은 상속인 조회 별도)
- 기관이 실제로 쓰는 메뉴명·동사: 협회 "보험료 및 갱신,재가입", "보장(보장하지 않는) 내용" / 내보험찾아줌 "내보험 찾아줌"

## 3. 예외·단서 조항 (긍정문 뒤집는 "다만" 전수)

- **할증은 모든 실손에 적용되지 않는다** — 4세대는 특별약관, 5세대는 특별약관2에 한함. 1~3세대는 이 구조가 아님
- 협회 원문 표현이 "**과거에 판매된 일부 실손의료보험 상품은** 개인별로 차등·적용되지 않았습니다" — '일부'라는 표현이 있으므로 1~3세대 전부가 무조건 무관하다고 단정하지 않는다
- 갱신 안내 시점(15일 전)은 "**보험회사 별로 다를 수 있습니다**"라고 협회가 명시
- 자동갱신 통지 기한도 회사별 상이 가능
- 재가입 시 보험회사가 인수 조건(재가입 가능 최고 연령 등)을 설명 — 연령에 따라 재가입이 제한될 수 있음
- 할증 폭·할인 폭의 구체적 비율은 특별약관2 기준으로만 협회가 언급 → 다른 특약에 그대로 적용하지 않는다

## 4. 확인 못 해 쓰지 않는 것

- 보험사별 실제 인상률 숫자 — 매년 변동, 협회 통계 페이지에서 직접 확인하도록 안내
- 1~3세대의 할증 여부 단정 — '일부'라는 원문 표현 때문에 "1~3세대는 할증 없음"으로 단정하지 않고 "내 증권·약관 확인" 안내

## 5. 기존 글 정합

- 기존 글: 실손보험/갱신재가입.tsx(갱신·재가입 개념과 세대별 주기 축), 24세대전환판단.tsx(세대별 자기부담률·전환 판단)
- 이 글의 축: **내 세대·특약이 할증 대상인지 판별 → 1~5등급 구간 → 갱신 전에 할 수 있는 것**
- 수치 정합: 24세대전환판단.tsx의 '5세대 자기부담 급여20%, 중증비급여30%, 비중증비급여50%'와 충돌 없음(이 글은 보험료 할증, 저 글은 자기부담률)
- 배치: indemnity-insurance-generations 허브, 영문 slug `nonpayment-premium-surcharge`
