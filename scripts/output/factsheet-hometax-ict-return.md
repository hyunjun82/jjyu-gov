## 쓰지 않는 것
- 신고 화면 안 입력 순서·칸 이름 — 로그인 필요, 확인 못 함
- 국세청 개별소비세 안내 페이지 — 없음(국세신고안내에 개별소비세 항목 없음)
- 기준가격 금액·현재 세율 — 시행령 미정리
