## 각 카드에 들어갈 사실 (팩트시트에서)

### qa1 개인워크아웃은 어디서 신청하나요?
- 1930의 세 채널: 전화(1600-5500, 오전 9시~오후 6시 / 해외 +82-2-6337-2000) · 인터넷(방문·온라인 상담) · 모바일(APP) 예약
- 신청 자체는 상담 예약에서 시작 — 상담을 거쳐야 접수로 이어진다
- cyber.ccrs.or.kr 관련 페이지는 인용하지 않음(콘텐츠 없음 + 보안 확인창)
- **box**: 신청 채널 세 가지

### qa2 신청 절차는 어떤 순서인가요?
- 1720의 11단계 흐름을 축약: 상담·접수 → 채권금융회사 통지 → 추심 등 행위 금지 → 채권신고 → 심사(심의) → 채무조정안 동의 요청 → 동의 회신 → 합의서 체결(연체정보 해제·공공정보 등록) → 변제계획 이행 → 상환완료
- 협약 조문으로 기한을 채운다: 채권신고 2주(제8조②) → 심의 30일, 연장 시 +30일(제9조①③) → 동의 회신 10일(제10조①), 무응답이면 동의 간주(제10조⑤)
- 확정 요건: 무담보·담보 각각 과반수 동의(제10조④)
- 전체는 약 2개월(1720)
- **table**: 단계 → 기한

### qa3 준비할 서류는 무엇인가요? → 버튼 ②
- 본인확인서류 택1 6종(1930 표 그대로, PASS 인정불가 단서 포함) — 3번 편과 같은 서류지만 이번엔 "신청 절차" 맥락에서 반복 없이 짧게
- 협약 제7조①의 신청서 기재사항: 성명·주민등록번호·주소·연락처 / 재산 및 채무내역 / 소득
- 반려 사유(제7조③): 배제사유 해당 또는 요청 서류 미제출·허위제출 시 반려될 수 있다는 점을 짚어 성실 제출을 강조
- 내부 링크는 걸지 않음(3번 편이 이미 서류를 자세히 다룸 — 여기선 "무엇을 내야 하는가"의 뼈대만)

### qa4 접수통지는 언제 오나요? → 버튼 ③
- 핵심 답: **신청 다음날** 채권금융회사에 접수 사실이 통지된다(1720)
- 근거: 협약 제8조①("특별한 사유가 없으면 즉시 통지") — 표현 차이를 짚고 실무 시점(다음날)을 답으로 제시
- 그 뒤 흐름: 채권신고 2주 → 심의 30일(+30일 연장 가능) → 동의 회신 10일 → 확정
- 이 구간에 상환 중단 유의사항도 붙인다: 접수일부터 특별한 사유 없는 한 개별 상환 중단
- **box**: 접수통지 이후 시계

## FAQ 2개
1. 신청비와 예납금은 어떻게 내나요? → 접수 시 교부받은 접수증의 입금계좌(기업은행 가상계좌)로 입금, 모르면 콜센터 문의 (출처 2500) — 금액은 공식 안내에 없음을 밝힘
2. 채권금융회사가 동의 기한 내에 답이 없으면 어떻게 되나요? → 협약 제10조⑤, 동의한 것으로 본다 (출처 2590)

## 쓰지 않는 것
- 신청비·예납금 구체 금액 — 공식 안내에 없음(20번 편 소관)
- 온라인 비대면 신청의 화면별 절차 — cyber.ccrs.or.kr 콘텐츠 없음
- 반려 후 재신청 대기기간 — 2번 편에서 이미 다룸(중복 방지)
