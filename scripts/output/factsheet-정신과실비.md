## 0. 관할 확정
- 기관 2곳 이상?: 아니오. 보상 기준=금감원 표준약관(별표15), 청구 창구=실손24, 소비자 안내=손해보험협회 공시실.
- 이 글이 다루는 기관: 금융감독원 / 손해보험협회 / 보험개발원(실손24)
- 법령: 보험업감독업무시행세칙 제5-13조제1항 [별표15] 표준약관

## 1. 확정 사실
| 항목 | 값 | 근거 |
|---|---|---|
| 우울증(F32·F33 ∈ F30~F39) 급여 | **보상** (단서에 포함) | 표준약관 p209 1호 단서 |
| 공황장애(F41 ∈ F40~F48) 급여 | **보상** (단서에 포함) | 표준약관 p209 1호 단서 |
| 정신질환 비급여 | **면책** (단서 없음) | 표준약관 p260 1호 |
| 단서에 포함된 코드 | F04~F09, F20~F29, F30~F39, F40~F48, F51, F90~F98 | p209 |
| 지급 기한 | 접수일부터 3영업일 이내 | 제8조 p213 |
| 청구 서류 | 진료비영수증·세부내역서·원외처방전·약제비 영수증 | 실손24 FAQ |

- 교차출처: p209(급여)와 p260(비급여) 두 면 대조로 단서 유무 확인. 손보협회 FAQ가 5세대 기준 참고자료임을 명시 → 세대별 단정 회피.

## 2. 행동 검증
- 버튼 목적지: https://www.silson24.or.kr/claim/web/ (캡처 확인). 로그인 없이 안내 접근, 청구 시 본인인증.
- 대리 청구: 가능(자녀·부모·제3자 메뉴).
- 기관 동사: "청구".

## 3. 예외·단서
1. **급여만 보상, 비급여는 면책** — 상담·검사가 비급여로 처리되면 빠진다.
2. 단서 목록에 **없는** F코드(예: F10~F19 정신활성물질 사용 장애, F50 섭식장애 일부, F60~F69 인격장애)는 급여여도 면책 → 본문에서 "모든 정신질환"이라고 쓰지 않는다.
3. 보험 가입 단계는 청구와 별개 — 손보협회 FAQ에 '계약 전 알릴 의무'가 별도 문항으로 있음. **가입 거절·할증 여부는 보험사 인수 기준이라 단정 금지**, 알릴 의무 사실만 서술.
