## 원문으로 잡아낸 오류 3건
- 행복주택 청년·대학생 거주기간: 항간 "6년" -> LH 원문 10년
- 국민임대 임대료: 기존 글 "60~70%" -> LH 원문 60~80%
- "장기전세는 SH만" -> LH 임대가이드에 장기전세 탭 있음, 정의에 한국토지주택공사 명시

## 쓰지 않는 것
- 영구임대·통합공공임대 개인 최대 거주기간 (LH 임대가이드에 표기 없음)
- 재계약 주기 2년 (원문 확인 못 함)
- SH 장기전세 소득·자산 수치 (SH 페이지에 물량만 있음)
- 영구임대 총자산 기준 (LH 영구임대 탭에 자산 항목 없음)
