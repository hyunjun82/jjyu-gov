# 팩트시트 — 골절 진단비와 실비

> 2026-08-10. 타이틀: "골절 진단비와 실비, 둘 다 받으면 중복될까?"

## 0. 관할 확정
- 기관 2곳 이상?: 아니오. 실손 기준=금감원 표준약관, 실손/정액형 구분=손해보험협회 공시, 청구=실손24.
- 골절진단비는 **정액형 특약**이라 상품별 약관 영역 → 금액·대상 골절 범위는 공시에 없어 단정 금지.
- 법령: 보험업감독업무시행세칙 [별표15] 표준약관

- 텍스트 추출만으로 판단한 항목: 없음.

## 1. 확정 사실
| 항목 | 값 | 근거 |
|---|---|---|
| 골절 치료비(실손) | 면책 질환 목록에 없음 → 보상 대상 | p209·p258 |
| 실손 지급 방식 | 실제 지불한 의료비 − 자기부담금 | 협회 비교표 |
| 정액형(진단비) 지급 방식 | 치료비와 무관한 사고별 약정 정액 | 협회 비교표 |
| 실손 다수보험 | 실제 부담액 초과하지 않도록 **회사별 비례 보상** | 협회 비교표 |
| 정액형 다수보험 | **중복과 무관하게 각 계약의 약정금액 보상** | 협회 비교표 |
| 목발·팔걸이·보조기 구입비 | 면책 (진료 재료) | p259 4호 |
| 서류·지급 | 자동전송서류 4종 / 접수 후 3영업일 | 실손24 FAQ, 제8조 |

- 교차출처: 비교표(협회) ↔ 표준약관 면책 목록(금감원) 대조. 두 문서가 같은 구조를 서로 다른 방식으로 서술.

## 2. 행동 검증
- 버튼: https://www.silson24.or.kr/claim/web/ (캡처 확인).
- 기관 동사: "청구".

## 3. 예외·단서
1. **골절진단비 금액·대상 범위(예: 5대 골절 등)는 특약마다 달라 공시에 없음 → 금액·범위 단정 금지.** 검색어에 "5대골절진단비"가 있으나 근거 없음.
2. **목발·보조기 구입비는 면책** — 골절 치료에서 자주 발생하는 비용이라 반드시 짚는다.
3. 자동차보험·산재에서 보상받는 의료비는 면책(명시) — 사고 원인에 따라 갈릴 수 있음.
4. 정액형이 "중복 지급"이라는 것은 **계약이 여러 개일 때** 각각 지급된다는 뜻. 실손과 정액형이 서로 다른 돈이라는 점과 구분해 서술.

## 4. 기존 글 정합
- 실손 클러스터의 "실비보험 여러 개 가입하면 중복으로 보상받나요?"는 **실손끼리의 중복(비례 보상)** 축. 이 글은 **실손 vs 정액형 진단비** 축이라 겹치지 않음. 본문에서 실손끼리 중복은 깊이 다루지 않는다.
