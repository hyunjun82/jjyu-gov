## 0-B. 원문 확인

Playwright로 HUG 상품개요를 열어 보증신청기한·대상주택·보증한도·보증조건·등기부 확인사항·보증료율·할인/할증을 텍스트로 뽑고, **보증료율 표는 요소 캡처를 떠서 24행 전부를 눈으로 대조**했다. 텍스트 추출값과 캡처가 전 행 일치했다. HF는 일반전세지킴보증 페이지에서 주택가격 상한·보증한도·선순위채권 제한·보증료율·채권보전조치·취급금융기관을 확인했다.

### 보증료율 (캡처 대조 완료, 연 %)

| 보증금액 | 아파트 70%↓ / 80%↓ / 80%초과 | 기타 70%↓ / 80%↓ / 80%초과 |
|---|---|---|
| 1억원 이하 | 0.097 / 0.117 / 0.137 | 0.111 / 0.142 / 0.172 |
| 1억 초과~2억 이하 | 0.102 / 0.124 / 0.146 | 0.117 / 0.151 / 0.184 |
| 2억 초과~5억 이하 | 0.107 / 0.131 / 0.154 | 0.124 / 0.161 / 0.197 |
| 5억원 초과 | 0.113 / 0.138 / 0.164 | 0.132 / 0.172 / 0.211 |

- 보증료 = 보증금액 × 보증료율 × 전세계약기간/365
- 부채비율 = (선순위채권금액 + 전세보증금) / 주택가액, 주택가액 = 주택가격 × 90%
- 단독·다중·다가구로 타전세계약확인서 미제출 시 해당 구간 최고요율 적용

| 종류 | 대상 | 할인율 |
|---|---|---|

## 3. 계산 정합성 검산 (본문 수치)

전세금 **2억원 아파트, 부채비율/LTV 70% 이하, 2년 계약** 기준

- HUG: 2억은 "1억 초과 ~ 2억 이하" 구간 · 아파트 · 70% 이하 → **연 0.102%**
  200,000,000 × 0.00102 = **204,000원/년** → 2년 408,000원
- HF: LTV 70% 이하 → **연 0.04%**
  200,000,000 × 0.0004 = **80,000원/년** → 2년 160,000원
- 차이: 204,000 − 80,000 = **124,000원/년**, 2년이면 **248,000원**
- 배수: 204,000 ÷ 80,000 = **2.55배** → 본문 "2.5배 넘게" 표현과 일치 (과장 없음)

최저~최고 배수 검산: HUG 최고 0.211% ÷ HF 최저 0.04% = 5.3배. 본문에는 같은 조건 비교값(2.5배)만 썼다.
