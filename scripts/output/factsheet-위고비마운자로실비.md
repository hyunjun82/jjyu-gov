## 3. 예외·단서 조항 (긍정문 뒤집는 "다만" 전수)

- 협회 FAQ 질문10 단서: 영양제·비타민제는 원칙 미보장이나 **"다만, 상해 또는 질병 치료의 목적으로 식약처 허가에 따른 약제 효능(효과)에 따른 치료에 한해 보장"** ← 이 글의 판단 축
- 협회 FAQ 질문2 말미: **"위의 내용은 일부 사항만을 나열한 것이며, 기본형/특별약관1/특별약관2 별로 보상하지 않는 손해가 상이"** → 세대·특약별로 결론이 달라질 수 있어 단정 금지
- 협회 예시는 "소비자의 이해를 돕기 위해 식약처 허가정보를 기초로 작성" — 개별 지급 여부는 보험사 심사
- 위고비 12세 이상 청소년: 12주 투여 후 BMI 5% 이상 감소 없으면 치료 중단·재평가
- 마운자로 2.5mg: "치료 시작을 위한 것이며 혈당 조절을 목적으로 하지 않는다"

## 4. 확인 못 해 쓰지 않는 것

- **KB 글이 근거로 든 "금융감독원 2025년 7월 기준"** — 금감원 보도자료에서 확인 실패 → 인용하지 않는다
- KB 글의 처방 건수 통계(위고비 누적 104만 건 등) — 출처 미표기 → 쓰지 않는다
- 위고비·마운자로의 급여/비급여 등재 여부 — 심평원 약제급여목록 미확인 → 단정하지 않고 "영수증의 급여·비급여 표기 확인" 안내로 처리
- 상병코드(E11, I10, R73 등) — 협회·식약처 원문에 없음 → 쓰지 않는다
- 실손 표준약관 별표15 원문 — law.go.kr이 hwp 다운로드만 제공하고 받은 파일이 다른 서식이었음 → 협회 공시 FAQ를 근거로 사용
