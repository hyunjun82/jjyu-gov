## 단서 (원문에 있고 글에 넣음)
- 운영 일정은 바뀔 수 있어 방문 전 전화 확인 (복지부 ↔ 이젠 화면 안내문) → Q1·Q2·Q4·FAQ
- 중증 증상(호흡곤란, 갑작스러운 팔다리 저림, 혀 마비로 말하기 어려움) → 곧바로 119 → Q3
- 응급똑똑 앱: 증상 입력 → 응급실 방문 필요 여부 판단 도움 → Q3
- 시·도 재난안전문자·재난방송 자막 안내 예정 → Q4
- 이젠 검색 화면: 처음엔 병·의원 체크 상태, 약국은 따로 체크 → Q2
- 이젠 시도 목록 16개 (광주·전남 = 전남광주통합특별시) → 본문엔 개수 없이 "전국 시도"
- 달빛어린이병원 156곳·소아전문응급의료센터 14곳 "운영 상황 관리 계획" → FAQ (운영한다고 쓰지 않음)

## 쓰지 않는 것
- 경증 환자 응급실 이용 시 본인부담 — 이번 보도자료에 없음
- 편의점 안전상비의약품 13개 품목·서울 6,926곳 — 서울시 기사 한 곳, 전국 교차 확인 못 함 (본문엔 "서울시 안내"로 개수 없이)
- 시·도별 문 여는 곳 개수 — 복지부는 전국 합계만
- 응급똑똑 앱 설치처·화면 순서 — 앱 미확인
- 17개 권역외상센터·심뇌혈관센터 29곳·DMAT 45개소 — 원문엔 있으나 일반 독자 행동과 멀어 본문 생략 (틀려서 뺀 것 아님)
