**타이틀** 개인워크아웃 부결 사유와 부동의 확률, 거절당하면 어디서부터 하나?

## 1. 개념 구분 (이 글의 핵심 뼈대)

세 가지가 다른 단계에서 일어난다. 뭉뚱그려 "부결"이라 부르면 안 된다.

| 단계 | 용어 | 근거 | 재신청 제한 |
|---|---|---|---|
| 접수 단계 | **반려** | 협약 제7조③ — 배제사유(제4조⑤) 해당, 또는 요청 서류 미제출·허위제출 | 조문에 별도 기간 명시 없음 |
| 심의 단계 | **기각** | 협약 제4조⑤2호 — 제9조 심의·의결, 제10조 채권금융회사 동의 요건을 충족 못한 경우 | 기각된 날부터 1년 이상 경과. 단, 기각 사유를 해소한 자는 예외 |
| 채권자 동의 단계 | **부동의** | 협약 제10조 — 채권금융회사가 조정안에 동의하지 않는 것 | 부동의 자체는 재신청 제한 사유가 아니고, 과반수 미달 시 기각으로 이어짐 |

## 2. 수치·조항 표

| 항목 | 값 | 1차 출처 |
|---|---|---|
| 반려 사유 | 배제사유(협약 제4조⑤ 7가지) 해당 또는 요청 서류 미제출·허위제출 | 협약 제7조③ |
| 기각 사유 | 제9조 심의위원회 심의·의결 또는 제10조 채권금융회사 동의 요건 미충족 | 협약 제4조⑤2호 |
| 기각 후 재신청 제한 | 기각된 날부터 1년 이상 경과하지 않으면 재신청 불가. 단, 기각 사유를 해소한 자는 예외 | 협약 제4조⑤2호 단서 |
| 부동의 시 의무 | 채권금융회사가 동의하지 않는 경우 그 사유를 구체적으로 명기하여 회신해야 함 | 협약 제10조③ |
| 확정(동의) 요건 | 무담보채권 총액·담보채권 총액 중 각각 동의한 채권금융회사의 채권합계액이 과반수일 때 확정 | 협약 제10조④ |
| 무응답 처리 | 채권금융회사가 10일 이내 회신하지 않으면 동의한 것으로 간주 | 협약 제10조①⑤ |
| 신청 취하·기각·실효 시 보증인 | 보증인의 책임은 신청 전 채무 내용대로 환원 | 협약 제22조② |

## 3. 단서 조항 (본문 반영)

- **"부결"이라는 단일 개념이 없다** — 반려(서류·자격 단계) / 기각(심의·동의 요건 단계) / 부동의(개별 채권자 반대)가 각각 다른 조문에 근거한다. 사장님 소제목의 "부결"을 이 세 갈래로 풀어 답한다 → qa1·qa2
- 부동의 자체는 즉시 전체 무산이 아니다 — 무담보·담보 각각 과반수 동의만 얻으면 일부 채권자가 반대해도 확정된다(제10조④) → qa3
- 채권금융회사는 부동의 시 사유를 구체적으로 명기해 회신해야 한다는 의무 조항이 있다 — 이게 "거절당했을 때 확인할 첫 자료"가 된다 → qa4
- 기각은 사유를 해소하면 1년을 기다리지 않고 바로 재신청할 수 있다는 예외가 핵심 → qa4

## 4. 확보하지 못한 것 (본문에 쓰지 않음)

- **부결률·기각률·부동의 확률의 실제 수치**: 신용회복위원회는 심의·동의 관련 통계를 공개하지 않는다. "확률은 어느 정도인가요"라는 소제목에 숫자로 답하지 않고, 확정 요건(과반수)과 무응답 간주 규정으로 구조를 설명하는 방식으로 대체한다
- 기각 사유를 "해소했다"고 인정받는 구체 기준: 협약에 사례나 기준이 없음
- 반려 후 재신청 제한 기간: 협약 제7조에 별도 기간이 없어(기각과 다름) 단정하지 않는다
