SNS공유
울산광역시  ‘120울산민원센터’는 일반민원, 시정소식, 교통정보, 관광안내 등 시정관련 사항에 대해 전화상담, 문자 상담을 통해 시민의 입장에서 신속·정확·친절하게 안내하고 시민과 소통하여 더 나은 울산광역시를 만들기 위한 공간입니다.
이용시간

평일 09:00 ~ 20:00(토·일요일, 공휴일은 운영하지 않습니다) 

이용번호 : 052-120(전화·문자상담)

시민의 접근성을 높이기 위한 홈페이지 민원게시판 간소화 추진으로 온라인 상담 게시판이 [울산시에 바란다]로 통합되어 운영됩니다.

상담내용
민원일반 : 일반행정, 여권발급, 민원안내 등
문화관광 : 축제행사 일정 및 관광 안내
교통분야 : 버스노선, 교통정보, 대중교통 분실물 등
환경분야 : 노후경유차 조기폐차, 운행경유차 배출가스 저감사업 등
상수도 : 요금조회, 납부방법, 상수도 일반 문의 등
차량등록 : 등록 구비서류, 제증명 발급 방법 등
기타 : 생활정보, 생활민원, 주요기관 전화번호, 포털사이트 검색 등

전화·구술 민원은 단순·질의·상담 사항으로 상담원의 답변은 법률적 효력이나 구속력을 가지지 않습니다. 법률적 효력이나 구속력을 가지는 행정기관의 답변을 원하시는 경우 '울산시에 바란다' 등을 통해 민원을 접수하여 주시기 바랍니다.

function comma(num){
 var len, point, str; 
 num = num + ""; 
 point = num.length % 3 ;
 len = num.length; 
 str = num.substring(0, point); 
 while (point < len) { 
 if (str != "") str += ","; 
 str += num.substring(point, point + 3); 
 point += 3; 
 } 
 return str;
}
