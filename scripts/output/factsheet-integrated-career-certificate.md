# 팩트시트 — 통합경력증명서 (integrated-career-certificate)

## 0. 관할 확정

| 항목 | 내용 |
|---|---|
| 소관 | 고용노동부 (증명서 명의: 고용노동부 장관) |
| 서비스 | 고용24 통합경력증명 서비스 (2026.08.13 오픈) |
| 1차 출처 | 대한민국 정책브리핑 카드뉴스 2026.08.13, 고용노동부 |
| 확인 시스템 | 고용24(work24.go.kr) 통합경력증명 메뉴 — 발급·관리 / 진위확인 |

⚠ 회사가 발급하는 경력증명서(별지 제7호서식)와 **다른 문서**다. 통합경력증명서는 공공 기록 기반이고
명의는 고용노동부 장관이다. 제출처가 회사 양식을 요구하면 그건 따로 받아야 한다 — 대체 가능하다고 단정하지 않는다.

## 0-B. 원문 캡처 확인 (browser_take_screenshot)

- 캡처 파일: 대한민국 정책브리핑 카드뉴스 전체 페이지, 고용24 통합경력증명 진위확인 화면, 발급 메뉴 로그인 알림
- 캡처에서 확인한 것: 카드뉴스 본문이 「도입 전 / 도입 후」 대비 구조로 세 덩어리(발급 번거로움, 이력서 반복 입력, 인사담당자 확인)로 짜여 있다. 각 덩어리마다 도입 전 항목이 점으로 나열되고 도입 후가 화살표로 이어지는 형태라, 표로 옮기면 그대로 대조표가 된다. 숫자로 명시된 것은 "경력정보 증명(24종)" 하나뿐이고 수수료·처리시간·발급 가능 기간은 카드뉴스에 없다 — 그래서 본문에도 쓰지 않는다. 고용24 진위확인 화면에서는 증명서 명칭 선택 목록에 통합경력증명서·이력확인원·직무능력인정서·국민내일배움카드 발급확인서·직업훈련이력 확인원 등이 들어 있는 것을 눈으로 확인했고, 입력 항목이 성명·발급번호·발급일자 세 개라는 것도 화면에서 봤다. 발급·관리 메뉴를 누르면 "이 메뉴는 인증서(공동/금융/간편인증)로 로그인 하셔야 합니다" 알림이 떠서 로그인이 필요하다는 사실을 직접 확인했다.
- 버튼 목적지 캡처: 발급 페이지(인증서 로그인 필요), 진위확인 페이지(비로그인), 경력증명서 서식 자료실(비로그인).

## 2. 단서 조항

- 증명서 명의가 고용노동부 장관이다 — **회사 명의 경력증명서와 다른 문서**다.
- 발급 메뉴는 인증서 로그인이 걸린다. 진위확인과 서식 자료실은 로그인 없이 열린다.
- 진위확인은 발급번호와 발급일자를 알아야 한다 — 증명서를 받은 쪽만 조회할 수 있다.
