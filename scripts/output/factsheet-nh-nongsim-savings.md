# 팩트시트 — NH농심천심적금 (nh-nongsim-savings)

## 0. 관할 확정

| 항목 | 내용 |
|---|---|
| 주체 | NH농협은행 (은행 자체 상품, 정부 지원사업 아님) |
| 근거 문서 | NH농협은행 홍보센터 NH뉴스 보도자료 2026.08.11 |
| 동명 규칙 여부 | 없음 — 은행 상품명이라 소관부처 충돌 없음 |
| 비교 공시 | 금융감독원 금융상품통합비교공시(금융상품한눈에) 적금 |

⚠ 정부 제도가 아니므로 법령 조문이 아니라 **은행 보도자료**가 1차 출처다.
금리는 은행이 바꿀 수 있으므로 본문에 **기준일('26.8.11.)** 을 반드시 함께 적는다.

## 2. 단서 조항 (다만/제외)

- 우대금리는 **조건 충족 시**에만 적용. 미충족 시 기본금리(2.30%).
- 조건별 개별 금리폭은 **보도자료에 미공개** → 본문에서 단정하지 않고 "영업점·상품설명서 확인" 안내.
- 판매 종료일 **없음**. 좌수(1만좌) 소진으로 종료 → 날짜를 지어내지 않는다.

## 0-B. 원문 캡처 확인 (browser_take_screenshot)

- 캡처 파일: NH농협은행 홍보센터 NH뉴스 보도자료 2026.08.11 전체 페이지 캡처
- 캡처에서 확인한 것: 보도자료 본문에 표가 하나도 없고 □ 문단 일곱 개로 이어지는 서술형이다. 예금 문단과 적금 문단이 따로 떨어져 있어 100만원·3천억원(예금)과 30만원·1만좌(적금)를 섞어 읽기 쉬운 구조라, 본문에서는 예금·적금 대조표를 따로 만들었다. 우대조건 문장은 "NH농협카드로 NH싱씽몰에서 결제"로 적혀 있는데 실제 몰 이름은 NH싱싱몰(농협몰, nonghyupmall.com)이라 오타로 판정하고 각주에 원문 표기를 남겼다. 이벤트 문단(200명 추첨, 2만원 상당 지역 특산품)은 "우대금리 혜택과 별도로"라는 단서가 문장 가운데 묻혀 있어 우대조건과 한 덩어리로 읽히기 쉽다 — 본문에서 박스로 분리했다. 금리 표기 옆의 ('26.8.11. 기준) 단서도 화면에서 괄호로만 붙어 있어 놓치기 쉬워 본문 표에 기준일을 함께 넣었다.
- 버튼 목적지 캡처: NH농협 영업점 안내, 금융감독원 금융상품한눈에 적금, NH올원뱅크 스토어 세 곳 모두 로그인 없이 열리는 것을 화면으로 확인했다. 인터넷뱅킹(banking.nonghyup.com)은 메뉴가 전부 javascript: 라 딥링크가 불가능해 제외했다.
