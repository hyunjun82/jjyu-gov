# 팩트시트 — 당뇨 실비 청구 (서류·진단비·1형2형)

> 2026-08-10. 타이틀: "당뇨 실비 청구 서류부터 진단비까지, 1형 2형 뭐가 다를까?"

## 0. 관할 확정

- 기관 2곳 이상인가?: 아니오. 실손 보상 기준은 금감원 표준약관(별표15) 단일 원천, 청구 창구는 실손24(보험개발원), 소비자 안내는 손해보험협회 공시실.
- 기관별 법령 상이?: 아니오.
- 이 글이 다루는 기관: 금융감독원 / 손해보험협회(공시) / 보험개발원(실손24) / 질병관리청(질환 정의)
- 법령: 보험업감독업무시행세칙 제5-13조제1항 [별표15] 표준약관

⚠ **세대 주의**: 손보협회 FAQ 상단 고지 — "실손의료보험 FAQ는 **'26.5월 실손의료보험 개편 이후 판매되는 5세대** 실손의료보험 상품에 대한 참고자료". 즉 2026년 5월부터 5세대가 판매 중. 본문에서 세대별 단정은 피하고, 세대 비교는 기존 허브(실비보험 2·3·5세대)로 링크.

- **캡처에서 확인한 것 (표 구조·단서 위치)**: 표준약관 면책 목록은 보장종목(급여/비급여)별로 **같은 목록이 두 번** 실리는 2열 표 구조이고, 질병 면책 목록에 열거된 코드는 정신·행동장애(F04~F99), 여성생식기 비염증성 장애(N96~N98), 임신·출산(O00~O99), 선천성 뇌질환(Q00~Q04), **비만(E66)**, 요실금(N39.3·N39.4·R32), 항문질환(K60~K62·K64)이다. **당뇨병 코드(E10~E14)는 급여 면책 목록에도 비급여 면책 목록에도 없다** — 화면으로 목록 전체를 봐야 "없음"을 확정할 수 있고, 텍스트 일부만 긁으면 판정이 불가능하다. 바로 옆에 **비만 E66이 면책으로 있는 게 이 글의 핵심 갈림길**: 같은 약이라도 당뇨 치료면 보상, 체중 감량 목적이면 E66 면책에 걸린다. 손보협회 비교표는 "구분 / 실손의료보험 / 정액형 건강보험" 3열 × 4행(보험의 목적·보상 요건·지급 보험금·다수보험 계약)이며, 마지막 행에 실손만 "회사 별 비례 보상" 단서가 붙는다.

## 1-B. 교차출처

- 당뇨 면책 여부: 표준약관 급여면(p209) + 비급여면(p260) 두 면 모두에서 부재 확인 (동일 문서 2개 면) + 손보협회 비교표의 보상요건("요양급여로 발생한 본인부담금 및 비급여 의료비")과 정합.
- 1형/2형: 질병관리청 + KB 경쟁글 서술 방향 일치(수치 인용 아님).

- 버튼 목적지: https://www.silson24.or.kr/claim/web/ — 열어서 캡처 확인(2026-08-10). 세션 토큰 없는 고정 URL.

## 3. 예외·단서 (다만/제외)

1. **비만(E66) 면책** — 당뇨약을 체중 감량 목적으로 처방받으면 이 조항. 당뇨 치료 목적이어야 보상. (GLP-1 상세는 기존 스포크 "위고비 마운자로 실비 청구되나?"가 다룸 → 내부 링크)
2. 실손 다수보험 — 비례 보상이라 두 개 들어도 실제 부담액 초과 지급 없음. 반면 정액형 진단비는 중복과 무관하게 각각 지급.
3. 5세대(2026.5 개편) 상품은 별도 약관 — 세대별 단정 금지.

## 4. 기존 글 정합

- 기존 스포크 "위고비 마운자로 실비 청구되나? 당뇨 고혈압이면 달라지는 기준" — GLP-1 축. 이 글은 **당뇨 진료 자체(서류·진단비·1형2형)** 축이라 겹치지 않음. GLP-1 질문은 그 글로 보냄.
- 기존 허브 "실비보험 2세대 3세대 5세대" — 세대 비교는 그쪽 담당.
