# 팩트시트 — 과세유흥장소 개별소비세 신고하는 법 (entertainment-venue-return)

작성 2026-09-21. 타이틀: 사장님 지정. **소제목 4개: 사장님 미지정 — 초안**

## 관할
개별소비세법 [시행 2026. 4. 24.]·시행령 [시행 2026. 9. 18.] — 재정경제부(환경에너지세제과). 신고처: 과세유흥장소 관할 세무서장.

## 수치·기한
| 항목 | 값 | 출처 |
|---|---|---|
| 세율 | 유흥음식요금의 100분의 10 | 법 제1조 제4항 (제7항 탄력세율 대상 아님) |
| 주기·기한 | 매월, 다음 달 25일 | 법 제9조 제5항 ↔ 세무일정 |
| 납부 | 신고서 제출 기한까지, 매월분 | 법 제10조 제1항 |
| 2026년 8월분 | 9월 28일 | 세무일정 9월 탭 |
| 2026년 9월분 | 10월 26일(월) — 25일 일요일 | 세무일정 10월 탭 ↔ 요일 계산 |
| 휴업 | 1개월 이상이면 휴업 개시 전 신고서 | 시행령 제35조 제3항 |
| 폐업 | 폐업한 달 다음 달 25일, 신고서에 폐업연월일·사유 기재 시 폐업신고 갈음 | 법 제9조 제7항, 시행령 제35조 제4항 |
| 담보 | 요구한 날부터 30일 이내 제공 통지 | 법 제10조 제5항, 시행령 제17조 제1항 |

## 단서
- "유사한 장소"에서 유흥종사자 없고 춤추는 공간 없으면 제외 (시행령 제2조 제3항)
- 봉사료: 구분 기재 + 종업원 지급 확인 시 제외, 경영자 수입 계상 시 포함 (시행령 제2조 제1항 제8호)
- 무허가 영업도 과세 (법 제1조 제11항)
- 개업신고: 영업개시 전, 허가증 사본 첨부(부가세법 제8조 등록자는 제외) (시행령 제35조 제1·2항)
- 외국군인 면세: 외국환 매입증명서 첨부 (시행령 제33조의3)
- 장부 3가지 (시행령 제36조 제3항)

## 쓰지 않는 것
- 신고서 서식 명칭·번호 — 시행규칙 미수집
- 무실적 달 신고 의무 — 조문 직접 확인 못 함
- 가산세 — 수집 범위 밖
