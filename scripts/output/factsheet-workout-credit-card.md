## 2. 단서 조항 (본문 반영)

- **"카드가 자동으로 정지된다"는 신복위 공식 문구가 없다** — 있는 건 카드대금 자동이체가 "자동 해지되지 않는다"는 정반대 방향의 안내뿐. 카드 자체의 지속 이용 여부는 카드사 심사 소관이라는 11번 편의 논리를 그대로 연결 → qa1·qa2
- 소액신용카드는 하나카드와 국민카드의 이행 기간 기준이 다르다(12개월 vs 24개월) → qa4에서 혼동 없이 나란히 비교
- 체크카드는 "후불교통체크카드"(신용거래 불가)와 "소액신용체크카드"(신용거래 가능)로 종류가 나뉜다는 것 자체가 사장님 소제목3의 답 → qa3
- 발급 제한 대상자 목록 중 "KCB·NICE 연체정보 등록"은 신규 소액카드 신청 자격 기준이지, 기존에 쓰던 일반 카드의 유지 여부를 직접 규정하는 건 아니다 — 혼동하지 않도록 구분해서 인용

## 3. 확보하지 못한 것 (본문에 쓰지 않음)

- **개인워크아웃 확정 시 기존 카드가 실제로 정지·해지되는지**: 공식 안내에 명시 없음(카드사 개별 정책)
- 체크카드(일반, 위원회 지원 상품이 아닌 것) 자체의 유지 여부: 공식 안내 없음
- 소액신용카드 발급 승인율·거절율: 공식 통계 없음
