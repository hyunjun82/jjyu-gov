# 팩트시트 — 치아보험 허브 타이틀 정정 (2026-08-12)

## 0. 이 팩트시트의 범위 (먼저 명시)

이번 변경은 **타이틀 종결 정정 1건**이다. 본문 수치·출처는 건드리지 않았다.

- before: 치아보험 가입 전 꼭 알아야 할 5가지, 발치 개수부터 확인하세요
- after: 치아보험 임플란트 보장한도 얼마까지 나오나, 발치 개수 모르면 손해

사유: "확인하세요" 존댓말 종결 금지(사장님 지시 2026-08-12) + 타이틀 공식
[메인키워드 + 세부키워드(얼마) + 후킹(모르면 손해)] 적용.
타이틀에 넣은 "얼마까지 나오나"를 받도록 qa[1] 소제목도 같은 문구로 맞췄다.

**새 수치를 인용하지 않았다.** 타이틀이 주장하는 사실은 하나 — "보장한도가 발치한 치아 개수 기준"이며
이 문장은 아래 0-B에서 원문 캡처로 재확인했다. 본문 전체 수치의 전수 검증은 글별 팩트시트 백로그.

## 0-A. 관할 확정

| 구분 | 소관 | 근거 |
|---|---|---|
| 실손·치아보험 보장 기준 안내 | **금융감독원** | fss.or.kr 보도자료 (nttId=195182) |
| 상품별 보장한도·면책 | 각 보험사 약관 | 상품마다 다름 — 본문에서 단정하지 않음 |

동명 규칙 확인: 치아보험 보장한도는 법령이 정하는 값이 아니라 **상품 약관** 소관이다.
금감원 보도자료는 "발치한 치아 개수 기준"이라는 산정 방식을 안내하는 문서이고,
연간 보장 개수 자체는 상품별로 달라 본문도 특정 숫자로 단정하지 않는다.

## 0-B. 원문 캡처 확인 (절대규칙 7-A)

- 각 1차 출처를 Playwright로 열고 **화면을 캡처해 눈으로 확인했는가**: 예
- 캡처에서 확인한 것(표 구조·단서 위치 등):
  - **금융감독원 보도자료 nttId=195182 전체 페이지 캡처**(2026-08-12).
    "보철치료(브릿지, 임플란트)의 연간 보장한도는 발치한 치아의 개수 기준이며, 치료한 치아 개수가 아니다"가
    본문 서술로 들어가 있다. 표가 아니라 문장 형태라서 구간·단서가 뭉개질 여지가 없는 구조임을 확인했다.
  - 이 문장이 타이틀의 "발치 개수 모르면 손해"와 "임플란트 보장한도 얼마까지 나오나"를
    동시에 지탱한다. 즉 타이틀이 새 사실을 만들지 않았다.
- 텍스트 추출만으로 판단한 항목이 있는가: 없음. 캡처를 보고 판단했다.

## 2. 단서 조항 확인 ("다만 / 제외")

- 금감원 자료는 "발치한 치아 개수 기준"을 원칙으로 두고, 사랑니·교정 목적 발치는
  원칙적으로 지급되지 않을 수 있다는 단서를 별도로 둔다. 본문 qa 에 이미 반영돼 있다.
- 연간 보장 개수 상한은 **상품별**이라 본문이 특정 숫자로 단정하지 않는다. 이 방침을 유지한다.

## 3. 경쟁글과 어긋나는 지점

- "치료 횟수만큼 받는다"는 서술이 커뮤니티에 돌아다닌다 → 금감원 원문이 "치료한 치아 개수가 아니다"로
  명시. **원문이 맞다.** 본문은 원문 표현을 그대로 인용하고 있다.

## 4. 쓰지 않는 것
