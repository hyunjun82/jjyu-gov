# 팩트시트 — 의료급여 의뢰서 (medical-aid-referral)

## 0. 관할

| 항목 | 내용 |
|---|---|
| 소관 | 보건복지부 |
| 근거 | 의료급여법 시행규칙 제3조 [최근개정 2026.7.10] |
| 기관 단계 | 의료급여법 제9조제2항 (1차·2차·3차) |

## 0-B. 원문 캡처 확인

- 화면 캡처: `medicaid-rule.png` (국가법령정보센터 의료급여법 시행규칙 화면) — 2026-08-15 저장.
- 캡처에서 확인한 것: 제3조제1항 본문은 "수급권자가 의료급여를 받으려는 경우에는 … **제1차의료급여기관에 의료급여를 신청해야 한다**"이고, 단서에서 **제1호부터 제8호까지는 제2차 또는 제3차 기관에**, **제9호부터 제14호까지는 제2차 기관에** 바로 신청할 수 있게 한다. 조문 끝 개정 이력의 마지막이 **2026년 7월 10일**이다. 제1호부터 제8호는 응급환자, 분만, 결핵·희귀난치성·중증질환자, 2·3차 기관 근무 수급권자, 등록장애인의 보조기기 지급, 등록장애인의 장애인구강진료센터 이용, 감염병 확산 등 긴급 사유, 국가건강검진 후 결핵 확진검사다. 제9호부터 제14호는 재활치료가 필요한 사람의 재활의학과 진료, 한센병환자, 등록장애인, 「국민건강보험법 시행령」 제45조제1호 지역의 수급권자, 국가유공자·보훈보상대상자 상이등급자, **15세 이하의 아동**이다. 제2항은 노숙인 등인 수급권자는 **노숙인진료시설인 1차 또는 2차 기관에 신청**해야 하고 응급환자·분만은 예외라고 한다. 제3항은 신청을 받은 기관이 다른 기관 진료가 필요하다고 판단하면 **진료담당의사의 진료의견을 적은 별지 제3호서식 의료급여의뢰서를 수급권자 또는 보호자에게 발급**해야 하며, 1차 기관이 받은 경우 2차 기관에 의뢰한다고 정한다.

## 2. 단서

- 노숙인 등도 **응급환자이거나 분만하는 경우**에는 노숙인진료시설이 아닌 1·2·3차 기관에 신청할 수 있다.
- 등록장애인은 제11호로 2차 기관 직접 신청이 되지만, 장애인구강진료센터 이용은 제6호로 2·3차까지 열린다.

## 3. 확보 못 한 것 (본문에 쓰지 않음)

| 항목 | 사유 |
|---|---|
| 의뢰서 없이 진료받은 경우의 비용 처리 | 제3조에 없음, 별도 확인 필요 |
| 제14호가 언제 신설됐는지 | 개정 이력만 확인, 신설 시점 특정 못 함 |
| 의뢰서 유효기간 | 선택의료급여기관 외의 일반 절차는 확인 못 함 |
| 제3차 기관 지정 요건 | 제17조 소관, 이번에 안 봄 |

## 5. 오해 소지

1. "무조건 의원부터 가야 한다" → 14가지 예외가 있다
2. "응급실도 의뢰서가 필요하다" → 응급환자는 제1호로 바로 갈 수 있다
3. "아이도 의원부터" → 15세 이하 아동은 2차 기관에 바로 신청할 수 있다
