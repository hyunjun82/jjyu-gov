통신자료 제공내역 열람 신청은 어떻게 해야 하나요?

#통신자료제공사실확인
#통신자료제공내역열람

﻿[통신자료 제공내역 열람  또는 통신자료 제공사실 확인서 요청 안내]
﻿

통신 이용자는 '개인정보 보호법' 제35조 제1항에 따라 전기통신사업자에게 통신자료 제공내역 열람을 요청할 수 있습니다. 
- 요청일로부터 1년 이내의 통신자료 제공내역을 열람 가능하며(전기통신사업법 시행령 제53조 제1항), 
- 법원, 검사 또는 수사관서의 장(군 수사기관의 장, 국세청장 및 지방구세청장 포함), 정보수사기관의 장이 재판 수사, 형의 집행 또는 국가안전보장에 대한 위해를 방지하기 위한 목적으로 전기통신사업자에게 문서를 요청한 경우에 대한 제공일자, 요청기관, 요청사유, 제공 내역 등(전기통신사업법 제83조 제5항)을 확인하실 수 있습니다.

수사기관 등에 제공되는 통신 자료는 가입자 인적 사항(예: 성명, 주민등록번호, 주소, 전화번호, 아이디, 가입/해지일 등)으로,
가입자의 통화 내역이나 내용 등이 제공되는 것은 아닌 점 참고하여 주십시오.

통신자료 제공내역 열람은 현재 가입 중인 당사자 본인 회선에 대해서만 확인이 가능하며,
전화 상품의 경우 가입자명, 성별, 생년월일, 사용 중인 전화번호가 일치하는 제공내역 확인이 가능합니다.

통신자료 제공사실 확인은 고객센터를 통해 신청하실 수 있습니다.
- 고객센터 유선 상담 또는 채팅 상담을 통해서 문의해주시면 신청 서류 등을 안내해드리며
- 자필로 작성한 신청 서류를 이메일로 보내주시면
- 신청일로부터 1년 이내의 통신자료 제공내역 정보를 10일 이내에 신청해주신 고객님의 이메일로 발송해드립니다.

통신자료 제공내역 열람은 본인인증 및 동의 절차를 필요로 하기 때문에 아래의 고객센터 운영시간과 채널을 참조하여 신청 부탁 드립니다.
- 핀다이렉트 고객센터 운영시간: 평일 오전 9시 ~ 오후 6시 (점심시간 오후 1시 ~ 2시). 주말 및 공휴일 제외.
- 핀다이렉트앱/웹 "채팅상담" 으로 빠르게 문의 가능하시며, 전화상담은 114(가입자무료) 또는 1668-5730(유료)로 가능합니다.

해지는 어떻게 하나요?

#해지문의
#해지신청
#해지방법

﻿해지하는 방법을 알려 드릴게요!

통신상품(요금제) 해지는
고객센터에서 [채팅상담]을 통해 도와 드려요.

해지 시에는 본인 여부 확인을 위한 본인인증이 필요하며, 해당 과정과
해지 안내사항은 고객센터를 통해 안내받을 수 있어요.

참고로 핀다이렉트에서 개통하신 번호를 사용하시다가 다른 통신사로 "번호이동"을 하시는 경우에는 시스템적으로 자동 해지되니 별도 해지하실 필요 없어요.

 

 

고객센터 채팅상담은 어떻게 하나요?

방법 1

 
 

핀다이렉트 홈페이지 혹은 핀다이렉트 앱 오른쪽 아래에 위치한 먼지 이모티콘을 클릭하면 채팅상담이 시작됩니다.

방법 2

카카오톡 채널 “핀다이렉트” 채팅창에서
고객센터를 선택해 나오는 메뉴에서 4번째 메뉴 상담사 연결 을 선택하면 채팅상담이 시작됩니다.

⏰  상담 가능 시간

▪️평일 오전 9시 ~ 오후 6시

▪️점심시간: 오후 1시 ~ 2시

※ 주말 및 공휴일 휴무

 

 

해지할 때 주의해야 할 것이 있나요?

▪️타 통신사로 번호이동할 경우 핀다이렉트 회선은 자동으로 해지되기 때문에 별도 해지 요청하실 필요 없습니다.

▪️해지 신청은 본인에 한하여 가능합니다.

▪️해지 취소는 해지를 진행한 당일에만 복구 가능합니다.

▪️해지 취소 가능 기한이 경과한 경우 해지된 번호는 다할 경우 사용하거나 복구할 수 없습니다.

▪️다른 회사로 이동하신 후 이동하신 회사의 통화품질에 불만이 있으신 경우 14일
이내에 다할 경우 핀다이렉트 서비스를 이용하실 수 있습니다.

▪️다음 달에 최종 요금을 정산하여 수신자부담 등 현재 시점으로 확인이 불가능한 요금 등으로 인해 차액이 발생하면
추가 청구되거나 자동 납부됩니다.

▪️최종 정산 요금을 해지와 동시에 납부하지 않고 후 청구 신청하시는 경우 신규 서비스 가입 등이 제한될 수 있습니다.

▪️해지 전까지 사용한 요금은 일할 계산되어 익월에 청구됩니다.

▪️해지 전 5~10분 이내 사용요금,
수신자부담 및 국제전화요금 등은 해지 후 별도 청구될 수 있습니다.

▪️월 중 해지할 경우 사용량 일할 계산되어 과금 될 수 있습니다.

[eSIM][재발급] eSIM 재발급을 하려면 어떻게 하나요?

#듀얼심
#eSIM재발급
# eSIM
# ESIM

eSIM 재발급이 필요한 경우에는 아래 두 가지 방법을 통해 휴대전화 정보(IMIE / IMEI2 / EID)를 확인하신 후 핀다이렉트 고객센터(채팅상담 또는 가입자 무료 114 / 유료 1668-5730)로 문의해 주세요.

✅ 키패드 이용 

- 기본 전화 앱 키패드에서 *#06# 입력

서드파티 통화 앱(예: 후후, 후스콜 등)에서는 이 기능이 정상적으로 동작하지 않을 수 있어요.

 ※ 에이닷 앱에서도 확인이 가능해요. 

- 안드로이드 : 15버전 이상만 가능

- 아이폰 : *#06# 입력 후 '통화' *#06# 클릭

✅ 휴대전화별 확인 경로

ο 아이폰 

- 설정 → 일반 → 정보에서 IMEI, IMEI2, EID 정보 모두 확인 가능

ο 갤럭시 

- 설정 → 휴대전화 정보에서 IMEI, IMEI(eSIM)으로 구분되어 확인 → 상태 정보에서 EID 확인

function comma(num){
 var len, point, str; 
 num = num + ""; 
 point = num.length % 3 ;
 len = num.length; 
 str = num.substring(0, point); 
 while (point < len) { 
 if (str != "") str += ","; 
 str += num.substring(point, point + 3); 
 point += 3; 
 } 
 return str;
}
