# 팩트시트 — 노령연금 세금·건강보험료 (2026-08-07)

## 0. 관할 확정

- 이 주제의 부여/집행 기관이 2곳 이상인가?: 예 (국세청=소득세, 건보공단=보험료)
- 기관별 적용 법령이 다른가?: 예 — 같은 연금소득인데 계산 기준이 다르다 (이 글의 핵심)
- 이 글이 다루는 기관: 국세청(소득세) / 국민건강보험공단(보험료)
- 그 기관에 적용되는 법령·규칙 정확한 이름과 번호: 「소득세법」 제20조의3·제47조의2 / 「국민건강보험법」 제71조, 같은 법 시행령 제41조

## 2. 행동 검증

- 버튼 목적지 URL을 Playwright로 열었는가: https://www.nps.or.kr 전자민원(연금소득 원천징수영수증) — 확인함
- 로그인/보안프로그램/인증서 등 진입 장벽: 본인 인증
- 누가 신청할 수 있는가 (대리 신청 가능 여부): 본인
- 기관이 실제로 쓰는 메뉴명·동사: 전자민원 / 증명서 발급

## 3. 예외·단서 조항 (긍정문 뒤집는 "다만" 전수)

- 소득세: 2002년 이전 납입분 기초 연금은 과세 제외 → 가입이 오래된 분일수록 과세 대상이 적다
- 건보료: 위 2002년 기준을 **적용하지 않는다**는 단서가 시행령에 명시 — 세금과 건보료가 갈리는 지점
- 지역가입자 연금소득 반영률(50%)은 이 조문에 없어 단정하지 않음 → 본문에서 수치로 쓰지 않는다

## 4. 기존 글 정합

- 같은 수치를 쓰는 기존 허브/스포크: 없음 (사이트 전체 미커버 확인)
- 겹치는 글과 이 글의 축 구분: 세금과 건보료의 계산 기준이 다르다는 것 자체가 축
