# 팩트시트 — 자동차 개별소비세 환급 신청하는 법 (passenger-car-ict-refund)

작성 2026-09-21. 타이틀: 사장님 지정. **소제목 4개: 사장님 미지정 — 초안**

## 관할
개별소비세법·시행령 — 재정경제부(환경에너지세제과). 환급 신청처: 해당 물품에 개별소비세를 부과한 관할 세무서장 또는 세관장.

## 수치·조건
| 항목 | 값 | 출처 |
|---|---|---|
| 장애인 한도 | 500만원 (특수장비 설치비용 제외 산출) | 법 제18조 제1항 단서 |
| 다자녀 한도 | 300만원 | 법 제18조 제1항 단서 |
| 다자녀 요건 | 18세 미만 자녀 3명 이상 양육 | 법 제18조 제1항 제3호 바목 |
| 장애인 1명당 | 1대 | 법 제18조 제1항 제3호 가목 ↔ 홈택스 안내문 |
| 장애인 범위 | 국가유공자 중 장애인 / 장애의 정도가 심한 장애인 / 5·18 부상자 / 고엽제 경도 이상 | 시행령 제31조 제1항 |
| 명의 | 본인 또는 세대 같은 가족 공동명의 | 시행령 제31조 제3항 ↔ 홈택스 안내문 |
| 교체 시 | 3개월 이내 종전 차 처분·신고 | 시행령 제31조 제3항 단서 |
| 환급 근거 | 면제 물품은 이미 낸 세액 환급 | 법 제20조 제2항 제2호 |
| 신청 기한 | 사유 발생일부터 6개월이 지난 날이 속하는 달의 말일 | 법 제20조 제4항 |
| 연명 | 납부자(제조자)와 연명 | 시행령 제34조 제3항 |
| 서류 | 신청서 + 사유 증명 + 납부 증명 / 승용차는 제19조의3 ① 서류 | 시행령 제34조 제1·4항 |
| 등록증 사본 | 반출한 달의 다음 달 20일까지 제조자에게 | 시행령 제19조의3 제2항 ↔ 홈택스 안내문 |
| 사후관리 | 5년 이내 양도·용도변경 시 신고·납부, 다자녀 예외 4가지 | 시행령 제33조 ↔ 홈택스 안내문 "5년 이상 보유" |
| 가산세 | 환급 안 됨 | 법 제20조 제5항 |

## 쓰지 않는 것
- 홈택스 "장애등급 1~3급" — 옛 기준(시행령과 불일치)
- 소비자 단독 온라인 환급 신청 화면 — 찾지 못함
- 30일 내 환급(시행령 제34조 제5항) — 제조자 신청 전제로 읽힘
- 교육세 면제액, 신청서 서식명 — 미수집
