## 0-B. 원문 확인

Playwright로 LH청약플러스 임대가이드의 8개 탭(통합공공임대·국민임대·행복주택·공공임대·영구임대·장기전세·매입임대·전세임대)을 하나씩 열어 텍스트를 뽑았고, 통합공공임대 소득·자산표는 전체화면 캡처로 눈으로 대조했다(텍스트 추출값과 캡처가 일치). SH는 「임대주택 공급」의 유형별 표에서 공급면적·임대의무기간을 확인했다.

**주의해서 구분한 것**: SH 표의 값은 "임대의무기간"으로 사업자가 그 주택을 임대주택으로 유지해야 하는 기간이다. LH 행복주택 탭의 "최대 거주기간"은 한 가구가 살 수 있는 기간이다. 두 숫자는 성격이 다르므로 한 표에 섞지 않았다. 본문 FAQ에 이 구분을 따로 적었다.

## 2. 계산 정합성 검산

- 3인 가구 기준 중위소득 100%는 5,359,036원, 도시근로자 월평균소득 100%는 8,168,429원.
  차이 = 8,168,429 − 5,359,036 = **2,809,393원**. 본문에 "280만원 넘게 벌어집니다"로 적었다(과장 없음).
- 통합공공임대 중위 150%는 100%의 1.5배와 일치하는지 확인 — 1인 2,564,238 × 1.5 = 3,846,357 ✅ 표 값과 동일.
  4인 6,494,738 × 1.5 = 9,742,107 ✅ 동일. 표가 자체 정합한다.
- 행복주택 자녀 있는 경우 14년 = 기본 10년 + 4년. 본문 "4년이 더 붙는다" 표현과 일치.

## 5. 원문 대조로 잡아낸 오류 3건

| 항목 | 항간·기존 표기 | LH 원문 |
|---|---|---|
| 행복주택 청년·대학생 거주기간 | 6년 | **10년** |
| 국민임대 임대료 | 60~70% (기존 글 public-rental-housing) | **60~80%** |
| 장기전세 공급기관 | "SH만의 고유 상품, LH 공고엔 없음" | **정의에 "한국토지주택공사" 명시 — LH도 공급** |

장기전세 정의 원문: "국가, 지방자치단체, 한국토지주택공사 또는 「지방공기업법」 제49조에 따라 주택 사업을 목적으로 설립된 지방공사가 임대할 목적으로 건설 또는 매입하는 주택으로서 20년의 범위에서 전세 계약의 방식으로 공급하는 임대주택"

## 6. 쓰지 않는 것 (사유)

| 항목 | 사유 |
|---|---|
| 영구임대·통합공공임대의 개인 최대 거주기간 | LH 임대가이드에 표기가 없다. 표에 "LH 안내에 표기 없음"으로 두고 지어내지 않았다 |
| 재계약 주기 2년 | 원문에서 확인하지 못했다 |
| SH 장기전세 소득·자산 수치 | SH 공급계획 페이지에 물량만 있고 자격 수치가 없다 |
| 영구임대 총자산 기준 | LH 영구임대 탭에 자산 항목 자체가 없다. 다른 유형 값(34,500만원)을 끌어다 쓰지 않았다 |
| 영구임대 총자산 2억 4,500만원 | 참고한 블로그 수치. LH 원문(통합·국민·행복 34,500만원)과 달라 확인 전까지 쓰지 않는다 |
| 전세임대 세부 조건 | 탭은 확인했으나 이번 글 범위 밖 |
