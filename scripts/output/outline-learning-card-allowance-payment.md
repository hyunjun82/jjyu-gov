# 구성표 — learning-card-allowance-payment

- 타이틀: 내일배움카드 훈련장려금 신청과 지급 조건, 지급일과 출석 연동
- 확정: 사장님이 14~26편 세트로 직접 확정 (2026-09-18, 세트 14번). 타이틀·소제목 4개 원문 그대로.
- 허브: /policy/learning-card

## 소제목 (사장님 확정, 변경 금지)

1. 훈련장려금은 따로 신청해야 하나요?
2. 장려금 지급 조건은 어떻게 되나요?
3. 언제쯤 입금되나요?
4. 출석률이 모자라면 못 받나요?

## 1번 소제목의 긴장 — 정직하게 다룬다

고용24 안내는 "별도의 신청 없이 본인이 등록한 계좌로 지급"이라 한다.
그런데 운영규정 제53조제2항은 "훈련기관과 훈련생은 HRD-Net을 통하여 마감일부터 3일 이내에
훈련비 및 훈련장려금 산정내역을 확인하고 관할 지방고용노동관서의 장에게 지급을 신청하여야
한다"고 적혀 있다. 둘을 모두 밝히고, 실무상 새로 서류를 내는 신청은 없지만 산정내역 확인
절차가 규정에 있으니 마감 후 3일 안에 확인하라고 안내한다. 어느 한쪽만 쓰면 오답이 된다.

## 근거

- 제2조제6호 — 단위기간 = 훈련개시일로부터 매 1개월
- 제49조제1항 — 단위기간 출석률 80% 이상 + 지급 대상 3부류
- 제49조제3항(캡처 law-49-3-allowance.png) — 단가와 월 한도
- 제49조제2항 — 훈련기관 귀책사유면 출석률 무관 지급
- 제49조제4항 — 원격·법정직무·외국어는 미지급
- 제50조(캡처 law-50-allowance-cut.png) — 미지급·감액 사유
- 제53조 — 마감·산정 시점, 확인·신청 3일, 지급 10일 이내, 훈련생에게 직접 지급
- 제54조 — 10원 미만 끝수 계산 안 함
- 고용24 제도안내·발급안내 — 별도 신청 없이 등록 계좌로 지급
