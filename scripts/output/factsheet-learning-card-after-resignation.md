# 팩트시트 — learning-card-after-resignation

- 관할: 고용노동부 / 1차 출처: 국민내일배움카드 운영규정 제4조·제6조·제7조·제8조·제49조
  https://www.law.go.kr/LSW/admRulInfoP.do?admRulSeq=2100000279150
- 교차 출처: 고용24 발급안내 / 고용노동부 고객상담센터(1350)
- 확인일: 2026-09-18

## 수치

| 항목 | 값 | 근거 |
|---|---|---|
| 지원제외 판단 기준일 | 신청일 | 제4조제5항 |
| 발급 여부 통지 | 접수일로부터 7일 이내 | 제7조제1항 |
| 제출 서류 | 4종, 지원대상 확인 서류는 생략 가능 | 제6조제1항 |
| 카드 통합 시점 | 2020년 1월 1일 (실업자·재직자 구분 폐지) | 1350 상담 답변 |

## 단서

- 운영규정 제4조제2항 지원제외 목록에 "퇴사자"나 "이직 예정자" 항목은 없다. 퇴사했다는 이유로 막히지 않는다.
- 상실신고 완료를 발급 요건으로 정한 조항도 없다. 지원제외 해당 여부는 신청일 기준으로 판단한다(제4조제5항).
- 재직자 제외 조항(제4조제2항제11호)은 대규모기업 만 45세 미만 월평균 임금 300만원 이상인 사람에게만 적용되고, 신청일 기준으로 판단하므로 이미 퇴사했다면 그 기준에서 벗어난다.
- 퇴직증명서를 요구하는 조항은 없다. 제6조제1항의 지원대상 확인 서류도 관서장이 확실하다고 인정하면 생략한다.
- 실업 상태에서 신청하려면 구직신청이 필요하다(고용24 발급안내). 재직 중일 때는 원칙적으로 불필요했던 절차가 퇴사 후에는 붙는다.
- 훈련장려금 기본 대상은 근로계약을 체결한 사람이 아닐 것을 요구하므로(제49조제1항제1호), 퇴사하면 장려금 요건에 가까워진다. 단 총 훈련시간 140시간 이상과 단위기간 출석률 80% 이상은 그대로다.
- 법정직무훈련과정과 외국어훈련과정은 수강신청일 기준 고용보험 피보험자만 신청할 수 있어(제8조제2항), 퇴사 후에는 이 두 유형을 신청할 수 없다.

## 오해 소지

- "재직자 카드에서 실업자 카드로 바꿔야 한다"는 절차는 없다. 2020년 1월 1일부터 하나로 통합됐다. 달라지는 것은 구직신청 필요 여부, 장려금 대상 여부, 외국어·법정직무 수강 자격이다.
- "상실신고가 끝나야 신청된다"는 요건도 규정에 없다.

## 쓰지 않는 것

- 고용보험 상실신고가 실제로 며칠 걸리는지 — 고용보험법·사업주 신고 영역이고 1차 출처로 확인하지 않았다.
- 퇴사 사유(자발적·비자발적)에 따른 차이 — 내일배움카드 운영규정은 퇴사 사유를 구분하지 않는다. 실업급여 쪽 논점이라 이 글에서 다루지 않는다.
