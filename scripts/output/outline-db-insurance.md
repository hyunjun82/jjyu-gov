## hero (서론)

급할 때 번호부터 찾게 되는데요. DB손해보험 대표번호는 1588-0100 하나로 통합돼 있습니다.
다만 그냥 걸면 ARS 안내가 길게 이어져서, 상담사 목소리를 들으려면 0번을 눌러야 합니다.
시간대도 갈립니다 — 월~금요일 09시 ~ 18시에는 상담사가 받고, 평일 야간 18시 ~ 09시과 공휴일 24시간에는 사고접수·긴급출동 위주로 돌아갑니다.
그럼 지금 바로 거시는 게 빠르겠죠.

**← 상단 버튼: 1588-0100 전화 걸기 → tel:15880100**

## 확정 사실 (공식 페이지 대조 완료)

| 항목 | 값 |
|---|---|
| 대표번호 | 1588-0100 (고객상담센터) |
| 상담 시간 | 월~금요일 09시 ~ 18시 |
| 야간 | 평일 야간 18시 ~ 09시 |
| 공휴일 | 공휴일 24시간 |
| 상담사 연결 | ARS 0번 (주간만) |
| 업무별 번호 | 13개 |
| ARS | 주간 9단계 / 야간 6단계 |
| 본사 | 서울특별시 강남구 테헤란로 432(대치동, DB금융센터) |

## 오해 소지 — 본문에서 반드시 풀 것

1. 주간 ARS 와 야간 ARS 는 다른 표다. 하나로 합치면 밤에 잘못 누른다.
2. 야간에 상담사 연결이 되는 것처럼 쓰지 않는다 — 접수만 된다.
3. 문자 전용 번호는 전화가 안 된다고 명시한다.
4. 번호는 추출본에 있는 것만 쓴다. 생성기가 대조해 막는다.

## 쓰지 않는 것 (검증 못 함)

- 평균 대기시간·통화시간 — 공식 발표 없음
- 상담 만족도 — 공식 발표 없음
- 지점별 영업시간 — 지점마다 달라 일괄 표기 불가
