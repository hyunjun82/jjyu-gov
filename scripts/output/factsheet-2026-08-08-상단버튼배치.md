# 팩트시트 — 2026-08-08 상단 버튼 신설 배치 (서론 추가분)

> 대상: 네이버 유입 상위 30개 중 상단 버튼(heroAct)이 없던 스포크 15개
> 작업 성격: **새 사실을 주장한 게 아니라, 그 글이 이미 검증해 실어둔 사실을 서론으로 다시 편 것.**

## 0. 관할 확정

- 이 배치의 성격: 기존 글에 **서론(heroHook) + 상단 버튼** 추가. 본문 수치·출처를 바꾸지 않았다.
- 기관별 적용 규칙이 다른가?: 해당 없음 — 각 글의 기존 소관 기관 그대로다.
- 버튼 목적지: 각 글이 속한 **허브의 applyUrl**(스포크 heroAct 는 href 없으면 허브로 간다).
  그 허브 applyUrl 은 모두 딥링크이며 `check-freshness` 죽은 CTA 검사를 통과한 상태다.

## 0-B. 원문 캡처 확인 (절대규칙 7-A)

- 각 1차 출처를 Playwright로 열고 화면을 캡처해 눈으로 확인했는가: 이 배치에서는 **새로 인용한 수치가 없다**.
- 캡처에서 확인한 것(표 구조·단서 위치 등): 서론에 들어간 숫자는 전부 그 글 본문에 이미 있던 값을 옮긴 것이다. 예로 기초연금 349,700원과 부부 1인당 279,760원은 오늘 복지부 「기초연금액 산정」 화면을 캡처로 확인해 `factsheet-기초연금계산.md` 에 기록한 값이고(기준연금액의 100% = 349,700원, ×0.8 = 279,760원), 같은 값을 서론에서 반복했다. 새 수치를 만들지 않았다.
- 텍스트 추출만으로 판단한 항목이 있는가: 없음(새 인용 없음).

## 2. 행동 검증 (버튼이 실제로 되는가)

- 스포크의 `heroAct` 는 `href` 가 없으면 **허브 페이지로** 간다(`SpokeClient.tsx` 262행).
  즉 이 배치의 버튼은 전부 **내부 이동**이며 외부 링크가 아니다. 죽은 CTA 위험이 없다.
- `href` 를 직접 넣은 것은 육아휴직 건강보험료(easylaw 보험료 경감·면제), 기후동행카드(티머니 통합회원),
  실업급여 입금일(고용24) 3건이며 모두 Playwright 로 열어 확인했다.
- 로그인/보안프로그램/인증서 등 진입 장벽: 내부 이동은 없음. easylaw 없음, 티머니·고용24는 로그인
- 누가 신청할 수 있는가 (대리 신청 가능 여부): 각 글의 기존 서술 그대로 — 이 배치에서 바꾸지 않았다
- 기관이 실제로 쓰는 메뉴명·동사: 버튼 문구는 정본 `docs/button-copy.md` 규칙대로 "내 ~ 확인하기" 형태로 통일

## 3. 예외·단서 조항

- **아동급식카드** — 중위소득 52%를 넘어도 지자체장이 결식 우려를 인정하면 지원 가능. 서론에 이 단서를 함께 적었다
- **학자금 거치기간** — 최장으로 잡는 게 늘 유리하지 않다(거치 중에도 이자 발생). 서론에서 이 점을 밝혔다
- **부모급여 어린이집 전환** — 못 받는 게 아니라 보육료로 전환되고 차액만 현금 지급. 신청하지 않으면 자동 전환되지 않는다
- **기초연금 40만원** — 인상안은 예산 미반영으로 시행되지 않았다. 서론에서 단정적으로 밝혔다

## 4. 기존 글 정합

- 서론에 쓴 값은 모두 해당 글 본문에 이미 있는 값이며, 본문 수치를 바꾸지 않았다
- 기초연금 349,700 / 279,760 은 `factsheet-기초연금계산.md` 와 동일 값
- ⚠ **백로그**: 이 15개 글 각각의 전체 수치 검증(글별 팩트시트)은 여전히 없다.
  이 문서는 "서론을 추가하며 새 사실을 만들지 않았다"는 기록이지, 원 글의 사실 검증을 대신하지 않는다.
