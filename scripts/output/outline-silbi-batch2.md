## 수집하며 알게 된 것

- **네이버 SERP 에는 연관검색어 블록이 없다.** 구글이 연관검색어 + PAA 를 둘 다 준다.
- **헤드리스 fetch 로는 못 긁는다.** HTTP 200 이 와도 두 블록이 비어 있다.
  브라우저 안에서 `fetch('/search?q=…', {credentials:'include'})` 로 돌려야 나온다.
- 어순을 뒤집으면 결과가 달라진다 — `실비 백내장` 0건 / `백내장 실비` 10건.
- `미용 실비` 는 **미용실(헤어숍)** 자동완성이 나온다. `미용 목적 실비` 로 써야 의도가 맞는다.
- 자동완성 0건이라 씨앗에서 뺀 말: `교통사고 실비` · `비중증 실비` · `성형 실비` · `임신 실비`
- 기존 스포크와 세부키워드가 겹쳐 뺀 축: 전환·해지·부활·미납·할증·정신과
  (`24세대전환판단` · `실효부활` · `납입중지` · `비급여할증` · `우울증공황장애실비`)

## 작성 전 할 일

1. 각 편 `scripts/output/source-{slug}.txt` 추출본 먼저 만든다 — 없으면 push 가 막힌다
   (2026-08-19 `check-source-match.ts` 를 스포크까지 보도록 넓혔다).
2. `act` 는 qa 인덱스 **2·4·마지막**에만 넣는다. 다른 자리에 넣으면 화면에 안 나온다.
3. 타이틀이 약속한 세부키워드마다 소제목 하나씩. 본문이 타이틀보다 넓어지면 타이틀을 넓힌다.
4. 소제목도 위 PAA 문장을 그대로 쓴다 — PAA 는 그 자체가 사람들이 친 질문이다.
