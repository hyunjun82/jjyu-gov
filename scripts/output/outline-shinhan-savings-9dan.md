## 오해 소지 — 본문에서 반드시 풀 것

1. **9%는 기본이 아니다** — 기본 3.0%, 우대 최고 6.0%p. 조건 미충족이면 3%.
2. **5%p + 2%p = 7%p인데 최고는 6%p** — 단순 합산이 아니다. 상한인지 8월 한정인지
   공식 미확인이므로 단정하지 않고 "상한 6.0%p"로만 적고 확인 안내.
3. **신한 거래가 있으면 5%p가 통째로 빠진다** — 직전 6개월 예·적금·주택청약 보유자는 제외.
4. **월 30만원 적립식** — 표시금리를 원금 전체에 곱한 이자가 아니다.
