# 팩트시트 — learning-card-university-student

- 관할: 고용노동부 / 1차 출처: 국민내일배움카드 운영규정 제4조
  https://www.law.go.kr/LSW/admRulInfoP.do?admRulSeq=2100000279150
- 교차 출처: 고용24 국민내일배움카드 발급안내(지원자격)
- 확인일: 2026-09-18

## 수치

| 항목 | 값 | 근거 |
|---|---|---|
| 대학 재학생 발급 가능 기준 | 졸업까지 남은 수업연한이 2년 이내 | 제4조제2항제10의2호 가목 |
| 원격대학 재학생 | 제외에서 빠짐(발급 가능) | 같은 호 라목 |
| 고등학생 | 고등학교 3학년 재학생은 제외에서 빠짐 | 제4조제2항제10호 단서 |
| 판단 시점 | 신청일 기준 | 제4조제5항 |
| 피보험자 예외 | 제10의2호에 해당해도 고용보험 피보험자면 지원 가능 | 제4조제3항 |

## 단서

- 제외되는 대상은 「고등교육법」 제2조 및 제29조의2에 따른 학교의 재학생이다. 제29조의2는 대학원을 포함하므로 대학원 재학생도 같은 조항 안에 있다.
- 고용24는 이 조항을 "졸업까지 남은 수업연한이 2년 이상인 대학/대학원 재학생"이 제외된다고 풀어 안내한다.
- 제4조제5항: 지원제외에 해당하는지는 계좌발급을 신청하는 경우와 훈련과정을 수강 신청하는 경우 모두 신청일 기준으로 판단한다.
- 제4조제6항의 2년 주기 판단은 제11호부터 제15호까지(대규모기업 근로자·소득 기준 항목)에만 적용된다. 제10의2호는 여기에 들어가지 않으므로 수강신청 때마다 신청일 기준으로 다시 본다.
- 제4조제3항: 제10의2호에 해당하는 사람이라도 고용보험 피보험자(고용보험법 제5장의2·제5장의3 적용 피보험자는 제외)면 지원할 수 있다.

## 오해 소지

- "대학생은 안 된다"는 절반만 맞다. 졸업까지 남은 수업연한이 2년 이내면 재학 중에도 발급된다. 원격대학 재학생은 연한과 무관하게 제외에서 빠진다.
- 2년 주기로 한 번만 판단하는 조항(제6항)은 대학생 조항에 적용되지 않는다. 학년이 올라가면 신청일마다 다시 본다.

## 쓰지 않는 것

- 휴학생·군휴학이 "재학생"에 포함되는지 — 운영규정에 휴학을 따로 정한 조항이 없고, 학적 처리 기준은 학교와 고용센터 판단 영역이라 1차 출처로 확인하지 못했다. 조문이 정한 재학생 기준과 신청일 판단 원칙까지만 쓰고, 휴학 상태 처리는 관할 고용센터 확인으로 안내한다.
- 복학 시 이미 발급된 카드가 정지되는지 — 제18조제2항은 지원대상 요건에 해당하지 않게 되거나 지원제외에 해당하게 되면 계좌사용을 중지할 수 있다고만 정하고, 복학을 명시하지 않았다. 단정하지 않는다.
