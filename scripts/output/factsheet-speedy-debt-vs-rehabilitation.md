## 2. 단서 조항 (본문 반영)

- 개인회생 변제계획은 법원이 정한 기준으로 산정되며, 위원회는 접수 절차를 지원할 뿐 인가는 법원이 한다 (2290) → qa4
- 위원회에 접수된 사건은 전담재판부 운영 등으로 신속하게 심리된다 (2290) → qa4
- 신속채무조정 이행 중 개인회생을 신청하면 실효되므로 갈아타기 전 상담 필요 (680) → qa3

## 3. 확보하지 못한 것 (본문에 쓰지 않음)

- 개인회생 변제금 산정 5가지 기준의 세부 수치: FAQ 문답에 항목만 확인(본문은 "법원 기준"으로만)
- 개인회생 인가율·평균 변제율: 공식 자료 없음
- 신속채무조정에서 개인회생으로 갈아탈 때 걸리는 기간: 공식 안내 없음 (17번에서 재확인)
