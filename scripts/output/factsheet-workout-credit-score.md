## 2. 단서 조항 (본문 반영)

- **"얼마나 떨어지나요"에 숫자로 답하지 않는다** — 신용점수는 KCB·NICE 같은 신용조회회사가 자체 모델로 산정하는 값이고, 신복위는 그 점수를 발표하거나 관리하는 기관이 아니다. 대신 신복위가 실제로 관리하는 것(공공정보 등재·해제)으로 답의 축을 옮긴다 → qa1
- 공공정보 등재는 "손해"가 아니라 "교환"에 가깝다 — 등재와 동시에 기존 연체정보가 일괄 해제되는 구조(FAQ) → qa2
- 해제는 "1년"이 기본이지만 조기완제 시 즉시 해제된다는 점(7번 편에서 이미 확정, 재사용) → qa3
- "그 외 불이익"은 막연히 나열하지 않고 공식 자료가 실제로 언급한 두 사례(신원보증보험 제한 가능성, 보험 해약환급금 상계)로 구체화 → qa4

## 3. 확보하지 못한 것 (본문에 쓰지 않음)

- **신용점수 하락 폭(몇 점)**: 공식 수치 없음, KCB·NICE 산정 영역
- 개인워크아웃 확정 후 신용점수가 회복되는 데 걸리는 기간: 공식 수치 없음("신용도가 어느 정도 회복되면"까지만 FAQ에 있음)
- 신원보증보험 외 다른 보험·금융상품 가입 제한 목록: 공식 안내에 포괄적 목록 없음
