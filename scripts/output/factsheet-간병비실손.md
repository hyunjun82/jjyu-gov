## 2. 행동 검증

- 버튼 목적지 URL을 Playwright로 열었는가: 협회 FAQ(열람 확인), 실손24(열람 확인), 장기요양 신청은 건보공단 — 본문 작성 시 URL 재확인 필요
- 로그인/보안프로그램/인증서 등 진입 장벽: 실손24 로그인 / 장기요양은 공단 방문·온라인, 의사소견서 필요
- 누가 신청할 수 있는가 (대리 신청 가능 여부): 실손은 본인·대리청구인 / 장기요양 신청은 본인·가족·대리인
- 기관이 실제로 쓰는 메뉴명·동사: 협회 "보장(보장하지 않는) 내용" / 실손24 "나의부모/제3자 청구"

## 3. 예외·단서 조항 (긍정문 뒤집는 "다만" 전수)

- 간병비는 미보상이지만 **입원료·입원제비용·입원수술비는 보상 대상** — 병원비와 간병비를 나눠서 봐야 한다
- 상급병실료 차액은 **특별약관에 한함**
- 장기요양 등급·급여 범위는 공단 심사 결과에 따름 — 이 글에서 단정하지 않는다

## 4. 확인 못 해 쓰지 않는 것

- 간병비 지원 지자체 사업·간병인보험 상품 비교 — 근거 범위 밖
- 장기요양 본인부담률 수치 — 이 글에서 확인 안 함, 기존 장기요양 글로 연결

## 5. 기존 글 정합

- 같은 수치를 쓰는 기존 허브/스포크: 도수치료/산재 등과 무관. 장기요양등급 관련 기존 글과 연결 가능
