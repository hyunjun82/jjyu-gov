# 구성표 — 신속채무조정 신용점수 (speedy-debt-credit-score)

**타이틀** 신속채무조정 신용점수 얼마나 떨어질까? 공공기록 등재와 회복 시기
**패턴** ⑤ 하락폭·회복
**출처 검색어** 사장님 확정본(2026-09-15) — 소제목 그대로, 타이틀은 공식 훅 통과를 위해 '신용점수 하락폭'을 '신용점수 얼마나 떨어질까?'로만 수정
**허브** /policy/debt-restructuring (신속채무조정 14/19편)

## hero (서론)

채무조정을 신청하면 신용점수가 바닥까지 떨어져 몇 년은 아무것도 못 한다는 말에 망설이게 되시죠. 기록이 어디에 얼마나 남는지도 모르니 더 겁이 나고요. 신용회복위원회 안내를 보면 채무조정이 확정되면 연체정보가 해제되고, 신속채무조정과 사전채무조정은 한국신용정보원에 신용회복지원 공공정보를 아예 등재하지 않는데요. 다만 점수가 몇 점 떨어지는지는 공식 자료에 수치로 나와 있지 않고, 이미 생긴 연체와 조정 사실은 금융회사가 각자 반영하며, 실효되면 해제됐던 연체정보가 다시 등록됩니다. 그럼 공공정보가 어떻게 등록·해제되는지부터 확인하셔야겠죠.

**← 상단 버튼: 공공정보 등록·해제 기준 → https://www.ccrs.or.kr/cms/com/index.do?MENU_ID=620**

## 오해 소지 — 본문에서 반드시 풀 것

1. 점수 하락폭은 공식 수치가 없다 — 추정 금지.
2. 신속·사전채무조정은 공공정보(1101·1802) 미등재, 개인워크아웃은 등록 후 1년 이상 납입 시 해제.
3. 확정되면 연체정보는 해제되지만, 실효되면 다시 등록된다.
4. "연체정보등"은 3개월 이상 연체 시 한국신용정보원에 등록되는 정보다.
