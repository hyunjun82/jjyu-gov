# 팩트시트 — 아이 수족구 실비 청구

> 2026-08-10. 타이틀: "아이 수족구 실비 청구, 진단서 없이도 되나요?"

## 0. 관할 확정
- 기관 2곳 이상?: 아니오. 보상 기준=금감원 표준약관, 청구=실손24(보험개발원), 소비자 안내=손보협회.
- 법령: 보험업감독업무시행세칙 [별표15] 표준약관

- **캡처에서 확인한 것 (표 구조·단서 위치)**: 표준약관 면책 목록은 「한국표준질병사인분류」 코드를 하나하나 열거하는 방식이라 **열거되지 않은 질환은 면책이 아니다**는 구조가 화면으로 봐야 드러난다. 열거된 것은 정신·행동장애(F04~F99), 여성생식기 비염증성 장애(N96~N98), 임신·출산(O00~O99), 선천성 뇌질환(Q00~Q04), 비만(E66), 요실금(N39.3·N39.4·R32), 항문질환(K60~K62·K64)뿐이며 **수족구 같은 감염성 질환 코드는 급여면·비급여면 어디에도 없다**. 손보협회 비교표는 3열 4행이고 마지막 행에서 실손(비례 보상)과 정액형(중복과 무관하게 각각 지급)이 갈린다 — 실비와 진단금을 따로 받는 근거가 이 한 행이다. 실손24 메인은 청구 주체를 **"나의 실손청구 / 나의 자녀청구(미성년자 자녀의 보험청구) / 나의부모·제3자 청구"** 카드로 나눠 두어, 자녀 진료는 별도 메뉴로 들어가야 함이 화면에서 확인된다.
- 텍스트 추출만으로 판단한 항목: 없음.

## 1. 확정 사실
| 항목 | 값 | 근거 |
|---|---|---|
| 수족구 진료비 | **보상** (면책 목록에 감염성 질환 없음) | p209·p260 |
| 자녀 청구 | 실손24 "나의 자녀청구(미성년자 자녀의 보험청구)" 메뉴 | 실손24 메인 캡처 |
| 실손 청구 서류 | 진료비영수증·세부내역서·원외처방전·약제비 영수증 (참여기관 자동 전송) | 실손24 FAQ |
| 진단금(정액형) | 치료비와 무관한 약정 정액, 중복과 무관하게 각각 지급 | 손보협회 비교표 |
| 지급 기한 | 접수일부터 3영업일 이내 | 제8조 p213 |

- 교차출처: 면책 목록 부재를 급여면(p209)·비급여면(p260) 두 면에서 확인. 실손/정액형 구분은 협회 비교표.

## 2. 행동 검증
- 버튼: https://www.silson24.or.kr/claim/web/ (캡처 확인). 로그인 없이 안내 접근, 청구 시 본인인증.
- **대리 청구: 가능** — 미성년 자녀 청구 메뉴 존재(캡처).
- 기관 동사: "청구".

## 3. 예외·단서
1. **진단서는 실손 청구의 자동전송서류 4종에 포함되지 않는다** — 다만 정액형 진단금 특약은 보험사마다 요구 서류가 달라 **"진단서가 절대 불필요"로 단정하지 않는다.** 실손은 4종으로 접수된다는 사실만 서술.
2. 비급여로 처리된 항목(예: 일부 검사)은 상품·특약에 따라 결론이 다를 수 있음.
3. 수족구 진단금 지급 여부·금액은 개별 특약 사항 — 공시에 없으므로 금액 단정 금지.

## 4. 기존 글 정합
