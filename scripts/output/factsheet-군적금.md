# 팩트시트 — 장병내일준비적금 + 청년미래적금 (군 복무 목돈)

> 2026-08-11. 타이틀: "장병내일준비적금 청년미래적금 같이 가입 가능할까? 월급만으로 3,891만원"

## 0. 관할 확정
- 장병내일준비적금: **국방부**(현역·상근예비역), 법무부(대체복무요원), 병무청(사회복무요원). 지급은 국군재정관리단.
- 청년미래적금: **금융위원회·서민금융진흥원**.
- 중복 가입 가능 여부를 발표한 곳: **금융위원회**(국방부 협의, 2026.06.08).
- 은행별 금리 공시: **전국은행연합회 소비자포털**.
- 기관이 4곳이라 수치의 출처를 섞지 않는다 — 한도·매칭은 국방부, 합산 금액은 금융위, 금리는 연합회.

- **캡처에서 확인한 것 (표 구조·단서 위치)**: 금융위 보도자료의 합산 금액은 본문 한 줄이 아니라 **별표 각주에 조건이 달려 있다.** "약 3,891만원*"의 각주는 "장병내일준비적금에 최대한도(월 55만원) 납입하고 청년미래적금은 병급여(이병 75만원, 일병 90만원, 상병 120만원, 병장 150만원)에서 장병내일준비적금 월 납입액을 제외한 금액 납입", "약 4,074만원**"의 각주는 **"입영 전 저축액 등 활용"**이다. 즉 4,074만원은 월급 밖의 돈이 있어야 나온다. 본문만 읽으면 둘 다 그냥 되는 금액처럼 보인다. 또 괄호로 **"단, 청년미래적금은 만기가 3년으로 제대 후에도 납입 필요"**가 붙어 있어, 복무 중에 끝나는 돈이 아니다. 국방부 페이지의 자산형성 예시도 **월 40만원(2024년 한도) 기준**이라 2025년 한도 55만원과 다른 전제이므로 섞으면 안 된다.
- 텍스트 추출만으로 판단한 항목: 없음.

## 1. 확정 사실

### 장병내일준비적금 (국방부)
| 항목 | 값 |
|---|---|
| 가입대상 | 현역·상근예비역(국방부), 대체복무요원(법무부), 사회복무요원(병무청) |
| 월 한도 | **2025년 1월부터 개인 월 55만원** (1인 2계좌, 동일은행 불가, 계좌당 30만원, 5만원 단위) |
| 가입기간 | 육군·해병·상근 ~18개월 / 해군 ~20 / 공군·사회복무 ~21 / 대체복무 ~24 |
| 최소 가입 | '24.6월부터 **잔여 복무 1개월 이상**이면 가능 |
| 이자 | 5% 수준 **비과세**. 기초수급자 추가 우대 3.0%(IBK기업·국민은행) |
| 정부 매칭 | **2024년부터 원금의 100%** (~'23년은 원리금의 71%, '22년 33%) |
| 중도해지 | **비과세도 정부지원금도 못 받음** |

### 청년미래적금 (금융위·서금원) — 기존 허브 youth-future-savings 검증분

| 월 한도 | 50만원 / 3년 만기 |
| 정부 | 월 납입금 6%(일반형)·12%(우대형) |

### 합산 (금융위 보도자료)
| 구분 | 금액 | 조건 |
|---|---|---|
| 병 월급만 활용 | **약 3,891만원** | 장병적금 월 55만 + 청년미래적금은 병급여에서 그만큼 뺀 금액 |
| 최대한도 납입 | 약 4,074만원 | **입영 전 저축액 등 활용** |
| 장병적금 만기 | 약 2,019만원 | 원금 990 + 매칭 990 + 이자 39 (금리 5% 가정) |
| 청년미래적금 만기 | 약 1,872만원(월급만) / 2,055만원(최대) | 금리 5% 가정 |

- **계산 검산**: 2,019 + 1,872 = 3,891 ✓ / 2,019 + 2,055 = 4,074 ✓
- 병급여: 이병 75만 / 일병 90만 / 상병 120만 / 병장 150만 (금융위 각주)

## 3. 예외·단서
1. **4,074만원은 입영 전 저축이 있어야 한다** — 타이틀·서론에 쓰지 않고 본문에서 조건과 함께만 제시.
2. **청년미래적금은 3년 만기라 전역 후에도 납입해야 한다** — 복무 중에 끝나는 돈이 아니다.
3. **중도해지하면 비과세·매칭 전액 상실** — 조기전역·신분전환자는 만기까지 유지해야 함.
4. 국방부 자산형성 예시는 **월 40만원(2024년 한도)** 기준 — 55만원 한도와 섞지 않는다.
5. 금리 5%는 **가정치**. 실제 금리는 은행연합회 공시를 봐야 한다.
6. 청년미래적금 신청은 **연 2회(6월·12월)** — 상시가 아니다.
