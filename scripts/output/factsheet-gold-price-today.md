## 0-B. 원문 확인

- Playwright 로 koreagoldx.co.kr 를 열어 "한국금거래소 시세 라인업" 표를 그대로 추출. 표 머리에 **2026.08.15** 가 찍혀 있고 열 이름이 **"내가 살 때 (VAT포함)"** 과 **"내가 팔 때 (금방금방 앱 기준)"** 이다. 네이버금융 goldDetail 에서 국내 금시세가 **200,056.86원/g, 전일대비 +657.91(+0.33%)**, 표기가 **"2026.08.14 23:59 신한은행 기준 고시회차 821회"** 임을 확인했다. 같은 화면에 **1트로이온스 = 31.1034768g / 1돈 = 3.75g / 1트로이온스 = 8.294돈** 과 **"매매기준율(원화) = 국제금시세 ÷ 31.1034768 × 원달러환율 × 99.99% / 실물거래시 부가가치세(10%)는 별도"** 가 적혀 있다.
- KRX 는 data.krx.co.kr 접속 시 로그인 화면이 뜨고, getJsonData.cmd 는 세션 없이 `LOGOUT` 을 돌려준다. 그래서 이 글은 한국금거래소와 신한은행 고시를 출처로 삼는다.

## 2. 계산 검산 (2026-08-17)

- 살 때와 팔 때 차이: 874,000 − 731,000 = **143,000원**
- 팔 때가 살 때의 **83.6%** (731,000 ÷ 874,000)
- 신한 기준 1돈 값: 200,056.86 × 3.75 = **750,213원** (부가세 별도)
- 여기에 부가세 10%: 750,213 × 1.1 = **825,234원**
- 한국금거래소 살 때 874,000원과 차이 48,766원 → 유통 마진분. 본문에는 4만원쯤으로 반올림해 적는다
- 본문 반올림 표기: 874,000원 → 87만원 / 731,000원 → 73만원 / 143,000원 → 14만원
- 사자마자 되팔 때 빠지는 폭: 100 − 83.6 = 16.4% → 본문에는 16% 정도로 적는다
- 전일 대비 순금 살 때 +8,000원(0.92%), 팔 때 +4,000원(0.55%)

## 3. 단서 — 본문에서 반드시 밝힐 것

- **시세는 매일 바뀐다.** 이 글의 숫자는 2026년 8월 15일 고시 기준이다.
- **살 때는 부가세 10% 포함**, 팔 때는 부가세가 붙지 않는다.
- 팔 때 가격은 **금방금방 앱 기준**이고 실제는 감정 결과에 따라 달라진다.
- 18K·14K는 살 때가 **"제품시세적용"** 이라 정액이 없다.
- 백금·은의 팔 때는 **자사 바(bar) 기준**이다.
- 한국금거래소는 정부기관이 아니라 **민간 유통사**이고, 이 값은 그 회사 고시가다.
