## 2. 단서 조항 (본문 반영)

- 햇살론일반도 서민금융 신용평가시스템에 따라 보증이 거절될 수 있음 (서민금융진흥원) → qa2
- 토스뱅크: 은행 심사기준·신용평가 결과에 따라 제한될 수 있고, 대출 실행 시 신용점수가 하락할 수 있음 → qa4
- 소액대출은 연체정보 등록·최근 6개월 내 신규 채무 등으로 제한 (2000) → qa1

## 3. 확보하지 못한 것 (본문에 쓰지 않음)

- 완제 후 며칠·몇 개월이면 대출이 되는지: 공식 안내 없음
- 신속채무조정 이용자가 햇살론일반·근로자햇살론에 해당하는지에 대한 명시: 두 페이지 모두 개인워크아웃·개인회생만 언급
- 토스 비상금대출과 신복위 채무조정의 관계: 상품 안내에 언급 없음
- 신용점수가 언제 얼마나 회복되는지: 공식 안내 없음
