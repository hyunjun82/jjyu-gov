## hero (서론)
소득만 보면 분명 기준 아래인데 수급자도 차상위도 아니라는 통보를 받는 경우가 있습니다.
법이 차상위를 "수급권자에 해당하지 아니하는 계층"으로 정의해서, 순서가 수급 판정이 먼저입니다.
그래서 왜 떨어졌는지는 소득이 아니라 재산과 가족 쪽에서 답이 나옵니다.
**← 상단 버튼: [내 소득인정액 계산해보기] → /guide/income-recognition**

## 오해 소지 — 본문에서 반드시 풀 것
1. "소득 낮으면 차상위" → 수급 판정이 먼저고, 수급자면 차상위가 아니다
2. "혼자 살면 내 소득만 본다" → 개별가구 범위가 따로 정해져 있다
3. "재산 없으면 무조건 된다" → 소득인정액은 소득평가액 + 재산의 소득환산액
4. "차상위는 하나" → 확인·본인부담경감·자활·장애로 갈린다
