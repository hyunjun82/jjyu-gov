## 2. 단서 조항

- 4대보험 중 국민연금만 "다음 달 15일까지"로 기한 계산법이 다르다. 건강보험·고용보험·산재보험 3종은 "성립일부터 14일 이내"로 계산법이 같다. 이 둘을 섞어 "전부 14일"이라고 쓰면 국민연금 기한 오안내가 된다.
- 직원이 없는 1인 개인사업자(대표자 본인)는 근로자가 아니므로 위 4대보험 사업장 신고 의무 자체가 발생하지 않는다. 대표자 본인의 건강보험은 지역가입자로 유지되고, 고용보험(고용안정·직업능력개발사업)은 자영업자 임의가입만 가능하다(고용산재보험료징수법 제49조의2).
- 신고처는 4insure.or.kr 전자민원이며 공동인증서(구 공인인증서) 로그인이 있으면 세무사 없이 사업주 본인이 직접 접수할 수 있다 — 대행을 강제하는 법 조항은 없다.

## 3. 확보하지 못한 것 (본문에 쓰지 않음)

- 세무사·4대보험 신고대행업체 평균 수수료 — 공식 요금표가 없어 1차 출처 불가, 본문에 예시 금액을 쓰지 않는다.
- 급여별 국민연금·고용보험 실제 원 단위 계산 예시 — 4insure.or.kr 계산기가 건강보험(200만원 기준)만 verbatim 예시를 제공해, 국민연금·고용보험은 요율만 쓰고 임의로 원 단위 총액을 계산해 쓰지 않는다.

## 4. 오해 소지 — 본문에서 푼 자리

1. "4대보험 신고 기한은 다 14일" → 국민연금만 다음 달 15일까지로 다르다.
2. "개인사업자는 무조건 4대보험 가입 의무" → 직원을 채용해야 발생하며, 대표자 혼자면 의무 자체가 없다.
3. "세무사를 껴야 신고할 수 있다" → 4insure.or.kr 전자민원으로 사업주 본인 직접 신고가 가능하다.
4. "4대보험료는 사업주가 전부 낸다" → 국민연금·건강보험·고용보험(실업급여분)은 절반씩, 고용안정·직업능력개발사업분과 산재보험료만 사업주 전액 부담.
5. "4대보험료는 계좌이체로만 낼 수 있다" → 사회보험통합징수포털(si4n.nhis.or.kr)에서 신용카드(수수료 0.8%)·체크카드(0.5%) 납부도 가능하다. 직불카드·해외발급카드·기프트카드·무기명 체크카드는 불가.
