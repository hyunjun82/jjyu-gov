## 각 카드에 들어갈 사실

### qa1 개인워크아웃하면 신용카드가 정지되나요?
- 신복위 공식 자료에 "카드가 자동으로 정지된다"는 문구는 없다 — 정직하게 시작
- 오히려 정반대 방향 안내가 있다: 채무조정 신청해도 카드대금 자동이체는 자동 해지되지 않는다(직접 요청해야 함)
- 11번 편과 같은 논리 연결: 여신은 소득·신용상태·연체이력을 카드사가 종합 판단
- **box**: 자동으로 되는 것 vs 안 되는 것

### qa2 쓰던 카드는 계속 쓸 수 있나요?
- 공식 규정 없음 — 카드사 자체 심사 소관
- 발급 제한 대상자 목록(신규 소액카드 기준)의 "KCB·NICE 연체정보 등록"을 참고 원리로 인용하되, 이건 신규 신청 기준이지 기존 카드 유지 기준이 아니라는 걸 명확히 구분
- 카드대금 자동이체를 직접 해지 요청해야 한다는 실무 팁 반복 강조

### qa3 체크카드는 어떻게 되나요? → 버튼 ②
- 원래 쓰던 일반 체크카드: 공식 안내 없음(은행 개별 정책)
- 위원회의 "소액신용체크카드"·"후불교통체크카드" 지원사업과 혼동하지 않게 구분
  - 후불교통체크카드: 6개월 이상 이행, 신용거래 불가
  - 소액신용체크카드: 12개월 이상 이행, 신용거래 가능, 한도 30만원 이내
- act cue: 카드대금 자동이체가 자동으로 안 끊긴다는 걸 다시 확인

### qa4 카드 재발급은 언제부터 되나요? → 버튼 ③
- 신용카드(하나카드): 12개월 이상+미납 없음. 재조정 중이면 6개월+누적12개월. 완료 후 3년 이내도 가능
- 신용카드(국민카드): 24개월 이상(신속·사전은 18회)+미납 없음. 재조정 중이면 12개월+누적24개월. 완료 후에도 가능(기간 제한 없음 — 하나카드와 차이)
- 체크카드: 6개월(후불교통)/12개월(소액신용)+미납 없음
- 발급 제한 대상자 6가지
- 한도·비용: 국민카드 30~50만원(최대150만원), 하나카드 100만원, 체크카드 30만원. 연회비 국민 1만원·하나 1.2만원
- **table**: 카드별 자격 기간 비교

## FAQ 2개
1. 카드대금 자동이체는 채무조정 신청하면 자동으로 끊기나요? → 아니다, 직접 해지 요청 필요 (출처 2500)
2. 소액신용카드 한도는 얼마인가요? → 국민카드 최초 30~50만원(최대 150만원), 하나카드 100만원, 체크카드 30만원 (출처 2500)

## 쓰지 않는 것
- 개인워크아웃 확정 시 기존 카드 정지·해지 여부 — 공식 안내 없음
- 일반 체크카드(위원회 지원 상품 아닌 것) 유지 여부 — 공식 안내 없음
- 소액신용카드 발급 승인율 — 공식 통계 없음
