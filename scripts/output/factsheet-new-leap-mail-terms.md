## 2. 단서 조항 (본문 반영)

- 심사생략 대상: 기초생활수급자·중증장애인(장애인연금수령자)·보훈대상자(생활조정수당·생계지원금수급자) (85809·86422·87213) → qa1
- 매입제외채권(채무조정 진행 중 등)도 5천만원 판별에 합산 (FAQ) → faq
- 새도약기금은 별도 신청 절차 없음 → 양도 예정 통지를 받아도 할 일은 조회 (85809) → faq

## 3. 확보하지 못한 것 (본문에 쓰지 않음)

- 조회 화면·우편물의 "심사대상", "심사중", "미양도" 상태 이름에 대한 공식 정의 — 새도약기금 누리집·FAQ·공지, 금융위 보도자료, 정책브리핑, 검색 결과(블로그 포함)에서 정의를 찾지 못함. 로그인 후 화면은 본인인증이 필요해 직접 확인 불가 → 본문에는 "공식 풀이는 공개돼 있지 않다"고 밝히고, 공식 자료에서 쓰는 가까운 표현으로만 풀이
- 종결(기타면제)의 "기타면제" 세부 사유 — 공지에 정의 없음
