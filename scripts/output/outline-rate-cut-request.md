# 구성표 — rate-cut-request (2026-08-18)

## 타이틀
금리인하요구권 신청조건과 서류, 은행마다 깎이는 폭이 왜 다른가
- 사장님이 주신 키워드(금리인하요구권 / 조건 / 서류) 유지
- 종결: 시나리오형 "왜 다른가" (docs/title-style-24.md §0 — 합니다/~법 종결 금지)
- title-formula: 세부키워드(조건·서류) + 행동어(신청) + 후킹(깎)

## hero 서론
수용률과 인하폭이 은행마다 딴판이라는 것 -> 상단 버튼으로

## 소제목 6개 (버튼은 인덱스 2·4·마지막)
| # | 앵커 | 소제목 | 버튼 |
|---|---|---|---|
| 0 | q-what | 금리인하요구권이 뭔가요? | |
| 1 | q-when | 어떤 경우에 신청할 수 있나요? | |
| 2 | q-banks | 은행마다 얼마나 깎아주나요? | O |
| 3 | q-docs | 서류는 뭘 내야 하나요? | |
| 4 | q-reject | 거절되면 어떻게 하나요? | O |
| 5 | q-apply | 어디서 신청하나요? | O(마지막) |

## 버튼 목적지
- 상단(ctaLabel/applyUrl) -> 은행연합회 소비자포털 금리인하요구권 공시
- qa2 -> 은행연합회 공시 (내 은행 수용률·인하폭)
- qa4 -> KB 금리인하요구권 안내 (적용 제외 대상 확인)
- 마지막 -> KB 금리인하요구권 신청 안내

- 2026년 상반기 공시 — 아직 미공시(최신은 2025 하반기)
