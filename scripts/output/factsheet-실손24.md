## 3. 예외·단서 조항 (긍정문 뒤집는 "다만" 전수)

- **심사·지급은 실손24가 안 한다** — 실손24는 서류를 보험사로 전송하는 **중계기관**. 접수·심사·지급 현황은 각 보험사 홈페이지·앱에서 확인
- **병원이 문을 닫으면 청구가 안 된다** — 참여병원이라도 휴원·업무종료 시 진료내역이 조회되지 않아 청구 진행 불가. "현재 병원 사정으로 인해 청구가 어려워요" 메시지가 이 경우
- **최초진료일자 이전 진료는 선택 불가** — 보험계약 조회 때 입력한 최초진료일자(사고발생일자) 이전 내역은 조회돼도 선택되지 않음 → 날짜를 조정해 재조회
- **신규청구 vs 추가청구** — 보험사 앱으로 직접 청구한 내역은 실손24가 알 수 없으므로, 실손24에서 처음 넣는 것이면 추가 진료라도 **신규청구**로 선택
- 추가청구 가능기간·동일질환 인정 범위는 **보험사 약관마다 다름** → 단정하지 않고 보험사 확인 안내
- 미참여 병원 처리 방법은 공식 FAQ에서 확인하지 못함 → 본문에서 단정하지 않고 참여병원 조회·보험사 직접청구 안내로 처리
- 수수료 관련 규정도 공식 페이지에서 확인 못 함 → **금액을 쓰지 않는다**(실검색어에 "실손24 수수료"가 있으나 근거 미확보)
