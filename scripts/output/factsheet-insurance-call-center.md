## 2. 단서 조항

- 상담사 상담은 평일 주간이 기본, 사고접수·긴급출동은 야간·공휴일에도 접수된다.
- 같은 회사라도 **평일 주간과 야간의 ARS 단축번호가 다르다.** 주간 기준 안내를 밤에 그대로 누르면 다른 메뉴로 들어간다.
- ARS 단축번호를 공개하지 않는 회사가 있다(구성도가 이미지이거나 메뉴 이름만 있는 곳). 번호를 순서로 추정하지 않고 "미공개" 로 둔다.
- NH농협생명·NH농협손해보험·삼성생명은 출처가 모바일/다이렉트 서브도메인이다(`m.nhlife`, `m.nhfire`, `direct.samsunglife`). 같은 회사 도메인이라 1차 출처로 인정한다.

## 4. 오해 소지 — 본문에서 푼 자리

- "대표번호 하나면 다 된다" → 실제로는 업무별 전용번호가 따로 있고, 대표번호는 ARS 를 거친다.

## 6. CI 색과 화면 색은 다르다 (2026-08-26)

CI 색을 그대로 버튼에 쓰면 밝은 회사는 흰 글자가 묻힌다 — KB 노랑 `#FBAE14` 에 흰 글자는 대비 **1.88** 이다.
`readable()`(`components/CallCenterPage.tsx`) 이 **색상은 그대로 두고 대비 4.5 가 될 때까지만 어둡게** 내린다.

- 이미 어두운 15곳(삼성·AXA·SGI 등)은 CI 색 그대로 나간다.
- 밝은 11곳만 내려간다: KB 노랑 `#FBAE14` → 화면 `#92650C`(5.14), 현대해상 `#FF9D1A` → `#A66611`(4.64), 교보 `#6DB327` → `#4E811C`(4.69).
- 26곳 전부 대비 4.5 이상. JSON 의 `brandColor` 는 **CI 원색을 그대로 보관**한다 — 화면용으로 고쳐 넣지 않는다.
