## 2. 단서 조항 (본문 반영)

- 조정에서 제외된 채권자나 제3자가 경매를 신청하면 채권금융회사도 경매절차에 참가할 수 있고, 변제받으면 조정안을 재심의·의결할 수 있다 (협약 제22조③④) → qa1
- 예금계좌 이용 전 지급정지·(가)압류 여부를 미리 확인할 것 (FAQ) → qa2

## 3. 확보하지 못한 것 (본문에 쓰지 않음)

- 압류가 실제로 풀리는 데 걸리는 기간: 공식 안내 없음
- 민사집행법 제246조제1항제9호의 금액(시행령 기준액): 협약 본문에 금액 표기 없음
- 대위변제 구상채권의 감면율: 협약 별도 조문이 있으나 신속채무조정 적용 여부가 명시되지 않아 미사용
- 계좌 지급정지 해제 요청 서식·창구: 공식 안내 없음
