## 2. 급여(가)압류 해제 절차 (신청 불가 사유 3가지 포함)

| 항목 | 내용 |
|---|---|
| 신청 불가 사유 ① | 압류 채권자가 위원회 협약 채권금융회사가 아닌 경우 |
| 신청 불가 사유 ② | 급여의 압류가 전부명령인 경우 |
| 신청 불가 사유 ③ | 제3채무자(근무회사)가 적립금액의 일부를 법원에 공탁한 경우 |
| 구비서류 | 압류 및 추심명령 결정문 사본 / 급여(가)압류 채권자·추심권자 및 적립금액 확인서(위원회 양식) / 채권자별 압류내역서(위원회 양식) |
| 해제 절차 4단계 | ①확정 후 합의서 작성 시 위원회가 해제 공문·확약서 교부 → 채무자가 근무지에 제출 ②근무지가 확약서 작성 후 위원회 심사역에 제출 ③위원회가 채권금융회사에 통지 ④채권금융회사가 지정기한까지 해제, 근무지는 적립금을 위원회에 송금, 위원회가 배분 |
| 해제 기간 | 약 2~3주 |
| 회사 통지 여부 | 위원회는 채무조정 신청 사실을 근무지에 통지하지 않음. 다만 급여압류 해제를 위해서는 근무지와 확인·확약서 관련 연락이 있을 수 있음 |

## 4. 단서 조항 (본문 반영)

- **"통장압류"는 한 종류가 아니다** — 예금계좌 자체의 지급정지·가압류(신청 전 것은 해제 안 됨) / 급여(가)압류(조건부 2~3주 해제) / 부동산(가)압류(자동 해제 안 됨) 세 갈래로 나눠 답한다 → qa1이 이 핵심
- 추심은 멈추지만 상계를 위한 지급정지는 예외적으로 가능하다는 점이 "왜 통장이 자동으로 자유로워지지 않는지"의 답이 된다 → qa1·qa3
- 독촉이 계속되면 원칙 위반이니 확인이 필요하다는 것과, 보증인까지 보호 대상이라는 점을 함께 답한다 → qa4

## 5. 확보하지 못한 것 (본문에 쓰지 않음)

- 급여(가)압류 해제까지 "정확히 며칠"인지: 공식 안내는 "약 2~3주"로만 표현, 특정 일수는 없음
- 부동산 압류 해제 협상에서 요구되는 상환 비율의 구체 기준: FAQ는 "일부 상환 등을 요구할 수 있음"까지만
