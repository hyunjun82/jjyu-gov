# 구성표 — 주택담보대출 (mortgage-additional-loan)

**타이틀** 주택담보대출 추가 신청과 후순위 대출, 기대출 과다면 나눠 받는 방법은? (원문 "나눠 받나요"는 해요체 종결·세부키워드 미충족으로 훅 통과 못 해 "나눠 받는 방법은?"으로 조정)
**패턴** C. 신청·절차 — 사장님이 26편 세트로 직접 확정한 타이틀(11번)
**출처 검색어** 주택담보대출 추가대출(자동완성) · 후순위 담보대출(자동완성) · 주택담보대출 기대출(자동완성) · 주택담보대출 나눠받기(딥쿼리)

## hero (서론) — 여기만 사람이 쓴다

주택담보대출을 받은 뒤에 목돈이 더 필요해지면 같은 집으로 추가 대출을 받을 수 있는지 궁금해지실 텐데요, 이미 근저당이 잡혀 있는 집이라 아무 은행에서나 되는 건 아닙니다. 후순위로 별도 대출을 받는 방법이 있긴 하지만, 결국 DSR이라는 소득 대비 상환능력 기준을 넘으면 거절될 수 있습니다. 다만 한도 안에서라면 한 집에 여러 금융회사가 나눠서 대출을 걸어주는 것 자체는 제도상 가능합니다. 그럼 먼저 추가로 더 받을 수 있는지부터 보겠습니다.

## 오해 소지 — 본문에서 반드시 풀 것

1. 후순위 담보대출의 구체적 취급 은행·금리·한도는 이 세션에서 공식 출처를 확인하지 못해 단정하지 않는다 — 근저당권 순위 개념과 일반적 취급 형태(2금융권 중심)만 설명하고, 구체 수치는 "확인 필요"로 남긴다.
2. DSR 40%/60% 기준과 차주단위 DSR 적용 시점·대상(2019~2020년 대책 기준)은 출처 페이지 작성일(2020.9.4)이 오래됐다는 점을 밝히고, 계산식과 기본 구조(연소득 대비 원리금상환액)만 확정 사실로 쓴다. 최신 규제 세부사항은 은행 확인이 필요하다고 안내한다.
