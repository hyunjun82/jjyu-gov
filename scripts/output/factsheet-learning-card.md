# 팩트시트 — learning-card (허브)

- 관할: 고용노동부 / 발급 결정: 지방고용노동관서 / 전산: 한국고용정보원
- 1차 출처: 국민내일배움카드 운영규정 (2026 고시)
  https://www.law.go.kr/LSW/admRulInfoP.do?admRulSeq=2100000279150
- 교차 출처: 고용24 발급안내 · 제도안내 · 훈련 통합검색
- 확인일: 2026-09-18

| 훈련비 지원율(근로장려금 수급자) | 92.5% ~ 72.5% | 별표 4 |

| 계좌 유효기간 | 발급일부터 5년 | 제16조 |

## 계산으로 얻은 값 (원문 숫자에서 뺀 것)

- 일반훈련생 자기부담률: 지원율 85%일 때 자기부담 15%, 지원율 45%일 때 자기부담 55%.
  즉 100%에서 별표 4의 지원율을 뺀 값이다.
  별표 4는 지원율만 싣고 자기부담률은 따로 표기하지 않는다. 뺄셈 외의 가정은 넣지 않았다.

## 단서

- 제4조제2항에는 나이 하한이 없다. 걸리는 나이 항목은 만 75세 이상 하나다.
- 제4조제5항: 지원제외 해당 여부는 신청일 기준으로 판단한다.
- 제4조제3항: 고등교육법 재학생(제10의2호)과 사업자·법인대표·단체대표(제12~15호)에
  해당해도 고용보험 피보험자면 지원할 수 있다.
- 별표 4 특례 2: 고용위기지역 대상자, 특별고용지원업종 종사자, 출소(예정)자, 장애인,
  기초생활수급자·차상위계층, 자립준비청년, 한부모가족 해당자는
  국취 Ⅰ유형·Ⅱ유형 특정계층의 지원율을 준용한다. (자립준비청년은 보호종료아동 중 일정 연령 이하)
- 고용24 훈련 통합검색 실측(2026-09-18, 전국): 컴퓨터활용능력 1,561건, 제과제빵 916건,
  요양보호사 758건.

## 2026-09-18에 바로잡은 것

| 예전 표기 | 왜 틀렸나 | 바꾼 값 |
|---|---|---|
| 만 15~64세 | 2026 고시에 나이 하한이 없다 | 나이 하한 없음, 만 75세 이상 제외 |
| 만 65세 이상 제외 | 제4조제2항제2호는 만 75세 이상이다 | 만 75세 이상 |
| 14일 이내 발급 통보 | 14일은 진단·상담 기간(제9조제1항)이고 발급 통지는 7일(제7조제1항) | 7일 이내 통지 |
| 일반 재직자 45~70% / 일반 실업자 50~80% | 별표 4에 없는 구분이다 | 별표 4 대상별 표로 교체 |
| 훈련장려금 월 최대 11만 6천원 | 11만6천원은 여섯 구간 중 하나일 뿐이고 최대는 36만원이다 | 1일 2,500~18,000원 |
| 훈련과정 2만 건 | 확인하지 못한 수치다 | 검색어별 실측 건수로 교체 |
| 국가기간 100% 지원 | 제46조제2항은 90% 이상이고 본인부담 상한이 60만원이다 | 90% 이상 지원 |
| 실업자는 발급 전 직업심리검사·상담 필수 | 규정에 그런 요건이 없다 | 140시간 이상 과정 등의 진단·상담으로 교체 |

## 쓰지 않는 것

- 카드 우편 발송 소요 일수 — 규정에 없고 카드사마다 달라 확인하지 못했다.
- 훈련과정 전체 개설 건수 — 검색어별 건수만 실측했고 전체 수는 확인하지 못했다.
- 재발급 제한 기간 — 제재 사유별 기간을 이 고시에서 특정하지 못했다.
