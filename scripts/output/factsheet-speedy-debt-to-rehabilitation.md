## 0-B. 원문·화면 확인

- 1930 개인워크아웃 화면(Playwright): 연체 90일 이상, 추심중단 신청 다음날, 원금감면 미상각채권 최대 30%·상각채권 20~70%, 확정 후 연체정보 및 채무불이행자 정보 해제, 1년간 성실상환 시 공공정보(1101) 해제
- 표기 불일치: 1930은 개인워크아웃 상환기간을 "최장 8년 원금균등분할", 490 비교표는 "최장 10년"으로 적음 → 본문에서 상환기간 숫자 미사용

## 2. 단서 조항 (본문 반영)

- 공식 문서에 "전환" 절차는 없다 — 기존 조정이 실효·완료된 뒤 다른 제도를 새로 신청하는 구조 → qa2·qa3
- 위원회에 접수된 개인회생·파산 사건은 전담재판부 운영 등으로 신속하게 심리 (2290) → qa1
- 신속채무조정 확정자가 분할상환 전 상환유예기간 중 실효되면 효력부활 불가 (730) → qa3

## 3. 확보하지 못한 것 (본문에 쓰지 않음)

- 개인워크아웃 상환기간: 1930 "최장 8년"과 490 "최장 10년" 표기 불일치
- 신속채무조정을 개인워크아웃으로 "전환"하는 별도 절차·서식: 공식 안내 없음
- 두 제도를 동시에 신청했을 때의 처리 순서: 공식 안내 없음 (실효 사유만 확인)
- 개인회생 신청 후 기존 변제금 납입을 언제까지 해야 하는지: 공식 안내 없음
