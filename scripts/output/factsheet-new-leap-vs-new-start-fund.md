## 2. 단서 조항 (본문 반영)

- 새출발기금은 신청 1회만 가능, 부실우려차주가 90일 이상 이행 못 하면 부실차주로 재조정 가능 (Prod.do) → qa4
- 새출발기금 미협약기관 대출은 지원 불가 → 법원 회생·신복위 개인워크아웃 등 이용 (FAQ) → qa4
- 부실우려차주 채무조정이 실효돼도 새출발기금으로 매입되지 않음 (FAQ) → qa4
