# 팩트시트 — 의료급여 본인부담금 환급 (medical-aid-refund)

## 0. 관할

| 항목 | 내용 |
|---|---|
| 소관 | 보건복지부 / 지급 주체는 시장·군수·구청장 |
| 근거 | 의료급여법 시행령 제13조제5항 [시행 2026.1.1] 대통령령 제35932호 |
| 최근 개정 | 2025.9.30 (제6항 삭제, 제5항으로 통합) |

## 0-B. 원문 캡처 확인

- 화면 캡처: `medicaid-decree-full.png` (국가법령정보센터 의료급여법 시행령 화면), `medicaid-byl1.png` (별표1 뷰어) — 2026-08-15 저장.
- 캡처에서 확인한 것: 제13조제5항은 "제4항에 따라 의료급여기관에 지급한 급여대상 본인부담금이 다음 각 호의 구분에 따른 금액에 해당하는 경우에는 해당 호에서 정하는 금액을 기금에서 부담하고 이를 보건복지부령으로 정하는 바에 따라 **시장·군수·구청장이 수급권자에게 지급**한다"로 시작한다. 단서로 "지급해야 할 금액이 **2천원 미만인 경우에는 이를 수급권자가 부담**한다"가 붙어 있다. 1종은 가목 "매 1개월간 2만원 초과 5만원 이하인 경우 2만원 초과금액의 100분의 50", 나목 "매 1개월간 5만원을 초과하는 경우 초과금액의 100분의 100"이다. 2종은 가목 "매 1개월간 20만원을 초과하는 경우 초과금액의 100분의 50", 나목 "가목에 따라 지급받은 금액을 차감한 급여대상 본인부담금이 연간 80만원(요양병원에 연간 240일을 초과하여 입원한 경우 연간 120만원)을 초과하는 경우 초과금액의 100분의 100"이다. 괄호에 **제외 대상**이 명시돼 있다 — 별표1 제1호라목·마목(1종 틀니·임플란트), 같은 표 제2호마목·바목(2종 틀니·임플란트), 같은 표 제3호(선별급여·상급병실료·상한일수 초과분)로 낸 본인부담금은 계산에서 뺀다.

## 1. 수치

| 항목 | 값 | 출처 | 확인 |
|---|---|---|---|
| 지급 주체 | 시장·군수·구청장이 수급권자에게 지급 | 시행령 제13조제5항 | 2026-08-15 |
| 1종 1구간 | 월 2만원 초과 5만원 이하 → 2만원 초과분의 50% | 제13조제5항제1호가목 | 2026-08-15 |
| 1종 2구간 | 월 5만원 초과 → 초과분의 100% | 제13조제5항제1호나목 | 2026-08-15 |
| 2종 1구간 | 월 20만원 초과 → 초과분의 50% | 제13조제5항제2호가목 | 2026-08-15 |
| 2종 2구간 | 위 지급액 차감 후 연 80만원 초과 → 초과분의 100% | 제13조제5항제2호나목 | 2026-08-15 |
| 요양병원 특례 | 연 240일 초과 입원 시 기준이 연 120만원 | 같은 나목 괄호 | 2026-08-15 |
| 최소 지급액 | 2천원 미만이면 지급하지 않음 | 제13조제5항 단서 | 2026-08-15 |
| 계산 제외 | 틀니·임플란트 본인부담, 별표1 제3호(상급병실료·상한일수 초과 등) | 제13조제5항 괄호 | 2026-08-15 |
| 기준 기간 | "매 1개월간" — 30일이 아니라 1개월 | 조문 문언 | 2026-08-15 |

## 2. 계산 검산

- 1종, 한 달 본인부담금 4만원 → (40,000−20,000)×0.5 = 10,000원 지급
- 1종, 한 달 본인부담금 8만원 → (80,000−50,000)×1.00 = 30,000원 지급
- 2종, 한 달 본인부담금 30만원 → (300,000−200,000)×0.5 = 50,000원 지급
- 1종, 한 달 본인부담금 2만 3천원 → (23,000−20,000)×0.5 = 1,500원 → 2천원 미만이라 미지급

## 5. 오해 소지

1. "병원에서 돌려준다" → 아니다. 시·군·구가 지급한다
2. "낸 만큼 다 돌려받는다" → 구간별로 50%와 100%가 갈린다
3. "틀니도 합산된다" → 계산에서 빠진다
