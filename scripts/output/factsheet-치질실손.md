## 3. 예외·단서 조항 (긍정문 뒤집는 "다만" 전수)

- **급여 부분만** 보상 — 같은 수술이라도 비급여 항목은 제외
- 통원 청구 서류는 **금액 구간 3단계**로 달라진다
- 구체적 급여·비급여 구분은 진료 내용과 병원 청구에 따라 달라져 병원 확인 필요

## 4. 확인 못 해 쓰지 않는 것

- 치질 수술 방법별(결찰·레이저 등) 급여 여부 — 심평원 미확인
- 수술비 금액 — 병원·술식마다 달라 쓰지 않는다
