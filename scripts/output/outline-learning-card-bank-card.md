# 구성표 — learning-card-bank-card

- 타이틀: 내일배움카드 농협 신한 차이와 은행 방문, 온라인 발급과 카드 수령
- 확정: 사장님이 13편 세트로 직접 확정 (2026-09-18, 세트 3번). 타이틀·소제목 4개 원문 그대로.
- 허브: /policy/learning-card

## 소제목 (사장님 확정, 변경 금지)

1. 농협과 신한 카드는 무엇이 다른가요?
2. 은행에 갈 때 무엇을 챙겨야 하나요?
3. 은행에 가지 않고 온라인으로 발급되나요?
4. 카드는 며칠 만에 받아볼 수 있나요?

## 근거

- 운영규정 제12조(내일배움카드의 발급 및 사용) — 제휴카드사가 신용카드나 직불카드 형태로 발급
- 고용노동부 고객상담센터(1350) 답변 — 제휴카드사 신한·농협, 현장발급 익일 사용/우편수령 당일 사용,
  신용카드 수령 4주 이내, 분실 재발급 1~2주, 카드사 고객센터 번호
- 고용24 발급안내 — 실물 카드 수령(우편 또는 은행 방문), 발급 확인서와 신분증 지참
