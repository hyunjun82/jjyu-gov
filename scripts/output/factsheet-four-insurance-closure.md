# 팩트시트 — 휴업·폐업 4대보험 (four-insurance-closure)

**타이틀** 휴업이나 폐업하면 4대보험 어떻게 되나요, 지역가입자 전환과 정산까지

## 2. 단서 조항

- 휴업·폐업 둘 다 국민연금법 시행규칙 제4조상 "탈퇴 신고" 사유로 같이 규정돼 있다. 즉 휴업만으로도 별도 신고 대상이며, 자동으로 4대보험이 정리되지 않는다.
- 국민연금(다음 달 15일까지)과 건강보험(14일 이내)의 기한 계산법 차이는 article1·10과 동일한 패턴이 휴폐업 상황에서도 그대로 반복된다.
- 사업주 본인의 건강보험은 휴업·폐업 사유가 발생한 날의 "다음 날"부터 자격이 변동되며, 이 변동일이 곧 지역가입자로 전환되는 시점이다(직장가입자 자격을 상실하는 시점과 지역가입자 자격을 취득하는 시점이 같은 날).
- 고용보험·산재보험의 폐업 시 처리(보험관계 소멸신고)는 근로복지공단이 접수하지만, 정확한 신고 기한 조문은 이번 조사로 확인하지 못했다 — article10과 같은 한계.
- 남은 보험료 정산의 구체적 계산식(일할 계산 여부 등)은 이번 조사로 확보하지 못했다.

## 3. 확보하지 못한 것 (본문에 쓰지 않음)

- 고용보험·산재보험 보험관계 소멸신고의 정확한 법정 기한 조문.
- 폐업 시 남은 보험료의 구체적 정산·환급 계산식 — 관할 공단 확인이 필요하다고만 안내.

## 4. 오해 소지 — 본문에서 푼 자리

1. "휴업하면 4대보험이 자동으로 끊긴다" → 자동으로 정리되지 않는다. 휴업도 별도의 탈퇴·변동 신고 대상이다.
2. "폐업만 신고하면 4대보험도 같이 정리된다" → 사업자등록 폐업 신고와 4대보험 탈퇴 신고는 별개 절차라 각각 신고해야 한다.
