# 팩트시트 — 식중독 실비 청구 (수액·음식점 배상)

> 2026-08-10. 타이틀: "식중독 수액 실비 청구, 음식점 배상과 겹칠까?"

## 0. 관할 확정
- 기관 2곳 이상?: 아니오(실손 기준은 금감원 표준약관 단일). 음식점 배상책임은 **별개 보험**이라 실손 약관 밖 영역 → 본문에서 제도를 섞지 않는다.
- 법령: 보험업감독업무시행세칙 [별표15] 표준약관

- **캡처에서 확인한 것 (표 구조·단서 위치)**: 수액이 걸리는 조항은 질환 목록이 아니라 **약제 조항(2호)**이다. p259·p261이 같은 문장으로 "영양제, 비타민제 등의 약제와 관련하여 소요된 비용. **다만 약관상 보상하는 (상해/질병)를 치료함에 있어 아래 각목에 해당하는 경우는 치료 목적으로 보아 보상합니다**"라고 쓰고, 그 아래 **가·나·다·라 네 개의 하위 조건**이 들여쓰기로 붙는다(가. 약사법령에 의하여 약제별 허가사항 또는 신고된 사항대로 사용된 경우 / 나·다. 요양급여 약제가 별도 기준·승인 절차대로 비급여로 사용된 경우 / 라. 두 가지 이상 함께 사용된 경우의 처리). 텍스트로 뽑으면 이 네 목이 본문과 한 덩어리로 붙어 "영양제는 면책"만 읽히지만, 화면에서는 **면책 → 단서 → 4개 목**의 계단 구조가 한눈에 보인다. 또 6호에 "자동차보험(공제를 포함합니다)에서 보상받는 치료관계비 또는 산재보험에서 보상받는 의료비"가 면책으로 있고 **음식점 배상책임은 이 목록에 없다**는 점도 목록 전체를 봐야 확인된다.
- 텍스트 추출만으로 판단한 항목: 없음.

## 1. 확정 사실
| 항목 | 값 | 근거 |
|---|---|---|
| 식중독 진료비 | 면책 질환 목록에 없음 → 보상 대상 | p209·p260 |
| 수액 등 약제 | 원칙 면책(영양제·비타민제), **치료 목적으로 허가사항대로 사용 등 조건 충족 시 보상** | p259·p261 2호 + 가~라 |
| 자동차보험·산재 보상분 | 면책 | p259·p261 6호 |
| 음식점 배상책임 | 실손 면책 목록에 **없음** (별개 보험 영역) | 목록 전수 확인 |
| 실손의 성격 | 실제 부담한 금액을 보상 / 다수보험은 비례 보상 | 손보협회 비교표 |
| 서류·지급 | 자동전송서류 4종 / 접수 후 3영업일 | 실손24 FAQ, 제8조 |

- 교차출처: 약제 단서를 상해면(p259)·질병면(p261) 두 면에서 동일 확인. 협회 FAQ 요약과도 일치("영양제, 비타민제 등 약제 관련 비용 … 절차를 거쳐 사용된 경우 보상").

## 2. 행동 검증
- 버튼: https://www.silson24.or.kr/claim/web/ (캡처 확인).
- 기관 동사: "청구".

## 3. 예외·단서
1. **수액 = 무조건 보상 아님** — 영양 목적이면 면책, 치료 목적 + 허가사항대로 사용 등 조건을 충족해야 보상. 조건을 그대로 인용하고 단정하지 않는다.
2. **음식점 배상과의 관계는 단정 금지** — 실손 약관 면책 목록에 없다는 사실까지만 쓰고, 실손이 "실제 부담한 금액"을 보상하는 구조라 이미 배상받은 부분의 처리는 **보험사 확인**으로 안내한다. (자동차보험·산재처럼 명시된 면책이 아니므로 "못 받는다"고 쓰면 안 됨)
3. 식중독 관련 검사(예: 위내시경)의 급여 여부는 개별 판단 — 영수증 급여 칸 기준 안내.

## 4. 기존 글 정합
- 실손 클러스터에 감염·중독 축 글 없음. 배상책임 일반은 별도 정책(household-liability-insurance-guide)이 담당하나 이 글은 실손 축이라 겹치지 않음.
