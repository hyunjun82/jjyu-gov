## 0-B. 원문 캡처 확인 (browser_take_screenshot + PDF 원문)

- 캡처에서 확인한 것: 뷰어 상단 **[시행 2025. 12. 12.] [보건복지부령 제1138호]**, 별표목록 **[서식 7] 개인별장기요양이용계획서**. PDF는 **1쪽**이고 상단에 **<개정 2021. 6. 30.>**, 오른쪽 위에 **장기요양인정번호 L0000000000-(이용계획서번호)** 형식이 인쇄돼 있다. 서식 머리말에 "본 서식은 수급자가 장기요양급여를 원활히 이용할 수 있도록 발급하는 이용계획서로 **장기요양기관과 급여계약 체결 시 제시**하시기 바랍니다"라고 적혀 있다. 인적사항 아래 **재가급여(월 한도액) 1개월당 ○원**, **본인부담율(%) — 재가 / 시설**(※ 발급일 기준) 칸이 있고, 시설급여는 **노인요양시설(일반 / 치매전담실 가형 / 치매전담실 나형)**과 **노인요양공동생활가정(일반 / 치매전담형)** 다섯 갈래로 **1일당 금액**이 각각 들어간다. 가운데에는 **장기요양 필요영역 / 장기요양 욕구 / 장기요양 목표 / 장기요양 필요내용 / 수급자 희망급여 / 유의사항** 칸이 있고, 아래 **장기요양 이용계획 및 비용(급여비용 기준일)** 표에 급여종류별 **주 ○회·월 ○회**와 장기요양급여비용·본인부담금, 그리고 **합계**가 들어간다. 복지용구 칸과 담당 지사 전화번호·담당자 칸이 있고, 맨 아래 발급 명의는 **국민건강보험공단 이사장 직인**이다. 금액 칸은 서식 상태에서는 모두 빈칸(0000 형식)이라 실제 액수는 개인별로 채워져 발급된다.
- 버튼 목적지: 서식 PDF(hero·마지막) + 내부 이동 2개.

## 2. 단서 조항

- 본인부담율은 **발급일 기준**으로 표기된다 — 이후 사정이 바뀌면 값이 달라질 수 있다.
- 급여비용 표에는 **급여비용 기준일**이 따로 인쇄된다.
- 금액은 개인별로 채워지는 값이라 서식 자체에는 액수가 없다.

## 5. 오해 소지 — 본문에서 푼 자리

1. 보관용 안내문인 줄 오해 → qa1·qa3 계약 때 제시하는 종이
2. 한도액이 정액인 줄 오해 → qa3 개인별로 채워지는 값, 금액은 서식에 없음
3. 시설급여가 한 종류인 줄 오해 → qa4 다섯 갈래 1일당 금액
4. 계획을 바꿀 수 없다고 오해 → qa5 담당 지사 연락처가 서식에 있음
