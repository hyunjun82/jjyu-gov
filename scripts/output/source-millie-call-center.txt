[KT 혜택 이용 방법] 
밀리의서재 앱 접속 → 관리 → 나의 정기구독 → 통신 결합상품(KT/U+/T우주) → KT 요금제/부가서비스/멤버십 → KT 구독 시작하기 → 제휴 요금제의 가입 휴대폰 번호로 인증을 완료 해주세요.
기존 밀리를 정기구독으로 이미 이용 중이시라면, 남아있는 구독 기간을 KT 혜택 종료 후 이어서 사용하실 수 있습니다. [관리] 메뉴에서 '+'로 추가 기간을 확인할 수 있으며, 혜택 종료 후 잔여기간은 자동으로 사용됩니다.
단, 아래의 경우에는 KT 혜택을 사용할 수 없으니 참고 부탁드립니다.
* 인앱(구글/애플) 스토어 정기구독 중인 경우
* 이미 다른 제휴 혜택을 사용 중인 경우
* 기업 회원인 경우추가로, KT 제휴 혜택이 시작되면 기존 정기구독(자동결제)이 해지될 수 있습니다. 앱 접속 → 관리 → 나의 정기구독에서 다음 결제일이 표시되지 않는 경우 자동결제가 해지된 상태이며, 혜택 종료 후 구독이 자동으로 이어지지 않으니 참고 부탁드려요.

밀리의서재 혜택이 제공되는 T 우주의 구독 상품을 선택하시면 밀리 서비스를 이용할 수 있습니다.
[T 우주 혜택 이용 방법]T 우주 홈페이지→나의 구독→구독 관리→구독 중→상품 혜택 이용/연결하기→밀리의 서재 연결하기

구독중인 상품에 따라 다르게 적용되니 아래 내용을 확인해 주세요.
-콘텐츠를 열람하지 않은 경우
결제 후 기간에 따라 환불 금액이 결정되며, 관리 메뉴[관리 → 나의 정기구독 → 결제내역 조회]을 통해 직접 구독 취소를 하실 수 있습니다.
-결제 후 7일 이내 : 전액 환불
-결제 후 7일 경과 : 90% 환불
구독 취소(환불) 시 구독 권한은 종료됩니다.  
-콘텐츠를 열람한 경우
사용한 일수만큼 차감 후 서비스 수수료 10%를 제외한 금액으로 환불이 가능합니다. 부분 환불이 필요하신 경우, 자세한 확인을 위해 고객센터 -1:1문의로 접수해 주세요.
단, 앱 스토어를 통해 결제한 경우, 각 스토어의 정책에 따라 환불이 진행됩니다. 환불이 필요한 경우 각 스토어 고객센터로 문의해 주세요.
추가로 다음달부터 결제가 진행되지 않도록 자동결제 해지는 언제든지 가능하며, 회원님께서 [관리 → 나의 정기구독 → 나의 정기구독 관리]를 통해 해지하실 수 있으니 이용에 참고 부탁드립니다.

애플 스토어에 연결해 둔 결제 수단으로 결제를 진행한 경우, 애플 정책에 따라 애플 웹 또는 iTunes를 통해서만 환불이 가능합니다. 아래와 같이 진행해 주세요.
[애플 웹을 통해 환불하기]
1. https://reportaproblem.apple.com 접속
2. 구매한 Apple ID 로그인
3. 밀리의 서재 앱의 [문제 신고] 클릭
4. 문제 선택, 내용(환불 사유) 작성 후 제출
[노트북/PC/맥에서 iTunes로 환불하기]
1. iTunes 실행
2. 계정 → 나의 계정 보기 클릭 → 비밀번호 입력
3. [구입 내역]의 모두 보기 클릭
4. 밀리의 서재 앱 선택
5. [문제 신고] 클릭
6. 해당 웹페이지 로그인
7. 환불 요청 → 환불 사유 기재
애플에 연동된 메일로 환불 접수가 되었다는 회신이 오며, 환불 완료까지 시간이 다소 걸릴 수 있으니 참고 부탁드립니다.

구글 스토어 결제 환불 안내 입니다.
구글 스토어에 연결해둔 결제 수단으로 결제한 경우, 구글 정책에 따라 환불을 요청할 수 있습니다. 결제하신 지 48시간이 지나지 않았다면 구글 플레이를 통해 환불이 가능하며, 음악/영화/책 또는 기타 콘텐츠를 구매한 경우에는 48시간이 지난 후에도 환불 요청을 할 수 있습니다.
구글에서 환불을 받을 수 있는지 알아보려면 다음 단계를 따라주세요. 
1. play.google.com/store/account 접속
2. 주문 내역을 클릭 
3. 반품할 주문을 찾기
4. 주문에서 환불 요청 또는 문제 신고를 선택하고 내 상황에 맞는 옵션을 선택
5. 양식을 작성하고 환불을 원한다는 메모를 등록
6. '신고해 주셔서 감사합니다.'라는 메시지가 표시
환불 가능 여부가 결정되면 이메일이 전송됩니다. 보통은 15분 이내에 이메일이 전송되지만, 영업일 기준 4일까지 걸릴 수도 있습니다.
