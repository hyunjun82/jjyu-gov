# 팩트시트 — 장기요양 서식 다운로드 허브 (ltci-forms-download)

## 0. 관할 확정

| 항목 | 내용 |
|---|---|
| 소관 | 보건복지부 (제도) / 국민건강보험공단 (접수·판정) |
| 근거 | 노인장기요양보험법 시행규칙 별지 서식 |
| 서식 원본 | 국가법령정보센터 law.go.kr (뷰어 + 다운로드 직링크 제공) |
| 규칙 시행일 | [시행 2025.12.12] 보건복지부령 제1138호, 2025.12.12. 일부개정 (뷰어 화면 캡처 확인) |
| 수집 결과 | scripts/output/forms-노인장기요양보험법-시행규칙.json (서식 37개, 삭제 3 제외 34개) |

⚠ 공단 홈페이지에도 서식이 있으나, **개정일이 명시된 원본은 국가법령정보센터**다.
블로그에 떠도는 파일은 개정 전 판이 섞여 있어 반려 사유가 된다 — 개정일을 본문에 반드시 적는다.

## 0-B. 원문 캡처 확인 (browser_take_screenshot / PDF 원문)

- 캡처에서 확인한 것: 서식 뷰어 화면 상단에 **[시행 2025. 12. 12.] [보건복지부령 제1138호, 2025. 12. 12., 일부개정]** 이 표시된다. 반면 서식 파일 상단에는 **<개정 2022. 12. 30.>** 이 인쇄돼 있다. 즉 규칙의 최신 시행일과 그 서식이 마지막으로 손질된 날짜는 다르다 — 본문에 둘을 같이 적지 않으면 "낡은 서식 아니냐"는 오해가 생긴다. 국가법령정보센터 법령 본문(iframe)에서 별지 서식 목록 37개를 화면에서 뽑았고, 삭제된 3개(제8·21·22호)를 제외하면 34개다. 서식 뷰어는 `lsBylInfoPLinkR.do?bylCls=BF&bylNo=…&bylBrNo=…` 규칙이고, 뷰어 상단 다운로드 버튼이 `flDownload.do?flSeq=…` 직링크를 물고 있다. 실제로 두 건을 받아 원문을 읽었다. **별지 제1호의2서식**(장기요양인정 신청서·갱신신청서·등급변경신청서·급여종류내용변경신청서, 개정 2022.12.30, 3쪽)은 네 가지 신청이 한 장에 묶여 있고 상단 체크박스로 갈린다. 접수번호 옆에 **처리기간 30일**이 인쇄돼 있다. 3쪽 작성방법에 **65세 미만 노인성 질병 목록이 질병코드까지** 나온다(치매 F00·F01·F02·F03, 알츠하이머 G30, 뇌혈관질환 I60~I67·I68·I69, 파킨슨병 G20, 이차성 파킨슨증 G21, G22, 척수성 근위축 G12, G13, 기저핵 기타 퇴행성 질환 G23, 다발경화증 G35, 진전 R25.1, 중풍후유증 U23.4). 대리인 유형도 4가지로 명시된다(가족·친족·이해관계인 / 사회복지전담공무원 / 치매안심센터의 장 / 시장군수구청장 지정자). **별지 제2호서식**(의사소견서, 개정 2022.12.30, 4쪽)은 첫 장 상단에 **유효기간 발급일부터 30일**이 박혀 있다.
- 버튼 목적지: 허브 버튼은 전부 내부 스포크(/policy/…)로 보낸다. 파일 직링크는 각 스포크 하단.

## 2. 단서 조항

- 실제 거주지는 **방문조사·판정결과 우편물 수령지**다. 바뀌면 공단에 신고해야 한다.
- 우편물 수령인은 **신청인 본인 또는 보호자로 한정**된다.
- 치매안심센터의 장 대리신청은 **신청인이 치매환자인 경우로 한정**된다.
- 시장군수구청장 지정자는 가족·친족·이해관계인·사회복지전담공무원이 **신청할 수 없는 경우**에만.

| 항목 | 사유 |
|---|---|

| 공단 접수처 지사별 주소 | 서식에 없음 |

## 5. 오해 소지 — 본문에서 푼 자리

1. 낡은 서식 배포 → qa1에서 원본 출처와 개정일 명시
2. 신청 종류마다 서식이 다른 줄 오해 → qa2에서 한 서식 4종 체크박스 설명
3. 65세 미만은 안 되는 줄 오해 → qa4에서 질병코드 표
4. 의사소견서를 미리 떼는 줄 오해 → qa3에서 유효기간 30일과 순서 설명
