# 팩트시트 — 인지세 기한 지나서 자진신고 납부하는 법 (stamp-tax-late-payment)

작성 2026-09-21 · 대화창 · Playwright 실측
타이틀: 사장님 지정 그대로. 소제목 4개: **사장님 미지정 — 원문 확인 후 초안** (승인 전 push 금지)

## 관할
- 가산세: 국세기본법 (재정경제부 조세법령운용팀) — 제47조의4 제9항
- 납부·비과세: 인지세법 (재정경제부 부가가치세제과) — 제1조·제6조·제8조·제8조의2
- 상담: 국세상담센터 126

## 수치 (출처)
| 항목 | 값 | 출처 |
|---|---|---|
| 원칙 가산세 | 미납·과소납부 세액의 100분의 300 | 국세기본법 제47조의4 제9항 본문 |
| 기한 후 3개월 이내 납부 | 100분의 100 | 같은 항 단서 제1호 |
| 3개월 초과 6개월 이내 납부 | 100분의 200 | 같은 항 단서 제2호 |
| 감경 제외 | 경정할 것을 미리 알고 납부하는 경우 | 같은 항 단서 괄호 |
| 제9항 적용 제외 | 제3조제1항제1호 중 부동산 소유권 이전 증서 | 같은 항 괄호 |
| 일반 납부지연가산세 | 인지세법 제8조제1항 인지세 제외 | 같은 조 제1항 괄호 |
| 납부기한 | 작성일이 속하는 달의 다음 달 10일 | 인지세법 제8조제3항 ↔ 생활법령 |
| 전자조달 예외 | 작성일 납부 | 인지세법 제8조제3항 단서 ↔ 생활법령 |
| 비과세 주택 | 주택 소유권 이전 증서 기재금액 1억원 이하 | 인지세법 제6조제5호 ↔ 생활법령 |
| 비과세 대출 | 금전소비대차 증서 기재금액 5천만원 이하 | 인지세법 제6조제8호 |
| 비과세 문서 수 | 12가지 (제1호~제12호) | 인지세법 제6조 |
| 2023.1.1 이전 부동산 증서 | 부칙 제7조로 납부지연가산세 | 생활법령 (국세기본법 법률 제19189호 부칙 제7조) |
| 3배 / 1배 / 2배 (서론) | 100분의 300 / 100 / 200 를 말로 풀었다 | 제9항 |

## 단서 (원문에 있고 글에도 넣은 것)
- 경정을 미리 알고 내면 감경 없음 → 서론·Q2·FAQ1
- 부동산 소유권 이전 증서는 제9항 밖 → 서론·Q3
- 전자조달시스템은 작성일 당일 기한 → Q1
- 공동 작성 연대 납부 → Q4·FAQ2
- 소인(납부서비스에 사용 입력, 인지세법 제10조) → Q4

## 쓰지 않는 것
- 가산세 100/200/300 의 두 번째 출처 — 국세청 검색 시간 초과, 누리집 종이문서용은 보안프로그램 필요. **조문 원문 단일 출처.** (보고서 메모)
- 누리집에서 가산세 자동 계산 여부·납부 화면 — 확인 못 함 → 126 안내
- 2023.1.1 이후 부동산 증서 지연 시 가산세 — 두 출처 모두 직접 언급 없음 → 126 안내
- "3개월 이내"의 달력 날짜 — 기간 계산 규정 미수집
- 금액 예시 — 예시 수치 금지
- 인지세법 제10조 조문 원문 — 생활법령 인용으로만 확인
