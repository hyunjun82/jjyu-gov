## 3. 단서 조항 (긍정문 뒤집는 '다만' — 본문에 반영한 것)

- 국민기초생활보장법 제2조제2호 수급자는 국민연금 연계감액(제5조제4항·제6항)에서 제외되어 기준연금액 그대로 받는다는 단서를 반영함(시행령 제9조제1항)
- 부부 모두 기초연금 수급권자인 경우 100분의 20 감액 예외(제8조제1항)를 반영함
- 소득인정액+기초연금액 합산이 선정기준액 이상이면 초과분 범위에서 일부 감액 가능(제8조제2항)이라는 단서를 반영함

## 4. 확보하지 못한 것 (본문에 쓰지 않음)

- 국민기초생활보장법상 소득인정액 산정 시 기초연금 반영 방식 — 확보한 시행령 화면(제2조~제4조)에 해당 계산 조문이 없어 쓰지 않음
- 기초연금 현재 지급 금액(예: 월 특정 액수) — 추출본에 현재 고시된 기준연금액 수치가 없어 쓰지 않음(부칙의 20만원·30만원은 2014·2021년 경과조치 값이라 현재값으로 쓰지 않음)
- 주거급여-기초연금 간 직접 연동 조항 — 주거급여법 소스는 설계도에서 ok:false(기초연금 언급 없음)로 표시돼 근거로 삼지 않고, 선정기준(100분의 43)만 사실로 사용함
- 생계급여 자체의 구체적 지급액·감액 비율 — 국민기초생활보장법 본법(생계급여 지급기준) 조문이 확보되지 않아 쓰지 않음
