# 팩트시트 — 쿠팡 배달·일용직 4대보험 (four-insurance-gig-workers)

**타이틀** 쿠팡 배달이나 일용직도 4대보험 되나요, 가입 기준과 사업주 신고 의무

## 0. 관할 확정

| 항목 | 내용 |
|---|---|
| 소관 | 국민연금공단·국민건강보험공단·근로복지공단 |
| 1차 출처 | self-employed-four-insurance-join·part-time-four-insurance 글과 같은 근거(법제처 4대 사회보험 신고, 배달앱종사자 고용보험, 산재보험법 제6조) — 신규 조사 없이 기존 확보 사실 재구성 |

## 1. 수치 (전부 기존 편에서 확보한 사실 재사용 — 신규 수치 없음)

| 항목 | 값 | 원 출처 |
|---|---|---|
| 국민연금 일용근로자 제외 | 일용근로자 또는 1월 미만 기한부 근로자는 제외 | self-employed-four-insurance-join (easylaw 632) |
| 건강보험 일용근로자 제외 | 고용기간 1개월 미만 일용근로자는 직장가입자 제외 | 위와 동일 |
| 고용보험 일용근로자 예외 | 1개월 미만 일용근로자도 적용대상에 포함(제외 대상 아님) | 위와 동일 |
| 산재보험 적용 범위 | 근로자를 사용하는 모든 사업에 적용, 개인 근로시간 기준 제외 없음(사업 단위 예외만 있음) | source-industrial-accident-scope.txt(산재보험법 제6조 원문) |
| 노무제공자(배달앱) 신고 | 노무제공플랫폼사업자가 사유발생일 다음달 15일까지 신고, 보험료도 플랫폼사업자가 원천공제 | part-time-four-insurance (easylaw 1589) |

## 2. 단서 조항

- 이 글은 새로운 1차 출처 조사 없이, 이미 확보한 4개 편(1편 가입의무, 4편 알바, 4편 배달앱종사자 교차출처)의 사실을 "쿠팡·배달·일용직"이라는 새 각도로 재구성한 것이다. 모든 수치·인용은 기존 추출본을 그대로 가리킨다.
- "쿠팡알바"는 실제로는 계약 형태에 따라 갈린다 — 쿠팡 물류센터처럼 사업주와 직접 근로계약을 맺는 형태(일반 근로자, 4대보험 원칙 적용)와, 쿠팡이츠 배달파트너처럼 위탁계약을 맺는 형태(노무제공자, 플랫폼사업자가 신고)가 다르다. 계약 형태별 구체적 사업장 목록은 여전히 확보하지 못했다(part-time-four-insurance 글과 같은 한계).

## 3. 확보하지 못한 것 (본문에 쓰지 않음)

- 계약 형태별 구체적 사업장 목록(part-time-four-insurance 글과 동일한 한계).
- 노무제공자 산재보험 전속성 요건 세부 수치(part-time-four-insurance 글과 동일한 한계).

## 4. 오해 소지 — 본문에서 푼 자리

1. "쿠팡알바는 전부 노무제공자라 4대보험이 안 된다" → 근로계약을 맺은 형태(물류센터 등)라면 일반 알바와 똑같이 4대보험이 적용된다.
2. "일용직은 4대보험이 전부 제외된다" → 국민연금·건강보험은 1개월 미만이면 제외되지만, 고용보험·산재보험은 일용직도 적용대상이다.
